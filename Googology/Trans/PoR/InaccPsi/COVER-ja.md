## 1. 長さ 3 の鎖

$`a`$ での **無限の閉じた扇** とは、$`R(a)`$ の列 $`d_0 \lt d_1 \lt d_2 \lt \cdots`$ で、どの $`n`$ でも $`d_n \le_1 d_{n+1}`$ となるもの。**閉じた $`n`$ 扇** とは、
パターン $`a \lt d_0 \lt \cdots \lt d_{n-1}`$（どれも AP）で、$`a \lt_2 d_i`$、$`i \lt j`$ なら $`d_i \lt_1 d_j`$、$`d_i`$ の間には $`\lt_2`$ が無いもの。$`\varphi_n`$ は
その最小の実現の頂点、$`t_n`$ はその上端。この節の結果は、$`R_2^S`$ と書かない限りどれも $`R_2^C`$ でのもの。

- **補題 CORE-REACH**（証明済み、査読 1 回）。$`a \lt \kappa_C`$ なら $`\mathrm{lh}(a)`$ があり、$`\mathrm{lh}(a) \lt \kappa_C`$。だから核の点の右端と、その
  右端の極限は、どれも核に入る。定理 CP（[BREAK-ja.md](BREAK-ja.md) §8.1）の「核に入る」という仮定は、それらではひとりでに成り立つ。
- **定理 LEFT-CHAR**（証明済み、査読 1 回）。$`0 \lt e \lt \kappa_C`$ について：$`e`$ が $`\lt_2`$ の左端であるのは、$`e`$ が極限で
  $`\mathrm{Pred}_1(e)`$ が $`e`$ の中で上に有界でないときちょうど。（査読者：論文は「共終」と書く。ゆるく「どの点にもそれ以上の元が
  ある」と読むと、$`c_0 + 1`$ で成り立たない。証明は厳しい読み方を使っている。）
- **定理 CP3**（証明済み、査読 1 回）。$`a \lt \kappa_C`$ について、次は同じ：(i) $`a`$ は長さ 3 の鎖の底。(ii) $`a`$ は無限の閉じた扇を
  持つ。(iii) $`R(a)`$ のある極限点 $`e`$ で、$`\mathrm{Pred}_1(e)`$ が $`e`$ の中で上に有界でない。(iv) ある $`e \in R(a)`$ でそうなる。(ii) のとき、
  $`e = \sup_n d_n`$ は $`a`$ の右端でかつ左端で、$`e \lt_2 f`$ となるどの $`f`$ でも $`\{a, e, f\}`$ は鎖。だから定理 CF（[BREAK-ja.md](BREAK-ja.md) §3）の
  「右端の極限が左端」という条件（有限の配置では決まらない）が、1 つの点 $`a`$ の右端の間の $`\le_1`$ の条件になる：木 $`(R(a), \lt_1)`$
  が無限に上る枝を持つ。CP3 はどの点が鎖の底かを教えるが、鎖を作りも評価もしない。
- **系 LEAST3**（証明済み、査読 1 回）。(a) $`c_0`$ は無限の閉じた扇を持つ最小の点。(b) $`c_1`$ は、$`R(c_0)`$ の極限点 $`e`$ で
  $`\mathrm{Pred}_1(e)`$ が $`e`$ の中で上に有界でない最小のもの。(c) $`D^* = \{d : c_0 \lt_2 d,\ d \le_1 c_1,\ d \lt c_1\}`$ の順序型はちょうど $`\omega`$ で、
  $`\sup D^* = c_1`$。(d) $`Q_0 = C^*_3`$ とし、$`Q_{n+1}`$ を、$`Q_n`$ で $`c_1`$ を $`c_2`$ から下向きに 2 反映したもの（Carlson 2009, Def 9.4）とする。
  新しい点を $`u_{n+1}`$ とする。$`Q_n`$ の最小の実現で $`u_i`$ は $`D^*`$ の $`i`$ 番目の元。だから $`c_1`$ は $`n`$ 回の下向きの 2 反映が作る点の上限。
  （[BREAK-ja.md](BREAK-ja.md) §8.1 の系 LEAST と同じ形で、$`(x_k, T_k)`$ の代わりに $`(c_1, c_2)`$。）
- **NO-BRANCH と PIN-L**（証明済み、査読 1 回）。$`a \lt c_0`$ なら、木 $`(R(a), \lt_1)`$ は無限に上る枝を持たない。$`\lt_2`$ の左端 $`e`$ を含む
  どの最小な集合も、$`e \lt_2 v`$ となるある $`v`$ を含む。だから $`c_1`$ を含むものは $`\ge c_2`$ の点を含む。（「$`x_k`$ を含む最小な集合は
  $`T_k`$ を含む」（[BREAK-ja.md](BREAK-ja.md) §8.1）を広げたもの。）
- **定理 FIN-FAN**（証明済み、査読 1 回）。$`\varphi_2 = f_0`$。$`\varphi_{\lt\omega} = \sup_n \varphi_n`$ として：

```math
T_\omega \le \sigma_F \lt f_0 = \varphi_2 \lt t_2 \lt \varphi_3 \lt t_3 \lt \cdots, \qquad \varphi_{\lt\omega} \le m_3 \lt c_0 .
```

  $`\varphi_{\lt\omega}`$ は上限点の極限なので、$`\lt_1`$ の前の元を持たず、どの組にも入らない（LIM-CAP、[BREAK-ja.md](BREAK-ja.md) §6）。だから
  最小の閉じた扇を繰り返しても鎖には届かない：鎖には、無限の閉じた扇を持つ頂点が 1 つ要り、それが $`c_0`$。
- **場所**（証明済み、査読 1 回）。下からの評価だけ：

```math
c_0 \gt m_3 \ge \varphi_{\lt\omega} \gt f_0 \gt x_F \gt x_L \gt T_\omega, \qquad m_3 \gt \nu_C, \qquad m_3 \ge \Lambda_\varepsilon .
```

  定理 GEN と GEN-EXT の名前はどれも $`\psi_{\Omega_1}(\Omega_\omega\cdot\omega)`$ より下で、その中で共終（補題 CONT による）。H-LIFT
  （$`T_\omega = \psi_{\Omega_1}(\Omega_\omega\cdot\omega)`$、[BREAK-ja.md](BREAK-ja.md) §6）を仮定すると、$`c_0`$ はどの GEN と GEN-EXT の名前よりも先にある。
  [BREAK-ja.md](BREAK-ja.md) §7.4 の予想の名前では $`c_0 \gt y_L = \psi_{\Omega_1}(\Omega_\omega\cdot\omega + \omega^{P_\omega+1} + P_\omega)`$（予想）。$`c_0`$、$`c_1`$、$`c_2`$ の上からの評価と
  名前は分かっていない。
- **到達不能基数**（証明済み、査読 1 回）。$`FF_{cl}`$ を仮定 $`\varphi_{\lt\omega} \ge \theta_0`$ とする。FF から $`FF_{cl}`$ が出て（$`\sigma_F \lt \varphi_2`$ なので）、
  $`FF_N`$ からも出る。$`FF_{cl}`$ を仮定すると $`m_3`$、$`c_0`$、$`c_1`$、$`c_2`$ は $`\ge \theta_0`$ なので、その InaccPsi の名前にはどれも到達不能
  基数が入る。$`FF_{cl}`$ が求めるのは、鎖の無いパターンの 1 つの具体的な族、つまり最小の閉じた $`n`$ 扇が $`\theta_0`$ まで上ることだけ。
  また：$`\Phi_3`$((0,0,0)(1,1,1)(2,2,1)) の点が $`\ge \theta_0`$ なら、$`x_F`$、$`f_0`$、$`\varphi_n`$、$`m_3`$、$`C^*_3`$ に到達不能基数が要る。査読者は
  これを「その点は $`m_F`$」という等式を仮定してだけ認めた（§2）。この等式は今は §2 で証明済み（査読 1 回）。仮定なしでは未解決。
- **$`R_2^S`$**（証明済み、査読 1 回）。CP3 の (i) ⇒ (ii) と LEFT-CHAR の「⇒」は $`R_2^S`$ でも成り立つ。**定理 TR3**：$`(s_0, s_1, s_2)`$ を
  $`R_2^S`$ の長さ 3 の辞書式で最小の鎖とする。$`s_1 \le \beta_0`$ なら $`c_0 \le s_0`$ かつ $`c_1 \le s_1`$。（系 FIRST では、これに $`s_2 \le \beta_0`$ が
  要った。）$`R_2^S`$ での残りの向きは、§4 の 2 つの理由で未解決。

## 2. 最小の扇

$`V_F = \mathrm{Pred}_1(x_F)`$、$`m_F = \min V_F`$、$`o_F`$ は $`V_F`$ の順序型。$`v_\zeta`$ は $`V_F`$ の $`\zeta`$ 番目の元。**極限の元** とは $`\zeta`$ が極限の
$`v_\zeta`$。$`s^+`$ は $`V_F \cup \{x_F\}`$ の $`s`$ の次の元。PT は開いた扇 $`x \lt_2 y_1`$、$`x \lt_2 y_2`$、$`y_1 \not\le_1 y_2`$ で、その最小の実現が最小の扇
（[BREAK-ja.md](BREAK-ja.md) §7.4）。PTm は、PT に点 $`m \le_1 x, y_1, y_2`$ を加えたもの。結果はどれも $`R_2^C`$ でのもの。

- **補題 ENDS と RE**（証明済み、査読 1 回）。$`s \lt x_F`$ かつ $`s \lt_2 t`$ なら、$`t \lt x_F`$、$`t \notin V_F`$ で、$`(s, t)`$ に $`V_F`$ の元は無い。
  $`s \lt_2 t`$ で、ある $`r \in [s, t)`$ について $`s`$ が $`(r, t)`$ に右端を持たなければ、$`\mathrm{lh}(t) = t`$。特に $`\mathrm{lh}(y_1) = y_1`$、$`\mathrm{lh}(y_2) = y_2`$。
- **定理 FS**（証明済み、査読 1 回）。
  (a) $`V_F`$ は閉じていて $`x_F`$ の中で共終。だから $`x_F = \sup V_F`$。どの元も AP で、届く先は $`y_2`$。
  (b) $`\mathrm{Pred}_1(y_1) = \mathrm{Pred}_1(y_2) = V_F \cup \{x_F\}`$。
  (c) $`V_F`$ の中の左端はちょうど極限の元。極限の元 $`s`$ の右端はちょうど 1 つ $`t_s`$ で、$`s \lt t_s \lt s^+`$、$`t_s \notin V_F`$、
  $`\mathrm{lh}(t_s) = t_s`$、$`\mathrm{Pred}_1(t_s) = \mathrm{Pred}_1(s) \cup \{s\}`$。
  (d) $`m_F`$ と後者の元は左端でない。$`\mathrm{Pred}_1(m_F) = \emptyset`$。
  (e) $`V_F`$ の中の左端は $`x_F`$ の中で共終（$`x_F \le_2 y_2`$ と Carlson 2009, Def 5.3 の条項 1(d) から）。だから $`\lambda`$ を極限として
  $`o_F = \omega\cdot\lambda`$。特に $`o_F \ge \omega^2`$。
  (f) $`m_F \ge \sigma_N`$。$`m_F`$ は PTm の最小の実現の点で、それは $`\Phi_3`$((0,0,0)(1,1,1)(2,2,1)) の点。査読者はこの等式を直接に
  証明し、その行列の図を描き直した。だから [BREAK-ja.md](BREAK-ja.md) §7.4 の査読者が別の査読なしで加えた等式は、今は査読済み。
  (g) LEAST-F：$`Q_n`$ を、PT に $`n`$ 個の組 $`u_1 \lt_2 v_1 \lt \cdots \lt u_n \lt_2 v_n \lt x`$（$`u_i \le_1`$ それより後のどの点）を加えたものとする。
  $`Q_n`$ の最小の実現で $`u_i`$ は $`v_{\omega\cdot i}`$。$`Q_{n+1}`$ は、$`Q_n`$ で $`\{x, y_1\}`$ を $`y_2`$ から $`x`$ へ下向きに 2 反映して得られる。だから
  これらの点の上限は $`v_{\omega^2} \le x_F`$ で、等号は $`o_F = \omega^2`$ のときちょうど。
- **補題 BLOCK、PIN-F、PAIR-CP**（証明済み、査読 1 回）。BLOCK は左端をその右端と一緒に、被覆で下に動かす。補題 MOVE
  （[BREAK-ja.md](BREAK-ja.md) §8.1）を広げたもの。PIN-F：$`x_F`$ を含むどの最小な集合も、$`y_1`$ と $`y_2`$ の両方を含むか、1 つの $`y_i`$ と
  $`(x_F, y_i)`$ の中の分解できない元を含む。PAIR-CP：$`s \lt x_F`$ が極限の元の極限なら、$`s`$ を含むどの最小な集合も $`t_s`$ と
  $`(s, t_s)`$ の中の分解できない元を含む。
- **予想** $`o_F = \omega^2`$、つまり $`x_F = v_{\omega^2}`$。論文はこれを隙間についての「内部の写し」の命題に帰着させる。含意は証明
  済みだが、査読者はその命題が $`x_F`$ より下のどの極限の元でも成り立たないことを示した。だからこの帰着は予想の言い換えに
  すぎない。**今は別の道で証明済み**（定理 OF、§5.2、査読 1 回）。
- **到達不能基数。** $`H_m`$ を仮定 $`m_F \ge \theta_0`$、つまり $`\Phi_3`$((0,0,0)(1,1,1)(2,2,1)) の点が $`\ge \theta_0`$ であることとする。証明済み
  （査読 1 回）：$`FF_N \Rightarrow H_m \Rightarrow x_F \gt \theta_0`$。再生した証明書 $`\Phi_3(\mathrm{SRO}) \lt \Phi_3`$((0,0,0)(1,1,1)(2,2,1)) から POINT-SRO $`\Rightarrow H_m`$。
  そして $`\Phi_3(\mathrm{SRO})`$ の点が $`\theta_0`$ なら（[README-ja.md](README-ja.md) §3 の予想）、$`m_F \gt \theta_0`$（再生した証明書から）。だから、最初の
  扇に到達不能基数が要るかは、1 つの行列についての 1 つの命題。未解決。予想：要る。今は $`H_m`$ に、行列を含まない正確な言い換えがある（§5.3）。
- **未証明**（止める点、脇の主張だけ）。$`m_F \gt \theta_0`$ から、基 $`\psi_{I_0}(0)`$ の上に作った最小の扇の名前の候補が否定されること。
  その候補が名付けるのは $`x_F`$、$`y_1`$、$`y_2`$ だけで、議論は候補に無い根についての条項を加えている。

## 3. $`R_2^C`$ での NOLIM

記号は [BREAK-ja.md](BREAK-ja.md) の §7.3 と §8.4 と同じ：$`U_2`$、その隙間 $`(g, g^+)`$、（長いやり直しの点の）$`K`$ 鎖、LIM の点、$`b^*(g)`$。$`\nu = \nu_C`$。

- **補題 PIN-LH**（証明済み、査読 1 回。$`R_2^C`$）。$`Z`$ が最小な集合で、$`b \in Z`$ で $`\mathrm{lh}(b)`$ があれば、$`\mathrm{lh}(b) \in Z`$。
- **補題 FRAG2→**（証明済み、査読 1 回）。FRAG2（[RESTARTS-ja.md](RESTARTS-ja.md) §2）の条件を前向きにだけ満たす FRAG の写像は、構造が
  骨組み型の有限の集合の上で、その像への被覆。
- **補題 BLOCK-MOVE**（証明済み、査読 1 回。$`R_2^C`$）。SKEL⁺ を使い、査読者はそれを概略の段階でしか認めていなかったが、今は
  SKEL⁺ に完全な証明がある（§5.1）。$`Z`$ を有限の閉じた集合、$`b \in Z`$ を
  $`h = \mathrm{lh}(b) \lt \nu`$ の AP のやり直しの点で、LIM の点とする。すると $`Z`$ は、閉じた集合への被覆 $`f^+ \le \mathrm{id}`$ で $`f^+(b) \lt b`$ となる
  ものを持つ。それは $`Z \cap b`$ と $`h`$ より上では恒等で、$`Z \cap [b, h]`$ では、$`Z`$ が出会うやり直しの領域を、$`b`$ より下の $`K`$ 鎖
  $`c_1 \lt_1 \cdots \lt_1 c_K`$ の領域へ、ずれをそのままに送る FRAG の写像。動かしたやり直しの点の届く先は使わない：どの像も
  $`\mathrm{lh}(c_K) \le \mathrm{lh}(c_i)`$ より下。
- **定理 NOLIM$`^C`$**（証明済み、査読 1 回。SKEL⁺ を通して、§5.1）。$`R_2^C`$ では、$`(0, \nu) \setminus U_2`$ のどの点も LIM の点でない。
  だからどの隙間でも $`b^*(g) = g^+`$（ITER）で、$`(0, \nu]`$ の LIM の点はちょうど $`U_2`$ の元。証明：そういう $`b`$ は核に入るので、ある
  最小な集合に入る。それは $`\mathrm{lh}(b) \lt \nu`$ のやり直しの点。BLOCK-MOVE はそれを被覆で下に動かし、Carlson 2009, Thm 14.10(2) に
  反する。査読者はもっと短い証明を与えた：同じ写像が、どの $`\beta \lt \nu`$ でも $`b \le_1 \beta`$ について Carlson 2009, Def 5.3 の条項 1 を
  確かめる。だから $`b \le_1 \nu`$ で $`b \in U_2`$。核の評価も Thm 14.10 も使わない。
- **系 LL$`^C`$**（証明済み、査読 1 回。SKEL⁺ を通して、§5.1）。$`R_2^C`$ では、$`\nu`$ より下のやり直しの点の無限の $`\lt_1`$ 鎖の上限は $`U_2`$ に入る
  （[BREAK-ja.md](BREAK-ja.md) §7.3 の命題 LL）。

## 4. $`R_2^S`$ での被覆に対する最小性

ここでは $`k \ge 2`$ は $`R_2^S`$ の段で、$`U_k`$、$`x_k`$、$`T_k`$ は [BREAK-ja.md](BREAK-ja.md) §8 と同じ。$`o_k \gt \omega`$ のとき $`s = \upsilon^k_\omega`$。**S 被覆** とは

  (D0) $`a \lt_2 b`$ で $`a`$ がやり直しの点でなければ、$`(a, b)`$ は標準の組。$`a`$ がやり直しの点なら、$`b`$ もやり直しの点で、ある標準の組が

### 5.2 最小の扇の順序型は $`\omega^2`$（$`R_2^C`$）

### 5.3 最初の扇に到達不能基数が要るか（$`R_2^C`$）

パターンが **RF**（「届く先の無い右端」）とは、その $`\lt_2`$ の組のどの右端 $`z`$ も、そのパターンのもっと大きい元に $`\le_1`$ でないこと。
$`\mathrm{Core}_F`$ は $`x_F`$ より下の最小な集合の合併。$`FF_{RF}`$ は：どの $`\gamma \lt \theta_0`$ も、扇の無いある RF パターンの最小の実現より下。
$`H_m`$ は $`m_F \ge \theta_0`$（§2）。

- **定理 DOM_RF**（証明済み、査読 1 回）。$`(x; y_1, y_2)`$ を開いた扇でも閉じた扇でもよい扇とし、$`m \le x`$、$`m \le_1 y_2`$ とする。扇の無い
  どの RF パターンも、最小の実現が $`m`$ より下。特に $`m_F`$ より下。（[BREAK-ja.md](BREAK-ja.md) §6 の DOM_F は閉じた扇が要る。RF パターンでは、
  $`y_1`$ へ送る点に届く先は要らない。）
- **定理 SHARP_F**（証明済み、査読 1 回）。$`\mathrm{Core}_F = [0, m_F)`$。だから $`m_F`$ は、扇の無い RF パターンの点の上限で、$`x_F`$ より下の
  上限点の上限。
- **系**（証明済み、査読 1 回）。$`H_m \Leftrightarrow FF_{RF} \Leftrightarrow [0, \theta_0) \subseteq \mathrm{Core}_F`$、また $`m_F \gt \theta_0 \Leftrightarrow \theta_0 \in \mathrm{Core}_F`$。さらに
  $`FF_N \Rightarrow FF_{RF}`$。だから $`H_m`$ は扇の無い RF パターンだけについての下からの評価の命題で、行列と比べる必要は無い。
- **命題 RR**（証明済み、査読 1 回）。RR $`= \{x \lt_2 y,\ x \le_1 c,\ y \le_1 c\}`$ は扇が無いが RF でなく、その点は $`x_F`$ より上。だから
  $`x_F \lt \sigma_F \lt f_0`$（[BREAK-ja.md](BREAK-ja.md) §6 の未解決の問いが決まる）で、「扇の無いパターンの上限点は $`m_F`$ より下」は偽。成り立つのは
  RF パターンだけ。

### 5.4 $`\beta_0`$ までの $`R_2^S`$ での被覆に対する最小性

記号は §4 と同じで $`k = 2`$。場合 (P3b) では $`\beta_0 = s^+ = \upsilon^2_{\omega+1}`$ で、$`\beta_0`$ での違いは $`R_2^C`$ の $`s \lt_2 s^+`$ だけ。

- **補題 GT**（証明済み、査読 1 回）。Carlson 2009, Thm 14.10(2) から $`R_2^S`$ の最小性を得る方法：$`Z`$ を S 最小とし、$`P^*`$ を $`R_2^S`$ での
  $`Z`$ のパターンの $`R_2^C`$ での最小の実現とする。$`P^*`$ が点ごとに $`Z`$ より下で、$`P^*`$ の点の間の関係で 2 つの構造が一致すれば、$`P^* = Z`$、
  $`Z`$ は $`R_2^C`$ で最小、そして $`Z`$ は、関係が $`R_2^C`$ で成り立つ閉じたどの S 被覆よりも点ごとに下。
- **ISO-EQ**（証明済み、査読 1 回。場合 (P3b)）。有限の閉じた $`Z \subseteq [0, \beta_0]`$ が S 最小なのは、$`R_2^C`$ で最小で、$`s`$ と $`s^+`$ の両方は
  含まないときちょうど。
- **LOCAL⁺**（証明済み、査読 1 回。場合 (P3b)）。MIN$`^S`$ は閉区間 $`[0, \beta_0]`$ で成り立つ（LOCAL は $`[0, \beta_0)`$）。だから $`[0, \beta_0]`$ のどの
  S 最小な部分集合も $`s`$ を含まず、$`s`$ を含むどの S 最小な集合も $`\gt s^+`$ の点を持ち、定理 CP は $`R_2^S`$ の $`[0, \beta_0]`$ で成り立つ。
- **INCOMP**（証明済み、査読 1 回。場合 (P3b)）。$`[0, \nu_S]`$ では、どちらの構造ももう一方を含まない：$`s \lt_2 s^+`$ は $`R_2^C`$ で成り立ち
  $`R_2^S`$ で成り立たない。$`s \le_1 z`$ と $`s^+ \le_1 z`$ は、どの $`z \in (s^+, \nu_S]`$ でも $`R_2^S`$ で成り立ち $`R_2^C`$ で成り立たない。
- **NOGO-T**（証明済み、査読 1 回。場合 (P3b)）。GT は $`s`$ を含む S 最小な集合には決して使えず、$`o_2 = \omega`$ に MIN$`^S`$ が要るのは
  ちょうどその集合。査読者：場合 (P3b) では MOVE$`^S`$ がそれらの集合で MIN$`^S`$ をすでに否定するので、NOGO-T は示すべきことを
  変えない。論文のさらなる主張「どの証明も $`R_2^S`$ の中で働くしかない」は方法についての注意で、定理ではない。
- **BLOCK-MOVE$`^S`$、NOLIM-COND$`^S`$、RED**（証明済み、査読 1 回。SKEL⁺ を使い、それは今は証明済み、§5.1）。§3 の BLOCK-MOVE は
  $`R_2^S`$ で S 被覆として働く。MIN$`^S`$ から、$`(0, \nu_S) \setminus U_2`$ にある $`R_2^S`$ の LIM の点はどれも $`\mathrm{Core}_C(R_2^S)`$ に入らないことが出る。
  $`\nu_C = \nu_S`$ は MIN$`^S`$ と CORE-S から出る。CORE-S は、そういう LIM の点のどれも、そして $`o_2 \gt \omega`$ なら $`s`$ も、$`\mathrm{Core}_C(R_2^S)`$ に入る
  という命題（$`\mathrm{Core}_C(R_2^S)`$ が始切片なら成り立つ）。査読者：CORE-S を仮定すると、使う MIN$`^S`$ の場合は結論と同じなので、
  RED の中身は大域の MIN$`^S`$ だけ。
- **DESCENT**（証明済み、査読 1 回）。Carlson の L.14.6 の議論は $`R_2^S`$ で働く：$`Z`$ のどの S 被覆も $`Z \cup Q`$ の S 被覆に広がるなら、
  $`Z`$ は点ごとに $`Q`$ より下。これが要る広がりの性質は、DEFECT と NEC（§4）と同じ所で成り立たない。
- **未証明**（書いたままでは偽、直せる）。「悪い組」1 つでは何も止めない、という注意：その証拠 $`a = \omega^{\omega^s}`$ は、$`s`$ が $`\varepsilon`$ 数
  なので $`s`$ に等しい。正しい証拠は $`a = \omega^{s\cdot 2}`$。
