### 1.4 $`\nu_C = \nu_S`$：錨の写しを使わない計画

記号は [SHIFT-ja.md](SHIFT-ja.md) の §4、§8.4、§9.4 と同じ。**またぎ** とは組 $`(u, L)`$ で、いちばん上のやり直し $`u`$ があとのやり直し $`L`$ の区域の中まで届くもの。$`u`$ から $`L`$
への添字の距離が $`\rho_u`$ より下なら **浅い**、そうでなければ **深い**。ここでの「FRAG のもと」は、査読者の言うとおり、前の補題 LT、HEAD-TAIL、REFL-ξ のあらすじの水準。

- **GAP-CE**（証明済み、FRAG のもと）。尾がちょうど $`[0, x + u_m]`$ のすき間 $`(x^\#, K)`$（$`K`$ は長いやり直し）がある：どの $`u_n`$、$`x`$、$`u_m\cdot 2`$ も尾だが、$`x\cdot 2`$ は尾でない。
  だから [SHIFT-ja.md](SHIFT-ja.md) §9.4 の (E1) の 3 つ目の場合 (W-res-3) は、すき間の性質ではない。NO-LOC（証明済み、自明）：$`x \lt_2 \nu`$ での Carlson 2009, Def 5.3, clause 2 は、
  配置を $`\nu`$ より下に共終に置くだけで、与えたすき間の中には決して置かない。（錨の写しの天井では (W-res-3) を証明できない、という論文の結論は注意にすぎない。）
- **DOUBLE-FAR、ROOM-FAR、W-EQ-FAR**（証明済み、FRAG のもと）。$`\nu`$ より下に共終に、各 $`k \lt \omega`$ で $`\mathrm{lh}(l') \ge \rho_{l'\cdot(k+1)}`$ の長いやり直し $`l'`$ があり、$`\mathrm{lh}(l') \ge \rho_{l'\cdot\omega}`$
  のものもある。だから遠い頭には $`\nu`$ より下に場所があり、それらにも W-EQ が成り立つ。これで [SHIFT-ja.md](SHIFT-ja.md) §9.4 の NEAR-BLOCK の進行を止める点が直る：
  その行き先はあるので、**NEAR-BLOCK は証明済み**。
- **CAP-VIS、FREE-OFFSET**（やり直しと骨組みの点では証明済み、FRAG のもと。ほかの点ではあらすじ）。添字の距離は、構造の中ではやり直しの蓋 $`\delta + (-1 + \mathrm{logend}\,\varepsilon)`$
  を通してしか見えない。だから浅いまたぎは行き先の添字の距離を選んで決められ、$`\eta'_i = \omega^N\cdot i + \omega^{1+l'_i}`$。いちばん上の順序数の上の写像 $`T`$ は要らない。これで
  NEAR-BLOCK と、浅い遠い配置 (F1) が扱える。
- **RE-PLACE**（証明済み、FRAG のもと、査読者の 2 つの直しをして）。帰着 RED-TF が求めるのは、いちばん上の点の上の何かの写像で、錨の写し $`\mu`$ ではない。だから
  いちばん上の点はどれも、小さい順に、それぞれの規則で置ける：天井 $`\nu`$ の下の W-EQ、FREE-OFFSET、区域の骨組み、$`\varepsilon`$ 数でない点の規則。天井はもう無いので、
  (E1) は 3 つの場合とも、場所の失敗も、浅い遠い配置も、もう障害ではない。（あらすじ：一般の形の頭 HEAD-GEN と帳簿。）直し：小さいやり直しは KV0 と FRESH で
  直接置く。$`\varepsilon`$ 数でない点の規則は大きい指数をとる。論文の規則は 2 つの点を同じ値に送りうるから。
- **訂正**（査読者。16 回目の LT から受け継いだ誤り）：W-EQ と HEAD-TAIL は、頭 $`h = \delta_1`$、尾 $`t = 1`$ では成り立たない。やり直したちの極限である最小のやり直しの
  届く先は $`\delta + 2`$ で、$`\delta + 1`$ ではない。証明は TOP-REG⁺ を $`y = \delta_1`$ で使うが、TOP-REG⁺ はそこを除いている。この場合はほかでは使っていない。後続型のやり直し（logend が 2 のもの）は
  今は KV0 と FRESH で置く。
- **DEEP-UNC**（証明済み）：記録した長いやり直しの上のまたぎは、添字の指数のずれが非可算なので、深い。
- **未証明**：$`\nu_C = \nu_S`$ も $`\nu_C \lt \nu_S`$ も。論文の残りの一覧（RES-ALL）は尽きていない（進行を止める点）。その項目：(D1) 深いまたぎ。ずれが可算で
  $`\ge \rho_u`$（上の半分は TOP-REG-FAR で、下の半分には REFL-MOV が要る。あらすじ）か、ずれが非可算（未解決。§1.1 の (P) と同じ道具が足りない）。(D2) 届く先が
  $`[u, L)`$ に Cantor の標準形の項を持つまたぎ。(D3) 自分の区域の中で $`[\delta_j\cdot\omega, \upsilon_{a+\omega j+2})`$ に届くものと、尾が 0 のもの。(D4) $`\varepsilon`$ 数だが $`\upsilon`$ 点でない、いちばん
  上の点と、2 つの帳簿の条件。そして (E4)、$`[x^\#, \nu)`$ と交わる集合。一覧から抜けているもの：遠い落ち先が $`[\delta^L_j\cdot\omega, \upsilon_{L+\omega j+2})`$ にある浅いまたぎ、遠い頭が
