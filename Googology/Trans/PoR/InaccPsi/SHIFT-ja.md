## 1. $`\nu_C \ge X_4`$、そして $`\nu_C`$ の上からの評価を 2 つの $`\le_1`$ の命題に帰着

記号は [THETA-ja.md](THETA-ja.md) §1 と §9.1 と同じ：$`H(\eta) = \psi_{\Omega_1}(\Omega_\omega + \theta\cdot\eta)`$、$`\theta_2 = \psi_{\Omega_3}(\Omega_\omega)`$、$`G(\zeta) = \psi_{\Omega_2}(\Omega_\omega + \theta_2\cdot\zeta)`$、$`\iota'`$ と $`R`$ もそこと同じ。新しく：

```math
G_2 = G(\omega^2) = \psi_{\Omega_2}(\Omega_\omega + \omega^{\theta_2+2}),\quad P' = \psi_{\Omega_2}(\Omega_\omega\cdot 2),\quad L(\xi) = \psi_{\Omega_1}(\Omega_\omega\cdot 2 + P'\cdot\xi).
```

添字の指数が $`\eta_\lambda = \eta_0 + \omega^{e}`$（カントールの標準形）のやり直し $`\lambda`$ について、$`m_\lambda`$ は、$`-1 + e`$ が $`\Omega_2`$ より小さければそれ、そうでなければ $`\pi_{\eta_\lambda}`$。
届く先が $`\rho_{\lambda+\omega^2}`$ より小さいやり直しを **短い**、そうでないものを **長い** と言う。$`\tau`$ 点とは $`j \ge 1`$ の点 $`\upsilon_{\lambda+\omega j}`$。

- **直した形式的な届く先**（証明済み、査読 2 回）。[THETA-ja.md](THETA-ja.md) §9.1 の直しを書き出した：反映される点の定義、TOP-REG、届く先の補題、$`R`$ の定義と
  その系「届く先 $`\le R`$」で、候補 $`y`$ はどれも $`\gt \delta`$、TOP-REG では $`y \gt \delta_1`$。反映の補題は (L′) になる：$`(\delta, y)`$ のどの $`y'`$ も反映されるなら $`\rho \le_1 y`$
  （FRAG のもと）。古い形は $`\mathrm{logend}(\eta_\lambda) = 2`$ のどのやり直しでも偽。反例は $`\lambda = \omega^2`$ で、その届く先は $`\delta + 1`$。
- **補題 L$`_R`$ の最初の場合**（証明済み）。14 回目の査読者の注意（[THETA-ja.md](THETA-ja.md) §9.1）を直す：logend が 2 のやり直しのすぐ下にはやり直しが無いので
  $`\delta`$ は反映されず、最初の場合は反映の補題ではなく、ブロックの的についての歩みの補題（歩み 1）を使う。結論は同じ。その査読のほかの細かい点も反映した。
- **TOP-REG⁺**（SKEL⁺ の水準で証明済み。SKEL⁺ を最初の査読者はあらすじとして認め、今は SKEL⁺ が証明済み、[COVER-ja.md](COVER-ja.md) §5.1）。TOP-REG は
  $`\Lambda^*`$ までだけでなく $`\nu_S`$ より下のどのやり直しでも成り立つ。下の補題が $`\lambda \le \Lambda^*`$ を仮定するのは骨組みの事実を得るためだけで、$`\nu_S`$ が
  やり直しなので SKEL⁺ が $`[0, \nu_S)`$ でそれを与える。（査読者はどの下の補題も確かめた。論文は 1 つずつ挙げるべき。16 回目にそうした、§8.1。）
- **R-CAP\***（証明済み、FRAG 無し）。$`\nu_S`$ より下で $`m_\lambda \lt G_2`$ のどのやり直しも短い。**LONG-CLASS**（証明済み。査読者：$`m`$ が定まる
  $`\min(\nu_S, \psi_{\Omega_1}(\Omega_\omega\cdot 2))`$ より下で述べること）：だからそこの長いやり直しは $`m_\lambda \ge G_2`$。
- **補題 TL と定理 X4**（証明済み、FRAG 無し）。FIRST-PAIR、補題 GHOST、TAIL（[BREAK-ja.md](BREAK-ja.md) §2）と合わせて、NU-CT のどちらの場合でも：

```math
\nu_C \ge X_4 = H(\theta_2\cdot\omega^2 + \omega^{G_2+1}\cdot 2) = \psi_{\Omega_1}(\Omega_\omega + \omega^{\theta_2+2} + \omega^{G_2+1}\cdot 2) \gt X_3.
```

だから **$`R_2^C`$ での Wilken の主張は $`[0, X_4]`$ で両方の半分とも成り立つ**（FRAG 無し）：核の側は $`[0, \nu_C] \subseteq \mathrm{Core}(R_2^C)`$ から、名前の側は補題 L と
IS から。また $`\nu_S \ge X_4`$ で、NU-CT の場合 (A) では左端 $`a_0`$ は $`\ge H(\theta_2\cdot\omega^2 + \omega^{G_2+1})`$。

- **SHIFT**（証明済み）。Wilken 2020, Thm 21.13 の証明を 1 段上げて、$`+`$ 付きの $`R_2^S`$ で：$`a`$ が $`c_{n+1} \le_1 a`$ となる点 $`c_n`$ の上限で、$`[a, b)`$ のどの有限の
  部分も、$`c_n`$ を動かさない埋め込み $`c_{n+1} \to b`$ による $`[c_n, c_{n+1})`$ の像なら、$`a \lt_2 b`$（Prop 21.11。正確な仮定を確かめた）。
- **未証明**：名前の付いた組 $`(L(\omega), L(\omega+1))`$ での SHIFT。3 つの命題が要り、どれも未解決：$`L(n)`$ と $`L(\omega)`$ での長い届く先についての (C1) と (C2)、
  そして [BREAK-ja.md](BREAK-ja.md) §8.3 で未解決のままの届く先の条件 (C3)。（査読者：(C1) は共終に多い $`n`$ しか与えないので部分列に移ること。(C2) はどの $`x \lt c_n`$ も
  扱うべきで、$`\mathrm{lh}(L(n)) \ge L(\omega+1)`$ となる $`n`$ を選べば成り立つ。）
- **NU-MIN**（証明済み。$`R_2^C`$）。最小は $`\nu_C`$ での組の左端でとられる：

```math
\nu_C = \min\{\, \mathrm{lh}_C(a) : a \text{ additive principal, not a } \tau\text{-point, } \{\alpha \lt a : \alpha \le_1 \mathrm{lh}_C(a)\} \text{ cofinal in } a \,\}.
```

  （$`a`$ は加法的主要数で $`\tau`$ 点でなく、$`\mathrm{lh}_C(a)`$ に $`\le_1`$ な $`a`$ より下の点が $`a`$ の中で共終。）Carlson の最小性（Thm 14.10 (2)）が $`\lt_2`$ の組を
  与えるので、上からの評価に SHIFT は要らない。
- **CPB と CPB-S**（証明済み）。$`a \lt b`$、$`a`$ は加法的主要数で $`\tau`$ 点でないとする。$`R_2^S`$ で (P) 共終に多い $`\alpha \lt a`$ が $`\alpha \le_1 b`$、かつ (Q) $`a \le_1 b + 1`$ でない、
  なら $`\nu_C \le b`$。（査読者：$`\mathrm{lh}_C(a) = a`$ の場合を 1 行で除くこと。）補題 TL により、$`a \le \nu_S`$ が $`\rho_{\Lambda^*}`$ より上で $`\psi_{\Omega_1}(\Omega_\omega\cdot 2)`$ より下の
  やり直しなら、(P) から $`a = H(\eta_a)`$、$`\eta_a \ge \theta_2\cdot\omega^2 + \omega^{G_2+1}`$（後ろの 2 つの仮定は査読者が足した）。
- **名前**（含意として証明済み）。$`(L(\omega), L(\omega+1))`$ で (P) と (Q) が成り立てば $`\nu_C \le L(\omega+1) = \psi_{\Omega_1}(\Omega_\omega\cdot 2 + \omega^{P'+1} + P')`$。予想 NU-NAME
  （[BREAK-ja.md](BREAK-ja.md) §2）はそこで (P) と (Q) を導く（(Q) は CAP を通して、と査読者）。$`[0, \nu_C]`$ での主張は $`\nu_C \lt \psi_{\Omega_1}(I_\omega)`$ と同値（`bounded_inter_Om1` から）なので、それより下の名前の
  付いた評価ならどれでも足りる。
- **未証明**：$`\nu_C`$ の InaccPsi による上からの評価と、$`(X_4, \nu_C]`$ での主張。足りないのは名前の付いた 1 つの組での (P) と (Q)。(P) は長いやり直しの届く先の
  下からの評価、(Q) は上からの評価で（区域 C）、今のどの道具も与えない。

## 2. 素の符号：$`\Omega_1^\omega`$ より下の作用素の階層と $`\iota(\mathrm{CH}_2) \ge Z_K`$

記号は [THETA-ja.md](THETA-ja.md) §2 と §9.2 と同じ：$`F(\alpha) = \upsilon_{1+\alpha}`$、$`H'(\Delta) = \psi_{\Omega_1}(\Omega_\omega + \omega^{\theta+\Delta})`$。位置とは順序数 $`P \lt \Omega_1^\omega`$ で、
可算の係数で $`\Omega_1`$ 進に書く。$`O_1`$ は不動点を数え上げ、$`O_{P+1}`$ は $`O_P`$ の対角、係数の極限では共通部分、$`l \ge 1`$ で $`P = Q + \Omega_1^l\cdot(\mu+1)`$ では
$`O_P(H)`$ は $`O_{Q + \Omega_1^l\cdot\mu + \Omega_1^{l-1}\cdot z}(H)(0) = z`$ となる $`z`$ を数え上げる。[THETA-ja.md](THETA-ja.md) §9.2 の $`O_n`$、$`S`$、$`T`$ は位置 $`n`$、$`\omega`$、$`\omega+1`$。

- **OP-K、POS、DATA、DOM-K、NO-HIGH-K**（証明済み。査読者はどの場合も再帰の順も確かめた。査読者：DOM-K は包で定めた階層の比較の片方の向きに
  あたるもので、2 つのつながりは予想）。どの $`O_P`$ も作用素。$`O_{\Omega_1^\omega}(F)`$ の値域の外の
  $`\upsilon`$ のどの不動点も、位置の貪欲な署名を持つ。2 つの不動点は、小さい方のデータのどの順序数も他方の点より小さいとき、データで比べられる。順は

```math
\Lambda_T \lt O_{\omega+2}(F)(0) \lt \Lambda_P = O_{\Omega_1}(F)(0) \lt \Lambda_K = O_{\Omega_1^\omega}(F)(0) \lt Z_K,
```

$`Z_K`$ は $`O_{\Omega_1^\omega}(F)`$ の最小の不動点。

- **型 K、CHAIN-K、CHAIN-TOP、CHAIN-Y、LEX-HOST-K、(MC)、TOP の族**（証明済み）。不動点の部品は段の入れ子で、署名の項 1 つに段が 1 つ。段は
  位置の $`\Omega_1`$ 進の係数を 1 つずつ内側の鎖で符号にし、上の元は $`u^l \le_1 u^l + u^{l+1} + q^l`$ を満たす（飾りは内側の鎖の根 $`q^l`$ を指す）。段は位置の小さい
  どの段も宿し（CHAIN-K）、部品 $`c \le_1 c\cdot 2`$ はどの段も宿す（CHAIN-TOP）。[THETA-ja.md](THETA-ja.md) §9.2 の妨げは LEX-HOST-K の 1 つの場合になる。
- **定理 IDX-K**（証明済み）。素の符号で $`\iota(\mathrm{CH}_2) \ge Z_K`$。また部品 $`[r, x \lt_2 y, c \le_1 c + y]`$ で $`\iota \ge \Lambda_P`$、$`[r, x \lt_2 y, c \le_1 c\cdot 2]`$ で
  $`\iota \ge \Lambda_K`$。これらが (0,0,0)(1,1,1)(2,1,1)(3,1,1) と (0,0,0)(1,1,1)(2,2,0) の conv のパターンであることは確かめただけ。どちらも BMS の順で SRO より上なので、
  分かっている値とは矛盾しない。
- **FRESH、CHAIN-REL**（証明済み。査読者：CHAIN と CHAIN⁺ が $`x`$ より下のパラメータを許すことは、別の補題として書くこと）。$`A \ge x`$ で $`c \le_1 c + A`$ を
  持つ部品は、外側の左端 $`x`$ を使う相対的な鎖と相対的な飾りの付いた部品をすべて宿す。例：$`V_x \ll [n_0][Y]`$。
- **未証明**：「CHAIN-REL は宿した相対的な符号を宿り先の組の中のどこにでも置く」。$`x`$ を新しい点に置き換えると普通の鎖か飾りの付いた部品に
  なる構造でしか成り立たない。相対的な符号 $`N^x(P)`$ は定めておらず、その形は書かれていない補題。
- 予想する名前：$`\Lambda_K = H'(\Omega_1^{\Omega_1^\omega})`$、$`Z_K = H'(\Omega_1^{\Omega_1^\omega} + \Omega_1)`$。まだ $`\Lambda_\varepsilon`$ より下で、進んだのは素の道だけ。
- **未解決**：$`\iota(\mathrm{CH}_2) \ge \theta_0`$。次は $`O_{\Omega_1^\omega}(F)`$ の不動点のための (MC)（あらすじだけ）、それから $`\Omega_1^\omega`$ 以上の位置：相対的な符号、
  その比較 REL-S⁺、$`\Omega_1^{\Omega_1^\omega}`$ より先の比べる補題。

## 4. $`\nu_C = \nu_S`$：閉じた形の層をもう 1 つ、すべての記号での (PROF)、幽霊の判定

記号は [THETA-ja.md](THETA-ja.md) §4 と §9.4 と同じ。$`\mathrm{LT}(y)`$ は「$`y`$ より上のある長いやり直しの届く先の、カントールの標準形の最後の項が $`y`$」。

- **FRESH′、すべての $`\upsilon_{\iota+\zeta}`$（$`\zeta \lt \omega^2`$）を含む骨組み、TW-MIX′**（証明済み、査読 2 回）。14 回目の査読の直しを書き出した：新しい添字は
  $`\theta'' + \omega^{1+l'}`$。だから [THETA-ja.md](THETA-ja.md) §9.4 の TW-MULTI と TW-MIX はそこに書いたとおり成り立つ。（査読者：値は区域ごとに増える順で定めること。）
- **CLOSE、ISO-INV、EPS-VIS、HER**（証明済み。HER は 2 つの帳簿の仮定のもと）。いちばん上の点の届く先・和・ブロックのデータを書き留めることは
  有限回で止まり、これらの事実は同型な延長で保たれる。査読者の例 $`\omega^{\rho_a+1}`$ は受け継ぐ写しで扱える。
- **KV-Δ、CF-Δ⁺、FRESH-Δ**（LADDER と同じ仮定のもとで証明済み）。対角の類の上に閉じた形の層がもう 1 つ：$`\mathrm{Fix}(f_\Delta)`$ にあって臨界の類 $`K^{f_\Delta}`$ に
  無い添字で、決まった形が $`(A, \eta)`$ なら、ずれは $`\rho^{\rho+1} + P_A(\rho) + \mathrm{logend}(\eta)`$。だからどの長いやり直しも、$`U_2`$ のどの点も、$`\nu`$ も、添字は $`K^{f_\Delta}`$
  にあり、ほかのやり直しの添字はどれも $`\delta\cdot 2`$ より下の閉じた届く先を持つ。
- **LADDER-TAIL、DICT-n、PROF-n**（証明済み）。係数が $`u`$ より小さいどの記号でも、$`u`$ 以上の位置がいくつあっても (PROF) が成り立つ。だから「位置が 2 つ以上の
  (PROF)」の項目は閉じた。
- **CAND-2-SHAPE、SEP-RED**（帰着として証明済み）。$`a`$ の区域の外の錨 $`b \lt a \le \mathrm{lh}(b)`$ は長いやり直し。
- **OCC、G-SCHEMA、G-TAIL**（証明済み）。ちょうど尾 $`u_m`$ の CAND-1 が起きるのは $`\mathrm{LT}(u_m)`$ のときに限る。$`\Sigma_1`$ のパターン $`P`$ について：十分大きいすべての $`u_n`$ で
  $`P`$、かつ $`x`$ で $`P`$ でないなら $`\nu_C \lt \nu_S`$。$`\Pi_1`$ の性質「$`z \gt y`$ のすべてで $`y \le_1 z`$、かつ $`\mathrm{LT}(y)`$ でない」が $`x`$ より下の構造と $`\nu`$ より下の構造を
  分ける（幽霊）のは、十分大きいすべての $`n`$ で $`\mathrm{LT}(u_n)`$ が成り立ち $`\mathrm{LT}(x)`$ が成り立たないときに限る。（査読者：OCC では、$`u_{m+1}`$ より上の証人はまずその下に移すこと。

### 8.4 $`\nu_C = \nu_S`$：LT はどこでも成り立つので、§4 の性質は幽霊ではない
