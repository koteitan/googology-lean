# 骨組みが終わる所の $`R_2^+`$：INC1、骨組み型でない最初の点、扇から作る鎖、有限の閉包

このページは [PINS-ja.md](PINS-ja.md) の続き。状態の言葉は [README-ja.md](README-ja.md) の §3 と同じ：**証明済み**は、独立した
査読者が、致命的な点も止める点も無く証明済みと判定したもの。このページの結果はどれも 2026-10 のもので、4 つの論文
から来ている。どの論文も 1 回ずつ査読された。「査読 1 回」は査読者 1 人。「査読 2 回」は、独立した 2 つの論文がその
結果を証明し、それぞれが 1 回ずつ査読されたこと。査読者が未証明、または書いたままでは偽と判定した命題は、その論文の
ほかの部分が証明済みでも **未証明** に書く。4 つの論文はどれも Wilken, JSL 72 (2007)、Carlson, AML 38 (1999)、
Wilken, AML 45 (2006) を使わない。このページの結果はどれも Lean には無い。

**記号。** [REACHES-ja.md](REACHES-ja.md) と [PINS-ja.md](PINS-ja.md) と同じ。$`\nu_P = \upsilon_{\Lambda^*+\omega^2}`$ は定理 SKEL の終わり。
$`\mathrm{lh}_1(a)`$ は $`R_1^+`$ での $`a`$ の届く先。隙間とは、となり合う 2 つの $`\upsilon`$ の点の間の区間。**標準の組**とは
$`\lt_2`$ の組 $`(\upsilon_{\lambda+\omega j}, \upsilon_{\lambda+\omega j+1})`$（$`\lambda = 0`$ かやり直しの添字、$`j \ge 1`$）。それ以外の $`\lt_2`$ の組は**新しい組**。
**扇**とは $`\lt_2`$ の後の元を 2 つ持つ点。PS は「$`x \lt u \lt v \lt y`$ で $`x \lt_2 y`$ かつ $`u \lt_2 v`$」というパターン（中に別の組が
入れ子になった組）。$`\theta' = \psi_{\Omega_2}(\Omega_\omega\cdot 2)`$。

## 1. INC1：1 つの仮定に帰着

INC1-S は「$`R_2^S`$ で $`a \le_1 b`$ なら $`R_1^+`$ でも $`a \le_1 b`$」。INC1-nonups は $`R_2^C`$ での同じ命題。$`a`$ が $`\upsilon`$ の点なら
どちらも自明。$`R_1^+`$ では $`\upsilon`$ の点はその上のすべてに $`\le_1`$ だから。

- **前の「INC1-S は $`R_2^S`$ では自明」は誤り**（証明済み、査読 1 回）。$`R_2^S`$ の $`\le_1`$ は $`R_2^S`$ の言語での $`\Sigma_1`$ で、
  $`R_1^+`$ の言語でのものではない。だから写しは $`R_1^+`$ の $`\le_1`$ の事実を保つとは限らない。
- **補題 LEFT-AT**（証明済み、査読 1 回）。補題 LEFT が INC1 を要るのは自分の右端だけ：$`\alpha \lt_2 \beta`$ で、組 $`y \le_1 \alpha`$ で
  INC1 が成り立つなら、$`\lambda`$ が極限の $`\alpha = \upsilon_\lambda`$。補題 LEFT-SK も証明済み（査読 1 回）。
- **悪い右端。** $`\upsilon`$ の点でない点 $`b`$ が**悪い右端**とは、$`v \lt x \lt b`$ で $`v \lt_2 b`$、$`x \lt_1 b`$、$`x`$ は $`b`$ の隙間にある
  $`\upsilon`$ の点でない点、となるものがあること。このとき $`v`$ は扇（$`v \lt_2 x`$ かつ $`v \lt_2 b`$）。$`b^*_S`$、$`b^*_C`$ は最小の悪い右端。
  **予想 NOBAD**：悪い右端は無い。これは **予想 RIGHT**（どの $`\lt_2`$ の右端も $`\upsilon`$ の点）から出る。
  （定義の「$`v \lt x`$」は査読者が足した。証明はそういう $`v`$ しか作らない。）
- **定理 INC1-LOC**（証明済み、査読 1 回。$`R_2^S`$）。右端が $`b^*_S`$ 以下のどの組でも INC1-S が成り立つ。だから NOBAD なら
  INC1-S。証明の考え：成り立たない最小の右端 $`g_0`$ をとると、ある $`x`$ で $`g_0 = \mathrm{lh}_1(x) + 1`$。$`x`$ より下のどの点も
  $`(x, g_0)`$ に $`\lt_2`$ の後の元を持たないなら、写しの議論が Wilken, APAL 145 (2007) 162–175 の Claim 5.6 に矛盾する。
  そうでなければ $`g_0`$ より下に悪い右端がある。
- **定理 INC1-LOC-C**（CC を仮定して証明済み、査読 1 回）。$`R_2^C`$ でも同じ。**CC**（未解決）：固定した下の集合の上での
  $`R_1^+`$ の写しを、カントール標準形の部分で閉じるように選べること。Carlson 2001 は固定した下の集合が無い形しか
  証明していない（L.5.3 と L.3.18 からは出ない）。
- **下界**（証明済み、査読 1 回）。$`b^*_S \gt \nu_P`$（定理 SKEL：$`\nu_P`$ より下ではどの左端も後の元を 1 つしか持たない）。
  $`b^*_C`$ は $`\Phi_3(\mathrm{SRO})`$ の点より上（再生した証明書から：$`R_2^C`$ のどの扇もその点より上）。
- だから **補題 LEFT** が成り立つ（査読 1 回）：$`R_2^S`$ では $`b^*_S`$ 以下のどの左端でも、だから $`[0, \nu_P]`$ で。$`R_2^C`$ では
  CC を仮定して $`b^*_C`$ 以下のどの左端でも。NOBAD を仮定すれば（$`R_2^C`$ では CC も）どこでも。

LEFT を使っていた結果。「NOBAD を仮定して」は、$`R_2^S`$ では NOBAD を、$`R_2^C`$ では NOBAD と CC を仮定すること。

## 2. 骨組み型でない最初の点

$`\nu_S`$ は $`R_2^S`$ が骨組み型でなくなる最初の点（[REACHES-ja.md](REACHES-ja.md) §4）。$`\nu_{new}`$ は新しい組の最小の右端、
$`\nu_{nest}`$ は PS の実現の最小の上端 $`y`$。

- **前提の訂正**（証明済み・引用、査読 1 回）。$`\nu_P`$ は骨組み型でない点ではない：$`R_2^S`$ は $`[0, \nu_P]`$ で骨組み型（定理
  SKEL）なので $`\nu_S \gt \nu_P`$。また最初に破れる所は扇ではない（下の CAP）。
- **定理 SKEL⁺**（証明済み、査読 1 回。$`R_2^S`$。FRAG なし）。定理 SKEL の記述は $`[0, \nu_{new})`$ で成り立つ。変わるのは 1 つ
  だけ：やり直しの点が $`\lt_1`$ の前の元を持ってよく、それはちょうど、届く先がその点を覆う、それより下のやり直しの点。
  組は標準の組、ブロックの点はブロックの上限を持ち、やり直しの点の届く先は閉じている。だから $`[0, \nu_{new})`$ で
  $`R_2^S`$ は骨組み型で、INC1-S と LEFT が成り立つ。査読者は小さな穴を 2 つ（ある上限の選び方と、SKEL を自分の終わりの点
  で使った 1 か所）見つけ、それぞれに直し方を出した。
- **定理 FIRST-PAIR**（証明済み、査読 1 回。$`R_2^S`$。FRAG なし）。$`\nu_S = \nu_{new} = \nu_{nest}`$。これを $`\nu`$ と書く。
  - 破れるのは標準でない $`\lt_2`$ の組。届く先を切る $`\upsilon`$ の上限は $`\nu`$ 以下では起きない。
  - 右端が $`\nu`$ 以下の新しい組はちょうど 1 つ：$`(a_0, \nu)`$。$`a_0`$ は最小の新しい左端。$`\omega^3 \mid \Lambda`$ で $`a_0 = \rho_\Lambda`$。
    その $`\lt_1`$ の前の元はその下で共終。それらはやり直しの点で、$`\lt_1`$ の鎖をなし、どれも届く先がちょうど $`\nu`$。
    その最小のものを $`m_0`$ と書く。
  - $`\nu = \rho_{\mu_0}`$ はやり直しの点で、$`\omega^3 \mid \mu_0`$、$`\mu_0 \ge \Lambda + \omega^3`$。標準の組とやり直しの点の極限。
  - PS の最小の実現は、最小の点が $`a_0`$、上端が $`\nu`$。これは [REACHES-ja.md](REACHES-ja.md) §4 の予想 NS の $`R_2^S`$ 版
    （名前を除く）。
- **補題 CAP**（証明済み、査読 1 回。$`R_2^S`$ と $`R_2^C`$）。$`\alpha \le \nu_{nest}`$ ならどれも $`\mathrm{lh}(\alpha) \le \nu_{nest}`$。証明：「中に
  別の組が入れ子になった組がある」はパラメータの無い $`\Sigma_1`$ の文。$`R_2^S`$ での帰結：
  - $`\mathrm{lh}(a_0) = \nu`$。$`a_0`$ の $`\lt_2`$ の後の元はちょうど 1 つ。
  - $`\mathrm{lh}(\nu) = \nu`$：$`\nu`$ は自分の最初のブロックの上端に届かない最初のやり直しの点。
  - 頂点が $`\nu`$ 以下の扇は無い。長さ 3 のどの鎖も $`c_0 \gt \nu`$、そして $`m_3 \gt \nu`$。それより大きいすべての順序数に $`\le_1`$
    となる最小の $`\kappa`$ は $`\gt \nu`$。
- **査読 2 回。** 「$`R_2^S`$ のどの扇の頂点も $`\ge \nu_P`$、そして $`m_3 \gt \nu_P`$」は **査読 2 回** になった：CAP が $`\nu \gt \nu_P`$ を通して
  与え、§3 の定理 M-S が独立に証明する。
- **$`R_2^C`$**（証明済み、査読 1 回）。$`R_2^C`$ での PS の最小の実現の上端を $`T_C`$ とする。INC1 も CC も使わずに
  $`\nu_C \le T_C`$、CAP が成り立ち、$`[0, T_C] \subseteq \mathrm{Core}(R_2^C)`$。証明書「$`T_C`$ は $`\Phi_3`$（28 行目）の点より下」（再生済み）と
  合わせて、$`\nu_C`$ は [README-ja.md](README-ja.md) §6 の表の 28 行目の $`\Phi_3`$ の点より下。これでどんな仮定も要らない。
  $`\nu_C = T_C`$ か、$`\nu_C = \nu_S`$ かは未解決。
- **証明書**（$`R_2^C`$。著者が再生し、そのうち 4 つを査読者がもう一度再生した）。$`Q`$ = (0,0,0)(1,1,1)(1,1,1)（27 行目）、
  $`K`$ = (1,1,0)(2,2,1)(2,2,1)、$`M_a = QK(2,0,0)`$、$`M_\nu = M_a(1,1,0)(2,2,1)(2,2,1)`$ とする。PS の最小の点は $`\Phi_3(QK^3)`$ と
  $`\Phi_3(M_a(1,0,0))`$ の点の間、$`T_C`$ は $`\Phi_3(M_\nu[2])`$ と $`\Phi_3(M_\nu(1,0,0))`$ の点の間。最小の扇のパターン PT の点は
  $`\Phi_3(\mathrm{SRO})`$ の点より上で $`m_3`$ より下。
- **定理 GEN-EXT**（証明済み、査読 1 回）。定理 GEN（[PINS-ja.md](PINS-ja.md) §3）は $`\eta \lt \Omega_\omega\cdot\omega`$ でもそのまま成り立つ：
  $`D`$ に入るそういう $`\eta`$ のどれでも $`\psi_{\Omega_1}(\Omega_\omega + \theta\cdot\eta) = \upsilon_{1+\iota(\eta)}`$。**補題 RI3**：$`\iota(\eta)`$ が $`\omega^3`$ の倍数
  であることと $`\mathrm{logend}(\eta) \ge 3`$ は同じ。査読者の無作為な試験：480 個の $`\eta`$ で食い違い 0。
- **予想 NU-NAME**（標準形であることと大小は Python と Lean で確認済み）：$`m_0 = \psi_{\Omega_1}(\Omega_\omega\cdot 2)`$、
  $`a_0 = \psi_{\Omega_1}(\Omega_\omega\cdot 2 + \omega^{\theta'+1})`$、$`\nu = \psi_{\Omega_1}(\Omega_\omega\cdot 2 + \omega^{\theta'+1} + \theta')`$。最初の新しい組は
  $`(\upsilon_\omega, \upsilon_{\omega+1})`$ を 1 段上に写したもの、という予想。査読者の注意：Ytosk の読み方からの材料は、読み方の
  間の辞書での 1 つの新しい選び方だけに頼っている。ほかの 2 つの選び方は別の項を与える。
- **最初の扇**（証明済み、査読 1 回）。$`R_2^S`$ ではその頂点は $`\nu`$ より上の新しい左端で、後の元は 2 つとも $`\nu`$ より上。
  $`R_2^C`$ では $`\Phi_3(\mathrm{SRO})`$ の点より上（証明書）。名前は未解決。

## 3. 扇から作る長さ 3 の鎖

$`C_l`$ は [PINS-ja.md](PINS-ja.md) §4 のはしごの集まり（$`C_1`$ は $`\iota \mapsto \upsilon_\iota`$ の不動点）、$`f`$ は $`C_{\omega^\omega}`$ を並べる関数、
$`(C)'`$ は $`C`$ の極限点の集まり。「LEFT を仮定して」は、$`R_2^S`$ では INC1-S を、$`R_2^C`$ では INC1-nonups を仮定すること。
§1 により、これは NOBAD（$`R_2^C`$ では CC も）から出る。

- **定理 CF**（証明済み、査読 1 回。$`R_2^S`$ は査読者が引用を直した形、それと $`R_2^C`$）。いちばん下が $`a`$、まん中が $`e`$ の長さ 3 の
  鎖があることと、$`a`$ の $`\lt_2`$ の後の元が $`e`$ の中で共終で、$`e`$ が $`\lt_2`$ の後の元を持つことは同じ。だから長さ 3 の鎖とは
  ちょうど、後の元を無限に持ち、その極限が自分も左端である扇。**系 LEAST**（$`R_2^C`$）：$`c_0`$ は鎖のいちばん下の最小のもの、
  $`c_1`$ は $`c_0`$ の後の元のうち最小の左端、$`c_2`$ は $`c_1`$ の最小の後の元。
- **補題 PI2-UP と補題 PC**（証明済み、査読 1 回）。$`y \le_2 e`$ なら、$`y`$ の下で共終な有限の配置はどれも $`e`$ の下で共終。長さ 3 の
  どの鎖でも、組、扇、はしごのすべての段 $`l \lt \omega^\omega`$ の配置が、$`c_0`$ の下、$`c_0`$ の各後の元の下、$`c_1`$ の下で共終。
  $`c_0`$ の後の元は $`c_2`$ の中で共終。
- **定理 RE**（LEFT を仮定して証明済み、査読 1 回）。$`y`$ の下で組が共終で $`y \lt_2 e`$ なら、$`\mu`$ がやり直しの添字の $`e = \upsilon_\mu`$。
  さらにはしごのすべての段 $`l \lt \omega^\omega`$ の配置が $`y`$ の下で共終なら $`e \in C_{\omega^\omega}`$。
- **定理 C3′′-FALSE**（LEFT を仮定して証明済み、査読 1 回）。長さ 3 のどの鎖でも、$`c_0, c_1, c_2`$ と、$`c_0`$ と $`c_1`$ のどの後の元も
  $`C_{\omega^\omega}`$ に入り、$`c_0, c_1, c_2`$ は $`C_{\omega^\omega}`$ の極限点。だから予想した形 C3′′、
  $`C^*_3 = \{\upsilon_\Lambda, \upsilon_{\Lambda+\omega}, \upsilon_{\Lambda+\omega+1}\}`$ は偽で、C3-VEB（[PINS-ja.md](PINS-ja.md) §4）に書いた C3′′ の帰結は
  中身が無い。論文は文字どおりには「どの鎖 $`\upsilon_\mu \lt_2 \upsilon_{\mu+1}`$ も」除くと言うが、査読者はこれを長さ 3 の鎖の
  つなぎ目に限る（標準の組は実際にある）。
- **名前**（証明済み、査読 1 回。NAME-V から）。$`C_g`$ は $`V_g`$ の不動点の集まり（$`g \ge 1`$）。だから $`1 \le l \le \omega^\omega`$ で
  $`\min C_l = \psi_{\Omega_1}(\Omega_\omega + \omega^{\theta+\Omega_1\cdot l})`$、$`C_{\omega^\omega}`$ の最小の極限点は
  $`\Lambda_{struct} = \psi_{\Omega_1}(\Omega_\omega + \omega^{\theta+\omega^{\Omega_1+\omega}+1})`$。前はどちらも予想だった。
- **定理 NO-CHAIN-AT-$`\Lambda_{struct}`$**（証明済み、査読 1 回。条件なし）。$`\Lambda_{struct} \lt \Lambda_\varepsilon \lt \nu_P`$、
  $`\Lambda_{struct} \lt \rho_{\Theta_A+\omega^2}`$。これは $`\lt_1`$ の前の元を持たないやり直しの点なので、$`\lt_2`$ の後の元をまったく持たない
  （$`R_2^S`$ では SKEL、$`R_2^C`$ では EQB-A）。$`\Lambda_{struct} \lt \nu_P`$ の最初の証明。前は予想した名前からしか出なかった。
- **定理 M-S**（証明済み、査読 1 回。$`R_2^S`$。条件なし）。どの扇の頂点も $`\ge \nu_P`$、そして $`m \le_1 c_0`$ となるどの $`m \lt c_0`$ も
  $`\gt \nu_P`$。前は $`c_0 \ge \nu_P`$ だけが分かっていた。
- **評価**（LEFT を仮定して証明済み、査読 1 回）。$`R_2^S`$ では $`B = \nu_P`$、$`R_2^C`$ では $`B = \rho_{\Theta_A+\omega^2}`$ とし、$`f(a)`$ を $`B`$ より
  上の $`(C_{\omega^\omega})'`$ の最小の元とする。このとき $`c_0 \ge f(a)`$、$`c_1 \ge f(a+\omega)`$、$`c_2 \ge f(a+\omega\cdot 2)`$。$`R_2^S`$ での $`c_0`$ の評価は
  分かっていた。$`c_1`$、$`c_2`$ の評価と $`R_2^C`$ の形が新しい。その名前は予想で、どれも
  $`\psi_{\Omega_1}(\Omega_\omega\cdot 2) \lt \theta_0`$ より下。だから構造の理論だけではまだ到達不能基数が要らない。
- **定理 GEN の訂正**（証明済み、査読 1 回）。GEN が名前を付けるのは $`\upsilon^* = \sup H[D] \le \psi_{\Omega_1}(\Omega_\omega + \Omega_2)`$ より下の
  $`\upsilon`$ の点だけ。$`\upsilon`$ の点は $`\omega_1`$ の中で共終なので、「すべての $`\upsilon`$ の点に名前がある」（これらのページの前の版に
  書いた）は偽だった。GEN-EXT（§2）が名前を $`\eta \lt \Omega_\omega\cdot\omega`$ まで延ばす。査読者の無作為な試験：315 個で違反 0。

  作る方法を与えない。CF は問題を言い換えたもの（「$`e`$ が左端」）で、中身のある新しい結果は LEFT が要る。

## 4. 有限の閉包と $`\Theta_A`$ より先の届く先

$`C_\tau(z)`$ は $`\{0, \tau, z\}`$ を、カントール標準形の部分と部分和、$`\mathrm{lh}`$、バーの操作で閉じたもの（[PINS-ja.md](PINS-ja.md) §1）。

- **定理 CL-FIN**（証明済み、査読 1 回）。どの基 $`\tau \in \{1\} \cup E`$ とどの $`z \in [\tau, \tau^\infty)`$ でも $`C_\tau(z)`$ は有限で、その大きさは
  $`z`$ の大きさの初等的な式で抑えられる。証明の考え：$`\mathrm{lh}`$ が新しい項を作るのは「子」を通してだけで、子は親より
  Wilken の高さが小さい（Wilken, APAL 145 (2007) 130–161, L.7.14 の計算）。$`z \mapsto C_\tau(z)`$ が初等再帰的であることは
  概略だけ（数えない）。
- **LHPAR\*。** [PINS-ja.md](PINS-ja.md) の Cl\* の形は証明済み（査読 1 回）。もっと鋭い形は **書いたままでは未証明**：Wilken の
  パラメータ（APAL 145 (2007) 130–161, Def 3.28）では成り立たない。例えば $`\tau = \varepsilon_0`$、$`a = \theta^\tau(\theta^\tau(\omega+1))`$。
  パラメータをそのカントール標準形の部分と読めば成り立つ。鋭い形はほかでは使われない。
- **定理 EXPL**（証明済み、査読 1 回）。$`C_\tau(z)`$ は強い意味（被覆がパラメータを上げてもよい）での具体的なピンの
  パターンで、$`\tau`$-最小同型で、基の付け替えと交換する。だから [PINS-ja.md](PINS-ja.md) §1 の「$`C_\tau(z)`$ が $`\tau`$-最小同型な
  ピンのパターン」は証明済み、定理 TOP-FLAT$`_1`$（[PINS-ja.md](PINS-ja.md) §2）は CL-FIN と LHPAR\* を要らなくなった。
- **代入の写像**（証明済み、査読 1 回）。基とパラメータを、増加し、加法的で、$`\mathrm{logend}`$ と交換する写像で動かすと、
  $`\mathrm{lh}`$ とバーと交換する同型になる（SUBST-ISO、SUBST-COMM）。基の付け替えは Wilken の翻訳と交換する（COMM-T）。
  **FRAG-SUBST**：補題 FRAG の写像は代入の写像と等しい。だから補助の選び方によらない（[RESTARTS-ja.md](RESTARTS-ja.md) §1 の
  最後の予想は定理になった）。
- **補題 PIN-S**（証明済み、査読 1 回）。領域の $`\delta_j`$ より下のどの区間のどの点も、やり直しの点での写しに対してピン留め
  される。だから [PINS-ja.md](PINS-ja.md) §2 の仮定 H-RC は証明済み。
- **$`r(\Theta_A)`$**（証明済み、査読 1 回）。$`R`$ で $`\mathrm{lh}(\rho_{\Theta_A}) = \delta + \varepsilon_{\sigma+\omega}`$（上界は FRAG なし、下界は FRAG を使う）。
  だから EQB-A が $`\Theta_A`$ で許していた例外の組は起きない：$`\lambda \le \Theta_A`$ のどこでも HC が成り立ち、最初の違い $`\beta_0`$ は
  $`\rho_{\Theta_A+\omega^2}`$ 以上。
- **新しい目印**（証明済み、査読 1 回）。$`\Theta_\delta`$ と $`\Theta_{d\omega}`$ は、形式的な届く先（FRAG を使わない再帰）が $`\delta_\lambda\cdot 2`$ と
  $`\delta_\lambda\cdot\omega`$ に届く最小のやり直しの添字。$`\Theta_\delta`$ での形式的な届く先は $`\delta\cdot 2`$ で、
  $`\Theta_A \lt \Theta_\delta \lt \Theta_{d\omega} \lt \Lambda^*`$。
- **系 CORE-C$`^{d\omega}`$**（証明済み、査読 1 回。FRAG なし）。$`[0, \rho_{\Theta_{d\omega}}) \subseteq \mathrm{Core}(R_2^C)`$。前は $`[0, \rho_{\Theta_A+\omega^2})`$。
- **未証明、書いたままでは偽**（止める点。$`y = \delta`$ で 1 ずれる）。定理 TOP-REG（「反映されない点は届く先を抑える」）、
  REACH (a)、「届く先 = 形式的な届く先」という主張、定理 EQB-dw の評価 $`r_C \le R`$。反例：$`\lambda = \omega^2`$ では形式的な届く先は
  $`\delta`$ だが $`\rho \le_1 \delta + 1`$。一般に、ずれが有限のとき形式的な届く先は届く先より 1 小さい。査読者の直し方（$`y \gt \delta`$ だけ
  数える）は査読の中で証明されたが、それ自身はまだ査読されていない。$`\Theta_A`$、$`\Theta_\delta`$、$`\Theta_{d\omega}`$ での値と CORE-C$`^{d\omega}`$ は
  これによらない。
