# Trans

具体的な翻訳。2 つの系を同時に import する唯一の層。

## 規則

対 `{X, Y}` には**ファイルを 1 つ**だけ置きます。名前順で先に来る方の下に置きます。

```
Trans/BMS/DBMS.lean     BMS と DBMS に関する全部
Trans/BMS/Y.lean        BMS と Y に関する全部
```

方向ごとではなく、対ごとに 1 ファイルです。両方向の模倣と、あれば `Equiv` を
同じ場所に置きます。そうしないと `Equiv` の置き場所が決まらず、2 つの方向が
離れていく。どちら側からでも引けるように、下に索引を置きます。

系は全部 [Notation](../Notation/README-ja.md) にあるので、巨大数の系から
証明論の系への翻訳も、他の対と何も変わりません。名前順で先に来る方の下に置きます。
`Trans/BMS/OTB.lean`。

## どれを作るか

仕事が済む範囲で一番弱いものを選びます。

| 構造 | 要求 | 得られるもの |
|---|---|---|
| `Sim` | 一歩が一歩に写る | 整礎性と停止性が移る |
| `StepHom` | 展開と可換、＋停止状態の対応 | `Sim` になる |
| `Equiv` | 互いに逆な `Sim` | 両側が同値 |
| `OrdHom` | 順序を保つだけ | 整礎性が移る |

`StepHom` は括弧の番号を付け替える `reindex : Nat → Nat` を持ちます。付け替えない
なら `id` を入れます。

## 較正は定理ではない

参照実装との一致は有限個の検査（`#guard`、`decide`）であって、全入力についての
証明ではありません。別ファイルに置き、上の定理と同列に読まれないようにします。
