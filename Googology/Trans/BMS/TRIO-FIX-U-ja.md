# 修正 U: 有限レベルの非可算 `u` での規則 9

[`TrioRulesAll.lean`](TrioRulesAll.lean) の上に置く、独立したパッチです。`TrioRulesAll.lean` は
[koteitan/trio](https://github.com/koteitan/trio) の規則 1–10 に、修正 A–E と N を入れたものです。
コードは [`TrioFixU.lean`](TrioFixU.lean) にあります。
検査は [`TrioFixUSheet.lean`](TrioFixUSheet.lean) にあります。

## 不具合

[TRIO-SHEET-FIXES-ja.md](TRIO-SHEET-FIXES-ja.md) の「残っていること」によると、`u = Ω+1` のとき、
`(Ω_2, Ω_Ω]` で試したどの引数レベル `w` でも、規則 9 は非標準か順序違いの行列を出します。例外はレベル
`ω`（修正 E）だけです。ほかの非可算 `u` でも同じです。

このパッチの広い探査でも確かめました。14 個の `u` について、1,865 個のラベル `ψ_{Ω_u}(Ω_w)` を使います
（下の「探査」）。修正 U がないと、下の定義域にある 562 個のうち 337 個が非標準です（yaBMS `bms -s`）。
その中の 3,080 組が順序違いです。

## 記法

- `M(v)` は `ψ_0(Ω_v)` の行列です（ビルダーの 1 段下）。
- `Ω_L ≤ u < Ω_{L+1}` のとき、`u` のレベルは `L` です。修正 U が働くのは、有限レベル `L ≥ 1` の
  後続 `u = s+1` だけです。
- `base = low M(Ω_u)`: `M(Ω_u)` の最後の列の 1 行目を 1 下げたものです。どの `M(ψ_{Ω_u}(X))` も
  `base` で始まります。
- `P = M(ψ_{Ω_u}(Ω_{Ω_{L+1}}))`（規則が出すもの）。`u = Ω+1` ではシートの行 4467 です。
- `mark = (L+1, L+1, 1)`。`P ++ mark` は引数 `Ω_{Ω_ω}` です。
- `R_n = (P ++ mark)[n]`（BM4 展開）。`R_n` は引数 `Ω_{Ω_{L+1+n}}` です。
- `L^k(m[4:])`: `m` の添字 4 以降のすべての列で、`x` と `y` に `k` を足します。
- `L'^k(m[4:])`: `x` に `k` を足します。`y` には、1 行目の祖先が列 0 に届く列だけ `k` を足します。
- `reroot src img m`: `m` は `src` で始まります。結果は `img` の後に、`m` の `src` より後の列を
  並べたものです。`src` の最後の 3 列のどれかに（0 行目で）ぶら下がる列は、`img` の最後の 3 列に
  移ります: `x + dx`、相対列（規則 3）では `y + dy` です。それ以外の列はそのまま写します。

## 変更

規則 9 の `MpsiLevel3` を `MpsiLevelU` に替えます。上から順に判定します。

| 場合 | `M(ψ_{Ω_u}(Ω_w))` |
|---|---|
| `u` が可算、極限、または無限レベル | 変えない |
| `w` が `ψ` で始まり、`M(w) = low M(Ω_t) ++ tail`、`t = L+1` か `Ω+1 < t ≤ u` | `reroot (low M(Ω_t)) (low A_u(t)) M(w)`（つぶし） |
| `w ≤ Ω_{L+1}` | 変えない |
| `w = Ω_m`、`L+1 < m < ω` | `R_{m-L-1}` |
| `Ω_m < w < Ω_{m+1}`、`L+1 ≤ m < ω` | `reroot (low M(Ω_{m+1})) (low R_{m-L}) M(w)` |
| `Ω_ω ≤ w < Ω_{ω+1}` | `P ++ L^L(M(w)[4:])` |
| `Ω_{ω+1} ≤ w < Ω_Ω` | `P ++ L'^L(M(w)[4:])` |
| `w = Ω_Ω` | `P ++ (L+1,L+1,1)(L+2,L+1,1)(L+3,1,0)` |
| `L = 1`、`Ω_Ω < w < Ω_{Ω+1}` | `reroot (low M(Ω_{Ω+1})) P M(w)` |
| それ以外 | 変えない |

`A_u(t) = M(ψ_{Ω_u}(Ω_{Ω_t}))` は同じ表で求めます。`t = u` では形式的な葉
`base ++ (a+1,y0,1)(a+2,y0,1)(a+3,y0,0)` です。`a` は `base` の最後の列の `x`、`y0` はその `y` に
1 を足したものです。ガードが外れたとき（期待した先頭部分がないとき）は、変えない場合の結果です。

`L = 1` で `w < Ω_{Ω+1}` の行は、このパッチの第 1 版です。第 1 版は、レート制限で止まったエージェントが
残したものです。この版では次の 2 つを足しました。

1. **`t = 2` のつぶし行。** `Ω_2` より下の `ψ_1` と `ψ_{Ω_2}` の引数は、`P` の下げた葉にぶら下げます。
   例: 規則は `M(ψ_{Ω_{Ω+1}}(Ω_{ψ_1(Ω_2)})) = low P ++ (10,3,0)`（末尾は `(7,3,1)(8,3,1)(9,1,0)(10,3,0)`） を出します。これは
   非標準です。修正 U は `… (9,1,0)(10,2,0)` を出します。これは標準で、順序も合います。
2. **`Ω+1 < t ≤ u` のつぶし行。** 入れ子の引数 `ψ_{Ω_{Ω+2}}(…)` などは、`A_u(t)` の葉にぶら下げます。
   例: `M(ψ_{Ω_{Ω+2}}(Ω_{ψ_{Ω_{Ω+2}}(Ω_{Ω_Ω})}))` は、規則では
   `(11,4,1)(12,4,1)(13,1,0)(11,4,1)(12,4,1)(13,1,0)` で終わります（非標準）。修正 U では
   `(11,4,1)(12,4,1)(13,2,0)(2,2,1)(3,2,1)(4,1,0)` です。`u = Ω+1` と同じ形です。

`L ≥ 2` では、同じ表の添字をずらします。`2` が `L+1` になります。`u = Ω_2+1` では
`P = M(ψ_{Ω_u}(Ω_{Ω_3}))`、引数 `Ω_{Ω_ω}` は `P ++ (3,3,1)` です。その展開が引数
`Ω_{Ω_3}, Ω_{Ω_4}, Ω_{Ω_5}` です。規則は `Ω_{Ω_ω}` に、`P` から最後の列を除き
`(10,1,0)(8,4,1)` を付けた行列を出します。これは `P = M(ψ_{Ω_u}(Ω_{Ω_3}))` より下です。

## なぜこの行か

- **つぶし。** `ψ_{Ω_t}(Y)` は `Ω_t` のすぐ下にあります。その行列は `low M(Ω_t)` の後に引数が続く
  ものです。`ψ_{Ω_u}(Ω_w)` の中では、`A_u(t)` の葉が `Ω_t` を表します。そこで引数の部分を、
  `A_u(t)` の下げた葉にぶら下げ直します。`u = Ω+1`、`t = Ω+1` では、第 1 版の行
  `Ω_Ω < w < Ω_{Ω+1}` と同じです。
- **`L ≥ 2` の添字のずらし。** `u = Ω+1` では、`u` のレベルのすぐ上の区間は `[Ω_2, Ω_ω)` で、`P` は
  `Ω_2` を表します。`u = Ω_L+1` では区間は `[Ω_{L+1}, Ω_ω)` で、`P` は `Ω_{L+1}` を表します。2 を
  `L+1` に替えた同じ作り方で、標準で順序の合う行列が出ます。ほかの形は失敗します: 規則の
  `Ω_{Ω_ω}` は `Ω_{Ω_3}` より下です。印 `(2,2,1)` では展開が非標準になります。
- **持ち上げ。** `L = 2` で、レベル `ω` の `P ++ L^2(M(w)[4:])` と、`[Ω_{ω+1}, Ω_Ω)` の
  `P ++ L'^2(M(w)[4:])` は標準です。BM4 展開は持ち上げと交換します:
  `n = 0, …, 3` で `(P ++ lift(M(w)[4:]))[n] = P ++ lift(M(w)[n][4:])`。交換する引数は、`L = 1`
  （修正 E）で交換する引数とちょうど同じです。`n ≥ 1` で交換しないのは `Ω_ω`、`Ω_ω·2`、`Ω_{ω²}`
  だけです。これらは展開の悪い根が、捨てた先頭 `B` にあります。

## 証明したこと

[`TrioFixU.lean`](TrioFixU.lean) で、`sorry`、新しい公理、`native_decide` なしで証明しました:

- `MstepU_notPsi`: `ψ_{Ω_u}(X)` でないすべての `α` で、ステップは `MstepAll` のものです。
- `MstepU_psi`: `α = ψ_{Ω_u}(X)` では、ステップは `MpsiLevelU`、`MstepAll` のものは `MpsiLevel3` です。
- `MpsiLevelU_of_not`: `u ≤ Ω`（可算な `u` はすべて）と極限の `u` では、規則 9 は変わりません。
- `MpsiLevelU_of_finLvl_none`: 無限レベルの `u` では、規則 9 は変わりません。
- `MpsiLevelU_of_countable_arg`: 可算な引数では、規則 9 は変わりません。
- `tableU_of_le`: 表は `w ≤ Ω_{L+1}` を変えません。
- `MstepU_eq_MstepAll`: 修正 U が働かないとき、ステップは `MstepAll` のものです。
- `reroot_prefix`、`rerootTail_size`、`reroot_size`、`liftLk_size`: `reroot src img m` は `img` で
  始まり、列の数は `img.size + (m.size − src.size)` です。持ち上げは `m.size − 4` 列を残します。
- `WF3_trioRuleMatrixU`: どの列も 3 行で `z < 2` です。

標準性と順序については何も証明していません。それは上の数値検査です。

## 残っていること

1. **レベル 1 で `Ω+k` の形でない `u`、`w ≥ Ω_{Ω+1}`**（例: `u = Ω·2+1`、`Ω²+1`、`Ω+ω+1`）。
   そこでは、つぶし行を除いて規則 9 は変わりません。2 つの作り方が失敗しました。(a) `u' = Ω+2` の
   行列を `u = Ω·2+1` に移す（引数部分を `M(Ω_u)` の最後の階にぶら下げ直す）と、`Ω_{Ω+1}+1` の行列が
   `M(ψ_{Ω_u}(Ω_{Ω_{Ω+ω}}))[1]` より上になります。後者は `Ω_{Ω_{Ω+2}}` の自然な候補です。(b)
   `k ≥ 3` の `u' = Ω+k` では、列の対応がそもそもありません: `M(Ω_{Ω+k})` は `M(Ω_u)` の先頭部分では
   なく、最後の階どうしを合わせると `Ω_{Ω_{Ω+2}}` と `Ω_{Ω_{Ω+1}}` が同じ行列になります。
   `u = Ω²+1` では、`t = u` のつぶし行の像が `t = Ω+1` の像と一致し、ラベルがぶつかります。そのため、
   これらの `u` の定義域は `Ω_{Ω+1}` で止めました。
2. **有限レベル `L ≥ 2`、`Ω_Ω < w < Ω_u`**（入れ子の `ψ_{Ω_u}` 引数を除く）。`u = Ω_2+1` では、区間
   `[Ω_Ω, Ω_{Ω_2})` が持ち上げと最上部の間にあります。そこではどちらの持ち上げも働きません:
   `P ++ L'^2(M(w)[4:])` も、`Ω` の葉を `y = 1` のまま残す変種も、`(Ω_Ω, Ω_{Ω_2})` で試した 20 個の
   `w` すべてで非標準です（`Ω_Ω` 上の和、`ψ_{Ω_{Ω+1}}` と `ψ_{Ω_{Ω+2}}` の項、`Ω_{Ω+1}` から
   `Ω_{Ω²+1}` まで、`Ω_{ψ_1(Ω_2)}`、`Ω_{ψ_{Ω_2}(Ω_Ω)}`）。
3. **無限レベルの `u`**（`Ω_ω+1`、`Ω_Ω+1` など）と**極限の `u`**: 規則 9 は変えていません。シートに
   極限 `u` の行はありません。
4. **可算な `u`**（`ω+1` で `Ω < w < Ω_ω`、[TRIO-SHEET-FIXES-ja.md](TRIO-SHEET-FIXES-ja.md)）: この
   パッチの範囲外です。
5. **新しい行列を確かめるシートの行はありません。** シートにあるのは、各非可算 `u` の最初の点（と行
   4467）だけです。根拠は標準性、順序、展開です。
6. **`inDomain` は根拠より広いです**（レビューで、`inDomain` に入るラベルを 110 個足して確かめました）。
   - `u = Ω+k` で、`w ≥ Ω_{Ω+1}` が `ψ` で始まらないとき: 規則 9 は変わらず、`M(w)` は標準なのに
     結果が非標準です: `ψ_{Ω_{Ω+2}}(Ω_{Ω_{Ω+1}+Ω_Ω})`、`ψ_{Ω_{Ω+2}}(Ω_{Ω_{Ω+1}·Ω_Ω})`、
     `ψ_{Ω_{Ω+3}}(Ω_{Ω_{Ω+1}+Ω_Ω})`。なので `u = Ω+k` の「すべての `w`」は成り立ちません。
   - `M(w)` が最上位ですでに非標準か順序違いのとき、修正 U もそれを引き継ぎます:
     `w = Ω_Ω+Ω_3`、`Ω_{ψ(Ω)}+Ω_ω`、`Ω_{ω^ω}·Ω_3`、`ψ_{Ω_ω}(Ω_Ω)`（非標準）、組
     `Ω_Ω+Ω_3 / Ω_Ω+Ω_ω`、`Ω_5 / ψ_{Ω_ω}(Ω_Ω)`、`Ω_{ψ(Ω_ω)} / ψ_{Ω_Ω}(Ω_Ω)`、
     `Ω_{Ω+1}^2 / Ω_{Ω+1}^{Ω_{Ω+1}}`、`Ω_{ω+1}·Ω_3 / Ω_{ω+1}^2`（順序違い）、
     `M(ψ_2(Ω_Ω)) = M(ψ_{Ω_3}(Ω_Ω))`。

## 副次的な発見

- **`ψ_{Ω_v}` の項で始まる和**は、最上位で `Ω_v + δ` の行列になります:
  `M(ψ_{Ω_{Ω+1}}(Ω_{Ω+1}) + 1) = M(Ω_{Ω+1} + 1)` で、衝突です。和の分岐が、`ψ` の添字 `v` の
  `M(Ω_v)` の上に積むためです。規則 9 ではないので、修正 U は触れません。
- `M(ψ_1(Ω_{Ω_2+1}))` は最上位で非標準です。また `M(ψ_1(Ω_Ω)) = M(ψ_{Ω_2}(Ω_Ω))` ですが、`cmpOrd` は
  `ψ_1(Ω_Ω)` を `ψ_{Ω_2}(Ω_Ω)` より下に置きます。
- `M(Ω_{Ω²+1})` の葉の高さは `M(Ω_{Ω+1})` と同じ（`y = 3`）です。これが上の 1 の衝突の原因です。
