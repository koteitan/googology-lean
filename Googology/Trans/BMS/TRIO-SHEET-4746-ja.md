# トリオのシートの行 4746, 4747, 4752, 4753

[TRIO-SHEET-41-ja.md](TRIO-SHEET-41-ja.md) は、
[koteitan/trio](https://github.com/koteitan/trio) のシート
[`tools/omega_alpha_rows.tsv`](https://github.com/koteitan/trio/blob/main/tools/omega_alpha_rows.tsv)
のこの 4 行 (`S-c`) をシートの側に決めた。ただし「独立には確かめていない」としていた。根拠は、シートの行列に矛盾がないことと、規則の行列が衝突することだけだった。
このノートは別の根拠を示す。確認は [`TrioSheet41Confirm.lean`](TrioSheet41Confirm.lean) の `#guard` で行う。較正であって、定理ではない。

## 判定

**4 行ともシートの側で確かめられた。** 4746 と 4752 は 2 つの根拠で決まる: 確認済みの 4745, 4751 に対する順序が規則の行列を否定し、サブユニット則がシートの行列を与える。
最後の項のレベルもシートと合うが、ここでは規則と区別できない。
4747 と 4753 は最後の項のレベルで決まる。(確かめた) 4746, 4752 との衝突もこれと合う。

サブユニット則と展開の形は、見かけほど強くない。`u = 2` (行 4522, 4523。744 行の外) では、サブユニット 1 つで `Ω_{Ω_2}+Ω_3` から直接 `Ω_{Ω_2}·2` になる。
これは `u = Ω` での規則の形と同じ。`u = 2` と `u = Ω` を区別するのは、最後の項のレベルだけ (5 と「`u = 2`」の節)。

`M(α)` は `ψ_0(Ω_α)` の行列。`s₃ = (4,3,1)(5,3,1)(6,2,0)`、`s₂ = (2,2,1)(3,2,1)(4,1,0)` と書く。
行 4744, 4745, 4750, 4751 は TRIO-SHEET-41-ja.md で確かめ済み (4745 は展開、4744 と 4750 は形、4751 は葉による)。以下ではこれを「確認済み」と呼ぶ。

| 行 | `α` | シート | 規則 1–10 |
|---|---|---|---|
| 4746 | `Ω_{Ω_Ω}+Ω_{Ω_2}` | `M(4745) ++ s₃` | `M(4742) ++ s₃` |
| 4747 | `Ω_{Ω_Ω}·2` | `M(4745) ++ s₃ ++ s₂` | `M(4745) ++ s₃` (シートの 4746) |
| 4752 | `Ω_{Ω_Ω}·Ω_{Ω_2}` | `M(4751) ++ s₃` | `M(4749) ++ s₃` |
| 4753 | `Ω_{Ω_Ω}^2` | `M(4751) ++ s₃ ++ s₂` | `M(4751) ++ s₃` (シートの 4752) |

## 1. サブユニット則

`m` が列 `(x, L, 0)` で終わるとする。`subLaw m` は、`m` の後ろに、`m` の中の最後のサブユニット `(a,L,1)(a+1,L,1)(a+2,y,0)` の写しをつけたもの。
このサブユニットは、最後の列と同じ高さ `L` にある。

一致行の 11 組で `subLaw M(β) = M(β')` が成り立つ。ここで `β'` は、`β` の一番内側の後続 `s+1` を「`s` より大きい最小の非可算基数」に置き換えたもの:

| `s+1 ↦` | 一致行の組 |
|---|---|
| `0+1 ↦ Ω` (塔) | `Ω ↦ Ω_Ω ↦ Ω_{Ω_Ω} ↦ …`、`Ω_{Ω_{Ω_{Ω_{Ω_Ω}}}}` まで 5 組 |
| `1+1 ↦ Ω` | `Ω_Ω+Ω_2 ↦ Ω_Ω·2`、`Ω_Ω·Ω_2 ↦ Ω_Ω^2`、`Ω_{Ω_Ω+Ω_2} ↦ Ω_{Ω_Ω·2}`、`Ω_{Ω_Ω·Ω_2} ↦ Ω_{Ω_Ω^2}` |
| `ω+1 ↦ Ω` | `Ω_{Ω_ω}+Ω_{ω+1} ↦ Ω_{Ω_ω}+Ω_Ω`、`Ω_{Ω_ω}·Ω_{ω+1} ↦ Ω_{Ω_ω}·Ω_Ω` |

確認済みの行でも成り立つ: `4742 ↦ 4744`、`4749 ↦ 4750`、`4487 ↦ 4488`。

4 行では、ちょうどシートの行列が出る:

- `subLaw M(4745) = シートの 4746`: `Ω_{Ω_Ω}+Ω_{Ω+1} ↦ Ω_{Ω_Ω}+Ω_{Ω_2}`。ここで `Ω+1 ↦ Ω_2`。
- `subLaw (シートの 4746) = シートの 4747`: `Ω_{Ω_Ω}+Ω_{Ω_2} ↦ Ω_{Ω_Ω}+Ω_{Ω_Ω}`。ここで `2 ↦ Ω`。
- `4751 ↦ 4752 ↦ 4753` も同じ。

規則は違うことをする。規則は `s₃` を 4742 (と 4749) の `Ω_2` の葉につける。また `·2` (と `^2`) を、則なら 2 つ要るところをサブユニット 1 つで書く。

この根拠の限界: `s` が非可算の一致行の組はない。だから `Ω+1 ↦ Ω_2` という一歩は、則の実例ではなく、則を延長したもの。
`2 ↦ Ω` という一歩は則の実例で、1 段内側にあるだけ。
また、この則は組 4522, 4523 で成り立たない (「`u = 2`」の節)。

## 2. 順序

- **シート。** 4 つの行列は、744 の一致行と 4 つの確認済みの行のすべてに対して、`cmpOrd` で正しい側にある。
  鎖 `4745 < 4746 < 4747 < 4748` と `4751 < 4752 < 4753 < 4754` が成り立つ。
- **規則 1–10。** 4746 と 4752 の行列は、確認済みの 4745 と 4751 より下にある。ラベルは上なのに。
  4747 と 4753 の行列は、どの行に対しても正しい側にある。
- **順序でわからないこと。** 744 の一致行だけを相手にすると、規則の 4 つの行列も順序どおりになる。つまり一致行だけでは、この 4 行は決まらない。
  順序が規則を否定できるのは 4746 と 4752 だけで、それも確認済みの 4745 と 4751 を通してだけ。

## 3. 衝突

規則は 4747 にシートの 4746 を、4753 にシートの 4752 を与える。4746 と 4752 が確かめられたので、この衝突によって、規則の 4747 と 4753 は否定される。

## 4. 展開

`u = 1` では、一致行 4458, 4459, 4460 から次が成り立つ。

```
M(Ω_Ω·(k+1)) = M(Ω_Ω·ω)[k] ++ s₂      (k = 1, 2)
```

ここで `s₂` は、葉 `Ω_2` を `Ω_Ω` に上げる upgrade。`u = Ω` では、`M(Ω_{Ω_Ω}·ω)[1]` が確認済みの 4745 で、

```
シートの 4747 = M(Ω_{Ω_Ω}·ω)[1] ++ s₃ ++ s₂
```

これは同じ形をしている。葉 `Ω_{Ω+1}` を `Ω_{Ω_Ω}` に上げる upgrade が `s₃ ++ s₂` で、途中で `Ω_{Ω_2}` を通る。
修正した規則では、さらに `M(Ω_{Ω_Ω}·3) = M(Ω_{Ω_Ω}·ω)[2] ++ s₃ ++ s₂` にもなる。
シートの行を `n ≤ 3` で展開しても、4 行のどれかになるものはない (標準形の 785 行すべてを yaBMS で確かめた)。

`u = 2` では、`u = 1` と同じくサブユニットは 1 つ:
`M(Ω_{Ω_2}·2) = M(Ω_{Ω_2}·ω)[1] ++ (3,3,1)(4,3,1)(5,2,0)` (行 4522–4524、誤植を直したもの)。
これは `u = Ω` での規則の形。だからこの根拠だけでは 4 行は決まらない。

## 5. 最後の項のレベル

`M[1]` の最初の新しい列を見る。`α` の最後の項の基本列が `Ω_{k+1}` で対角化するとき、その列の行 1 の値は `k` になる。一致行の 83 行で成り立つ:

| 最後の項 | レベル | `k` | 一致行 |
|---|---|---|---|
| `Ω`、`Ω_Ω` | `Ω_1` | 0 | 61 |
| `Ω_2` | `Ω_2` | 1 | 19 |
| `Ω_3` | `Ω_3` | 2 | 3 |

確認済みの 4744 と 4750 (`+Ω_Ω`、`·Ω_Ω`) も 0 になる。83 行は見本。yaBMS で調べると、最後の項のレベルが有限の `k` で `Ω_{k+1}` になる一致行すべてで成り立つ:
744 行のうち 132 行、`k` は 0 から 5、例外なし。

`Ω_{Ω_2}` は、添字の `Ω_2` が `Ω_2` で対角化するので、`Ω_2` で対角化する。`Ω_{Ω_Ω}` は、`Ω_Ω` が `Ω_1` で対角化するので、`Ω_1` で対角化する。
だから 4 行には `1, 0, 1, 0` が要る。シートは `1, 0, 1, 0`。
規則は `1, 1, 1, 1` で、規則の 4747 と 4753 は、`Ω_{Ω_Ω}` ではなく `Ω_{Ω_2}` のレベルで対角化する。

## 組 4522, 4523 (`u = 2`)

行 4519–4535 は、シートの行列が標準形でない 28 行に入る。だから 744 の一致行には入らない。
4522, 4523, 4524 の欠陥は、`(4,3,1)` を `(4,4,1)` と書いた誤植だけ (行 4533 と同じ誤植)。直すと、シートは規則の行列になる。

この組でサブユニット則はサブユニットを 1 つ足し、`Ω_{Ω_2}·2` を与える。1 の置き換えなら `Ω_{Ω_2}+Ω_Ω` になるはず (`3 = 2+1 ↦ Ω`)。
だから、この置き換えはすべての組で成り立つ則ではない。

ここでは `M(Ω_{Ω_2}·ω)[1] = M(Ω_{Ω_2}+Ω_3)` なので、`M(Ω_{Ω_2}·2)` は `M(Ω_{Ω_2}·ω)[1]` にサブユニットを 1 つ足したもの。
これは `u = Ω` で規則がすること。2 つの場合を区別するのは最後の項のレベル。
サブユニット 1 つでは、どちらの場合もレベル `Ω_2` で終わる (`k = 1`)。これは `Ω_{Ω_2}·2` には正しい (最後の項 `Ω_{Ω_2}` は `Ω_2`)。
`Ω_{Ω_Ω}·2` には正しくない (最後の項は `Ω_1`)。シートの 2 つ目のサブユニット `s₂` が、レベルを `Ω_1` (`k = 0`) に下げる。

## まだ残っている `+1`

修正した規則は `Ω_{Ω_Ω}+Ω_{Ω_2}+1` を `Ω_{Ω_Ω}·2` より上に置く (TRIO-SHEET-41-ja.md の「残り」)。
これはシートの 4746 や 4747 に不利な根拠にはならない。同じ欠陥が一致行のあいだですでに起きている。
どちらの規則でも `Ω_Ω+Ω_2+1` は同じ行列になり、その行列は 4457 (`Ω_Ω+Ω_ω`) と 4458 (`Ω_Ω·2`) より上にある。ラベルはどちらより下なのに。
これは規則の「最後の葉の後の `+1`」の欠陥で、別に直す必要がある。
