## 2. 規則の形

2 行の $`\Phi`$ と同じく、行 0 の親の森を足し算の構造として読む。項は $`(y, z, \text{子})`$ である。$`\Phi_3(M)`$ は、$`\{0, 1, M\}`$ を次の操作で閉じたものである。

- 根の成分、途中までの和、anchor、$`\le_1`$ の届く先 $`\mathrm{lh}`$
- $`\le_2`$ の後者と、$`\le_2`$ の証人の節点

$`x \le_1 y`$ は $`x \le y \le \mathrm{lh}(x)`$ と読む。$`\le_2`$ の組は列挙してから閉じる。行 2 が全部 0 の行列では、$`\Phi_3`$ は 2 行の $`\Phi`$ と一致する。

2 行から増えた主な規則は次のとおりである。

- **根の最後の子が $`z = 1`$ の列の連なりのとき。** 2 行と同じ畳み込み $`\oplus`$ を、1 段上へのコピーで行う。コピーの中では、$`z = 1`$ の列は 1 段上がり、$`(y = 1, z = 0)`$ の列は $`N`$ に潰れ、$`y = 0`$ の列はそのまま残る。
- **$`\le_2`$ の組ができるとき。** 最後の子 $`W`$ の下に $`z = 1`$ の列があり、その後ろが葉だけのとき、$`\le_2`$ の後者の列が生まれる。例：シートの行 541 $`\lt_2`$ 行 551。
- **2 つ目の潰す操作。** 添字の列（子を持つ $`(y = 1, z = 0)`$ の列）の部分木を、$`\le_2`$ の点 $`c`$ に相対化して、2 行の $`\Phi`$ で読んだ節点を、$`\le_2`$ の区間の中に置く。潰し方は次のとおりである。

```math
\Omega_\omega \mapsto c,\qquad \Omega_{\omega + \nu} \mapsto \Omega_\nu
```

- **段の数え方。** 同じ段の $`z = 1`$ の子は、$`\le_2`$ の届く先を倍にする。この部分は、一部しか入っていない。

実装は `phi3.py` である。旗（flags）で版を選ぶ。

|---|---|
| `z,dbl` | 最初の版。働く範囲（シートの行 522–754）に合う |
| `z,dbl,idx,lvl,lev`（既定） | 2 つ目の潰す操作と、段の数え方の一部を足した版 |

## 3. 比べ方

- **シート。** 表計算シート "Sheetified Patterns of Resemblance"（作者不明）の 3 行の行を使った。シートのパターンは、それ自体が $`\Phi`$ 型の閉包になっているので、構造を直接比べた。
  - iso：$`\Phi_3(M)`$ がシートのパターンと同じ構造である。
  - sub：シートのパターンが、$`\Phi_3(M)`$ の節点の一部（点を含む）の制限になっている。このとき、比較の計算器で $`\iota(\Phi_3(M)) \le \iota(\text{シート})`$ を確かめる。埋め込みから逆向きも出るので、両者は等しい。

## 6. 2 段の潰す操作（$`\Phi_{3g}`$）

2 行の $`\mathrm{Coll}`$ は、潰す先が 1 つ（$`\Omega_1 \mapsto N`$）だった。3 行では、潰す先を 2 つ持つ。場合ごとの規則をやめて、2 つの潰す操作の再帰で $`\Phi_3`$ を作り直した（`phi3g.py`）。

**列の段。** 潰す部分木の中で、各列は次のどれかである。

- **有限の段 $`y`$**：$`z = 0`$ で、$`z = 1`$ の先祖が無いか、その先祖の $`y`$ より下。有限の列の下も有限である。
- **$`\omega`$ の段**：$`z = 1`$。
- **添字の段 $`\omega + j`$**：$`z = 0`$ で、$`z = 1`$ の先祖 $`a`$ の下にあり、$`y = a.y + j`$。$`j = 0`$ のものを**印**と呼ぶ。

**$`C1_N`$：$`\Omega_1`$ の段の潰し**（$`\Omega_1 \mapsto N`$、$`\Omega_{1+\nu} \mapsto \Omega_\nu`$）

- $`y = 0`$ の列：そのまま。
- 有限の $`y = 1`$ の列：$`N`$ の子に $`C1_N`$（子）を足した、$`y = 0`$ の根の列になる。
- 有限の $`y \ge 2`$ の列：$`y - 1`$。
- 添字の列：不動点。$`\omega`$ の先祖が動けば、一緒に動く。
- $`y = 2`$ の $`\omega`$ の列：$`y = 2`$ のまま、段 1 の列 1 本で包む（$`\psi_1(\Omega_\omega \cdots)`$ に当たる）。
- $`y \ge 3`$ の $`\omega`$ の列：$`y - 1`$。

**$`C2_x`$：$`\Omega_\omega`$ の段の潰し**（$`\Omega_\omega \mapsto x`$、$`\Omega_{\omega+j} \mapsto \Omega_j`$）。コピーした $`\omega`$ の列 $`D`$ の子に使う。$`x`$ は $`\le_2`$ の組を作れる点である。

- $`y = 0`$ の列：そのまま。
- 印：$`x`$ の子に $`C2_x`$（子）を足した、$`y = 0`$ の根の列になる。
- 添字 $`\omega + j`$（$`j \ge 1`$）：有限の段 $`j`$ になる。
- $`D`$ の下の有限の列：$`x`$ の子に $`C1_x`$（子）を足した根の列になる。

**届く先。** $`\mathrm{lh}`$ は、2 行の畳み込み $`\oplus`$ にこの 2 つの潰しを入れたものである。$`\oplus`$ の 2 つ目の場合は、「$`Y`$ が $`\le_2`$ の組を作れるなら $`\mathrm{lh}(Y) + Y`$、そうでなければ $`\mathrm{lh}(Y)`$」になる。$`\le_2`$ の届く先 $`\mathrm{lh}_2`$ も、同じ形の畳み込みで作る。

**局所的に決まらない 3 つの規則。** 各列の $`(y, z)`$ と先祖だけで決める純粋な版は、シートの行 755–914 のうち 69 行にしか合わなかった。シートは、兄弟や最後の加数全体を見る、次の 3 つの判断を要る。

1. 最後の $`\omega`$ の加数の右端の道にある葉の印は、有限の列（$`\Omega_1`$ の倍数）として扱う。同じ局所的な形 $`(3,2,0)`$ が、行 759 と行 851 で別の役を持つ。

## 7. Carlson の定義から読んだ規則（$`\Phi_{3h}`$）

§6 の 3 つの規則を、Carlson (2009) の $`\le_1`$ と $`\le_2`$ の定義、および Wilken, "Pure Σ₂-elementarity beyond the core"（APAL 172, 2021, [doi:10.1016/j.apal.2021.103001](https://doi.org/10.1016/j.apal.2021.103001)）の §1 にある $`R_2`$ の性質と照らし合わせた。3 つのうち 2 つは、局所的な規則に言い直せた。新しい版は `phi3h.py` である。

記法：$`N = \psi_0(\alpha)`$ は潰す点、$`W`$ は $`\alpha`$ の最後の加数である。

**規則 1（最後の列）。**
- **局所的な形。** 葉の印 $`m`$ が $`\Omega_1`$ の倍数になるのは、$`m`$ が今の潰す先の引数の最後の列で、かつ、その引数のいちばん外の $`\omega`$ の列の印であるとき、そのときだけである。
- **理由。** 1 行の再帰 $`\mathrm{lh}(\alpha) = \alpha + \mathrm{lh}(\rho_1) + \cdots + \mathrm{lh}(\rho_m)`$ と同じく、$`N`$ の届く先は $`W`$ だけで決まる。
  - $`\omega`$ の加数の中で、後ろにまだ項がある $`\Omega_1`$ は、段 $`\omega + 0`$ の係数である。$`\nu \ge \omega`$ なら $`1 + \nu = \nu`$ なので、$`C1`$ はこれを動かさない。
  - 引数全体の最後の $`\Omega_1`$ は、$`W`$ の有限の項である。$`C1`$ はこれを $`N`$ に送る。
- **確認。** この規則を外すと、$`\Phi(755)`$ と $`\Phi(810)`$ が、シートの次の行（756 と 811）以上になることを計算器が示した。

**規則 2（極限の直後の単位）。**
- **局所的な形。** コピーした $`\omega`$ の加数を $`\Omega_\omega \beta_1 + \cdots + \Omega_\omega \beta_k`$ と書く。$`\le_2`$ の段は、この倍数の後者の加数である。極限の加数の直後の単位の加数は、その極限の後者である。
- **理由。** $`a \lt_2 b`$ なら、$`a`$ は $`\lt_1`$ の無限の鎖の真の上限である（Wilken 2021 §1、Carlson 2009 Lemma 5.5）。極限の加数 $`\Omega_\omega \lambda`$ には、この鎖が無い。$`\Omega_1`$ の潰しが鎖を切るからである。だから、その段は $`\lambda + 1`$ で現れる。

## 9. Wilken の $`R_2`$ と未決の組

`por/tr3.py` は、トリオの行列 $`M`$ を、純粋な構造 $`R_2 = (\mathrm{Ord}; \le, \le_1, \le_2)`$ の Wilken の記法に訳す（Wilken, "Pure Σ₂-elementarity beyond the core", APAL 172, 2021, [doi:10.1016/j.apal.2021.103001](https://doi.org/10.1016/j.apal.2021.103001)）。訳した値を $`\mathcal{T}_3(M)`$ と書く。
- $`\upsilon_0 = 0`$、$`\upsilon_{i+1} = (\upsilon_i)^\infty`$、極限では上限をとる（Wilken の Def 1.5）。$`[\upsilon_i, \upsilon_{i+1})`$ の順序数は $`\tau = \upsilon_i`$ に相対的な $`\vartheta`$ の項で書け（Def 1.3）、その比較は Lemma 2.26 による。
- 読み方は $`\upsilon_{1+\xi} = \psi_0(\Omega_\omega + \psi_1(\Omega_\omega) \cdot \xi)`$ である。不動点 $`h = \upsilon_h`$ には有限の添字が無い。$`\mathcal{T}_3`$ はこれを行列で名付け、2 つの名前は行列の順序で比べる。
- 2 つの検証用の集合の上で、$`\mathcal{T}_3`$ は辞書式順序に沿って狭義に増える。
- **$`R_2`$ は $`R_2^+`$ ではない。** Wilken の $`\le_1`$、$`\le_2`$ は純粋な構造のものである。$`\Phi_3`$ が目指すのは、言語に $`+`$ を持つ $`R_2^+`$ である。2 つは違う。Wilken の Thm 1.8 では $`\upsilon_2 \lt_2 \upsilon_\omega`$ だが、シート（行 534）にも $`\Phi_{3i}`$ にも $`\upsilon_2`$ の $`\le_2`$ の後者は無い。だから Wilken の $`R_2`$ は $`\Phi_3`$ の判定には使えない。合うのは、$`R_2^+`$ の $`\upsilon_\iota`$ を $`R_2`$ の $`\varepsilon_0 \cdot \iota`$ と読むことである。これは Wilken §3 が $`R_1`$ と $`R_1^+`$ の間に与える対応と同じ形である。添字が有限の $`\upsilon`$ の点の上で、11758 の関係が一致し、食い違いは 0 である。

## 11. 根の加数が複数ある行と入れ子の枠（$`\Phi_{3l}`$）

$`\Phi_{3l}`$（`phi3l.py`）は、$`\Phi_{3k}`$ に 4 つの旗を足したものである。シートとの一致は 787 行から 834 行に増え、失った行は無い。§10 の 4 組の食い違いは消え、2 つの新しい検証用の集合でどちらも食い違いは 0 になった。これまでの検証用の集合（1085 + 305 行列）では、$`\Phi_{3l}`$ は $`\Phi_{3k}`$ と同じパターンを出す。だから、それらの順序の検証はそのまま成り立つ。

## 15. $`\Phi_3`$ の 1 つの定義

`phi3def.py` は、$`\Phi_3`$ を旗の無い 1 つの再帰で定める。作り方は次のとおり。$`\Phi_{3o}`$ の 50 個の旗を §14 の値に固定し、それで死んだ分岐をすべて消し、残りを 11 個の節 D1–D11 にまとめた。それ以外は何も変えていない。

**同じ写像である。** 7 つの順序の検証の集合のすべての行列（1085 + 305 + 785 + 290 + 262 + 152 + 94 = 2973 行列）と、シートの 1099 行のすべてで、$`\Phi_{3\mathrm{def}}`$ は $`\Phi_{3o}`$ とまったく同じパターンを出す。節点、届く先、$`\le_2`$ の組、点がすべて同じである。よって直すべき違いは無かった。シートとの一致（1051 行）と §14 の順序の検証（食い違い 0、同じパターンの組 0）は、$`\Phi_{3\mathrm{def}}`$ でもそのまま成り立つ。

**大きさ。** 注釈を除いて 876 行（$`\Phi_{3o}`$ は 967 行）、関数 58 個、分岐 171 個（$`\Phi_{3o}`$ は 207 個）。2 行版 §3 の半ページには遠い。長さの大部分は D6（段の列の並び）と D9（$`\le_2`$ になりうる節点の届く先）にある。昔の 1 行だけの規則は、旗ではなく 1 つの節の中の付帯条件になった。

### 15.1 項、持ち主、段（D1）

- 項は $`s = (y, z, B)`$ である。$`y`$ は段（行 1）、$`z \in \{0, 1\}`$（行 2）、$`B`$ は順に並んだ子である。和、$`\mathrm{root}`$、$`\mathrm{anchor}`$、epsilon の項、$`\log`$、$`\lambda`$ は 2 行版 §3 のとおり。
- $`z = 1`$ の列を **$`\omega`$ の列**と呼ぶ。$`z = 0`$ かつ $`y \ge 1`$ の列を**印**と呼ぶ。印の**持ち主**は、根への道の上で最も近く、段が $`y`$ 以下の $`\omega`$ の列である。持ち主と同じ段の印は、持ち主の $`\Omega_\omega`$ を表す。それより上の段の印は**添字の列**である。
- 列 $`K`$ の **1 段上の子**は、段 $`y_K + 1`$ の $`\omega`$ の子（$`\Omega_{\omega+1}`$ の因数）である。列 $`C`$ の**鎖**は $`C, C_1, C_2, \dots`$ である。ここで $`C_{i+1}`$ は $`C_i`$ の最初の 1 段上の子である。$`K_1, K_2, \dots`$ は $`D`$ の鎖である（15.5）。

### 15.2 潰す操作 $`C1_N`$（D2）

$`C1_N`$ は Buchholz の $`\Omega_1 \mapsto N`$ を、持ち主の積み重ねとともに読むものである。列 $`s = (y, z, B)`$ に対して次のように定める。

```math
C1_N(s) = \begin{cases}
s & (y = 0) \cr
(y - h,\ 1,\ C1_N(B)) & (z = 1;\ h \text{ は持ち主のずれ、一番外では } 1) \cr
(y - h,\ 0,\ C1_N(B)) & (z = 0,\ \text{ずれ } h \text{ の } \omega \text{ の列が持ち主}) \cr
\mathrm{root}(N.\mathrm{kids} + C1_N(B)) & (z = 0,\ y = 1,\ \text{持ち主なし}) \cr
(y - 1,\ 0,\ C1_N(B)) & (\text{それ以外})
\end{cases}
```

- **$`\Omega_1`$ 倍。** 一番外の $`\omega`$ の列と同じ段にある、最後の子の無い印は、持ち主を持たない。これは引数の最後の因数 $`\Omega_1`$ であり、$`N`$ になる。
- 持ち主の無い列の下では、積み重ねは空になる。$`\omega`$ の列は、有限の列をまたいで添字の列を持たない。
- 一番上で続く段 2 の $`\omega`$ の列は、1 つの段 1 の列（1 つの $`U`$ の形）にまとめる。

### 15.3 潰す操作 $`C2_x`$ と、同じ段の $`\omega`$ の列の読み（D3）

$`x`$ は $`\le_2`$ になりうる節点（15.5）で、その最後の $`\omega`$ の列 $`D`$ の段を $`y_D`$ とする。$`C2_x`$ は $`\Omega_\omega \mapsto x`$、$`\Omega_{\omega+j} \mapsto \Omega_j`$ である。

```math
C2_x(s) = \begin{cases}
s & (y = 0) \cr
(y - h,\ z,\ C2_x(B)) & (\text{持ち主あり、または } \omega \text{ の列の中の } z = 1) \cr
\mathrm{root}(x.\mathrm{kids} + C1_x(B)) & (z = 0,\ y \lt y_D,\ \text{持ち主なし}) \cr
\mathrm{root}(x.\mathrm{kids} + C2_x(B)) & (z = 0,\ y = y_D,\ \text{持ち主なし}) \cr
(y - y_D,\ z,\ C2_x(B)) & (y \gt y_D,\ \text{持ち主なし})
\end{cases}
```

**持ち主の規則**は、印と、持ち主と同じ段の $`\omega`$ の列の行き先を決める。行き先は、どの深さでも、持ち主が表す節点である。
- 持ち主が 2 段上にある最後の子の無い印は、$`D`$ に対して読む（$`x`$ へ潰れる）。
- 今読んでいる段の列と同じ段の $`\omega`$ の列は、その加数 $`\mathrm{Kimg}`$（下）になる。
- 段の列の奥深くにある $`D`$ の段の $`\omega`$ の列は、$`x`$ に対する $`\mathrm{Kimg}`$ になる。それが $`D`$ に一番下の段を与えた列（15.6 (a)）なら、その段の上で読む。

同じ段の $`\omega`$ の列 $`K`$ の加数は次のとおり。

```math
\mathrm{Kimg}(K) = \mathrm{root}\bigl(d_{1+j}.\mathrm{kids} + \mathrm{KI}(K.\mathrm{kids})\bigr)
```

ここで $`j`$ は、$`K`$ が自分の段より上に持つ段の数（$`q - 1`$ 以下）である。$`K`$ の最初の 1 段上の子が $`K_1`$ に等しいなら、$`K`$ は $`K_1`$ の段を共有する。このとき $`j`$ は、その後の 1 段上の子の数である。$`L_m`$ の中で読むときは、$`j`$ は $`m - 2`$ 以下である。$`\mathrm{KI}`$ は次のように写す。
- $`y = 0`$ の列はそのまま。段 $`y_D`$ の $`\omega`$ の列は $`\mathrm{Kimg}`$（入れ子）。
- 段 $`y_D`$ の最後の子の無い印は $`\mathrm{anchor}(x)`$（1 段上の $`\Omega_1`$ 倍）。段 $`y_D`$ の他の印は $`\mathrm{root}(x.\mathrm{kids} + \mathrm{KI}(B))`$。
- $`y_D`$ より上の $`z = 0`$ の列は $`(y - y_D, 0, \mathrm{KI}(B))`$。他の列の並びは $`C2_x`$。

$`C2_x`$ が段 1 の列に包む、続いた $`\omega`$ の列は、1 つの $`U`$ の形にまとめる。

### 15.4 根の $`\omega`$ の並びのコピー（D4）

$`\mathrm{Up}`$ は、根の $`\omega`$ の列のすべての列を 1 段上げる。最後の子の無い印は、持ち上げた列だけが持ち主なら $`N`$ になる。持ち上げた列と、1 段上の子の中の同じ段の $`D`$ の段の列が持ち主のときも同じである。

### 15.5 $`\le_2`$ になりうる節点、後者、組（D5、D7）

- $`x`$ が **$`\le_2`$ になりうる**とは、$`x = \mathrm{root}(P,\ U + q)`$ と書けることである。ここで $`U = (1, 0, G)`$、$`G = (G_1, \dots, G_n)`$ は $`C1_x(G) = U`$ となる $`\omega`$ の列の並び、$`D = G_n`$、$`1 \le q \le \mathrm{lev}(D)`$（15.6）である。後者は $`d_m = \mathrm{root}(P,\ U + q,\ U^m)`$（$`m = 1, \dots, q`$）である。ある $`d_m`$ である節点は、15.8 が届く先を与えない限り**行き止まり**（$`\le_1`$ の行き止まり）である。
- $`G_i`$ が**極限の加数**であるとは、その一番右の葉が、$`G_i`$ 自身が持ち主の子の無い印であることである（$`G_i`$ と同じ段の $`\omega`$ の子を通ってもよい）。
- **組**（原則 mult）。極限の加数は、次の加数が次のどれかなら、それと 1 つの組になる。
  - 子の無い 1；
  - 段だけ（子が 1 段上の子の鎖だけ）；
  - それを**覆う**加数：最後の印を除いた極限の加数、またはその子の頭の部分を繰り返し、段が同じ数以上ある。
- 加数が**中身を持つ**とは、その段の列のどれかが、鎖以外の子を持つことである。極限の加数 $`G_i`$ の**塊**は $`\mathrm{root}(d_q.\mathrm{kids} + (1, 0, (\mathrm{limx}(G_i, x))))`$ である。ここで $`\mathrm{limx}`$ は最後の印を $`x`$ に置き換える。

### 15.6 段の列 $`L(D)`$（D6）

段の列 $`K`$ が**切れている**とは、自分の段以下の $`z = 0`$ の子、または自分の段より下の $`\omega`$ の子を持つことである。ただし、自分と同じ段の $`\omega`$ の子か、自分より上の添字の列も持つなら、切れていない。$`L(D)`$ は段の列の並びで、後者 1 つに 1 つずつ対応する。列の無い段は $`\bot`$ と書く。$`\mathrm{lev}(D) = |L(D)|`$ とし、$`D`$ に 1 段上の子が無ければ $`\mathrm{lev}(D) = 1`$ とする。下から順に並べる。
- (a) **一番下の段**（次のうち多くとも 1 つ）：
  - $`D`$ の同じ段の $`\omega`$ の子の段（その最初の 1 段上の子が $`K_1`$ なら無し）；
  - 段の列の子で、$`K_1`$ を共有しない $`D`$ の段の $`\omega`$ の列の段；
  - 段の列の同じ段の子の中に入れ子になった $`D`$ の段の $`\omega`$ の列の段。
- (b) **鎖。** $`D`$ の鎖 $`K_1, K_2, \dots`$、続いて $`K_1`$ の繰り返しの鎖。鎖が切れているなら、その後の 1 段上の子の鎖もすべて続く。
- (c) **中にある前の段。** $`L_m`$ が、前の段の列の段にある $`\omega`$ の子を持ち、それが別の列なら、その段を $`L_m`$ のすぐ下に入れる。
- (d) **自分の一番上の段。** 次の場所に段 $`\bot`$ を入れる。後ろの 2 つは、前の列が切れていないときだけである。
  - 同じ段の $`\omega`$ の子を持つ、等しい 2 つの列の間；
  - 子を持つ $`K_1`$ の繰り返しの前；
  - 完全な鎖と、子を持つその最初の列の繰り返しの間。
- (e) **一番上。** 最初の鎖が切れていなければ、一番上の段 $`\bot`$ が続く。次に、さらなる 1 段上の子の鎖が続く。ただし、子の無いさらなる 1 段上の子が 1 つだけなら、それは段ではなく倍にするものである。一番上に同じ段の $`\omega`$ の子か添字の列を持つさらなる鎖は、自分の一番上の $`\bot`$ を持つ。

### 15.7 段の列の読み（D8）

$`d_m`$ は段の列 $`L_m`$（$`L(D)`$ の $`m`$ 番目）に属する。1 段上の子以外のその子は、次のように読む。
- **持ち主。** $`D`$ の段の印は $`x = d_0`$ へ行く。前の、より低い段の列 $`L_j`$ の段の印は $`d_j`$ へ行く。そのような印が子を持つなら、枠 $`\mathrm{root}(d_j.\mathrm{kids} + C2_{d_j}(B))`$ へ行く。$`L_m`$ の同じ段の $`\omega`$ の子の中でも、どの深さでも同じである。
- $`D`$ の段の $`\omega`$ の列は、段 $`d_1, \dots, d_q`$ の上の $`\mathrm{Kimg}`$ になる。前の段の列 $`L_i`$ の段の $`\omega`$ の列は、$`L_i`$ と $`L_m`$ の間の段の上の $`\mathrm{Kimg}`$ になる。

**列の子の畳み込み** $`F(S, t, K, b)`$ は、これらの読みを $`\oplus`$ で $`S`$ に畳み込む。$`t`$ に対して読み、枠の土台は $`b`$ とする。
- 切れていない鎖の後の、子の無いさらなる 1 段上の子 1 つは $`d_q`$ を与える（倍にする）。
- 極限の 1 段上の子のすぐ後の 1 は吸収される。
- $`K`$ と同じ段の $`\omega`$ の子は $`\mathrm{Kimg}`$ を与え、他の $`\omega`$ の子は何も与えない（それらは段である）。
- 添字の列は積み重なる。$`i`$ 番目は枠 $`\mathrm{root}(b + I_1 + \cdots + I_i)`$ を与える。枠が $`\le_2`$ になりうるなら、その入れ子の土台も節点である。
- 他の列 $`c`$ は $`C2_t(c)`$ を与える。ただし $`y = 0`$ なら $`\mathrm{root}(c.\mathrm{kids})`$ を与える。

### 15.8 届く先 $`\mathrm{lh}`$（D9）

$`S \oplus Y`$ は 2 行版の畳み込みである。ただし $`Y`$ が $`\le_2`$ になりうるときは $`\mathrm{lh}(Y) + Y`$ とする。根の項 $`t`$ に対して次のように定める。
- $`t = 1`$、または epsilon でない：2 行版 §3 のとおり。
- $`t = d_m`$ で $`L_m`$ が子を持つとき：
  - **鎖の子だけ**（かつ $`L_m`$ が $`d_q`$ の下で鎖を続けない）：$`\mathrm{lh}(t)`$ は、$`L_m`$ 自身の列より上にある最初の $`\bot`$ の段 $`k \ge m`$ に対する $`d_{k+1}`$ である。そのような段が無ければ $`d_q`$ である。
  - **$`m \lt q`$ で、$`L_m`$ が鎖を続け、他の子も持つ**：塊を足す前の $`\mathrm{lh}(x)`$（その子は一番上で読む）。
  - **それ以外**：$`\mathrm{lh}(t) = F((t), t, L_m, d_{m+1})`$（$`m = q`$ なら $`d_{m+1} = t`$）。段の列は添字の列では切れず、その枠は次の段の上に作る。
- $`t`$ が行き止まり：$`(t)`$。
- **根の $`\omega`$ の並び** $`A = (\dots, a_1, \dots, a_k)`$：$`S = (t, t)`$ から始め、$`i = 1, \dots, k`$ について $`S := S \oplus \mathrm{root}(A,\ (1, 0, \mathrm{Up}(a_1, \dots, a_i)))`$ とする。
- **$`t`$ が $`\le_2`$ になりうる**：下の $`\mathrm{lh}_1(t)`$。
- **入れ子の極限**：$`t = \mathrm{root}(A, U)`$ なら $`\mathrm{lh}(\mathrm{root}(A', U + 1))`$。ここで $`A'`$ は $`A`$ から最後の $`U`$ のコピーを除いたものである。$`t = \mathrm{root}(A, U + r)`$ で $`r \gt \mathrm{lev}(D)`$ なら $`\mathrm{lh}(\mathrm{root}(A, U + \mathrm{lev}(D))) \oplus 1 \cdots \oplus 1`$。
- **それ以外**は 2 行版の畳み込み：$`S = (t, t)`$ から始め、最後の子 $`W`$ の高い子の頭の部分の $`C1_t`$ の像を畳み込み、次に低い子を畳み込む。像が $`W`$ に等しいときは、入れ子の土台 $`W + 1`$ を使う。

$`x = \mathrm{root}(P, U + q)`$ の最後の組を $`G_a, \dots, G_b`$ とする。$`\mathrm{lh}_1(x)`$ は次のとおり。
- $`q \lt \mathrm{lev}(D)`$ なら、$`x`$ は入れ子であり、$`\mathrm{lh}(\mathrm{root}(P, U + q + 1))`$ である。
- そうでなければ、$`S = \mathrm{lh}(d_q)`$（または $`(d_q)`$）から始める。自分の読みを持つ $`d_m`$ の中で一番大きい $`\mathrm{lh}(d_m)`$ を取る。
- 最後の組の各 $`G_i`$ について：$`i \lt b`$ で、$`G_i`$ が $`G_b`$ より多くの段か中身を持つ極限の加数で、$`G_b`$ がそれを覆わないなら、その塊を畳み込む。そうでなければ $`F(S, x, G_i, d_q)`$ を畳み込む。段 $`q`$ が、同じ段の子を持つ列の後の自分の一番上の段（15.6 (d)）なら、土台は $`d_{q-1}`$ である。
- 鎖を続け、他の子も持つ段の列 $`L_m`$（$`m \lt q`$）の読みを、$`d_m`$ に対して、一番上で畳み込む。
- 切れていない鎖の後に子の無いさらなる 1 段上の子を 1 つ持つ段の列ごとに、$`d_q`$ を 1 回畳み込む。
- **前の加数の塊**：$`G_a`$ より前の、中身を持つ極限の加数ごとに、その塊を畳み込む（名前の付いた場合 `lnest` では 1 つの合わせた塊、15.11）。

### 15.9 証人（D10）

$`G`$ の最後以外の各組について、$`G_{\le e}`$ をその組で終わる頭の部分とする。
- $`G_e`$ が中身を持つ極限の加数なら、証人は無い。その塊が代わりになる。
- $`G_e`$ が $`1 \lt \mathrm{lev}(G_e) \le q`$ の極限の加数なら（その段は $`x`$ の段で覆われる）、証人は段だけの後者 $`\mathrm{root}(P, U + q, U^j, (1, 0, G_{\le e} + \mathrm{chain}))`$ である。ここで $`\mathrm{chain}`$ は段を $`\mathrm{lev}(G_e)`$ 個持つ段だけの列である。$`j`$ は $`G_e`$ の同じ段の子が読む一番高い段である（$`q - 1`$ 以下、そのような子が無ければ 0）。
- それ以外では、$`G_e`$ が極限の加数なら $`G_{\le e}`$ に $`(2, 1, ())`$ を足す（mult）。証人は、$`\mathrm{root}(P, U + q, U^{q-1}, (1, 0, G_{\le e}) + 1)`$ が $`\le_2`$ になりうるならそれである。これは最後の区間 $`(d_{q-1}, d_q)`$ にある（共終、Carlson 2009 Def 5.3 (2)）。

### 15.10 パターン（D11）

- 節点の集合 $`V`$ は、$`\{(),\ (1),\ \hat{M}\}`$ を含み、次の操作で閉じた最小の集合である。
  - 頭の部分の和、根の部分、$`\mathrm{anchor}`$、$`\mathrm{lh}`$；
  - $`\mathrm{lh}(t)`$ の中で作った枠と塊；
  - 後者 $`d_m`$ と証人。
- **Def 9.4 のコピー。** $`V`$ の $`\le_2`$ になりうる $`x`$ で、$`\mathrm{lh}(x) \ne (d_q)`$ かつ、それより小さい $`u \in V`$ で $`\mathrm{lh}(u) = \mathrm{lh}(x)`$ となるものが無いものを取る。それぞれについて、行き止まりでない最小の $`\mathrm{root}(P, U^m)`$ を足す。もう一度閉じ、節点が増える間くり返す。
- 順序は辞書式で、加法は 2 行版のとおり。$`x \le_1 z`$ は、$`x = z`$、または $`x`$ が 1 項で $`x \le z \le \mathrm{lh}(x)`$ のこと。$`\le_2`$ の組は $`x \le_2 d_m`$ で、§2 のとおり閉じる。

## 17. 理論：$`\upsilon_{\omega+1}`$ より下の $`R_2^+`$

$`\Phi_3`$ の順序の問いを決める、$`R_2^+`$ そのものについての最初の定理（補題 L、定理 A・B、命題 P′。§9 の未決の組のうち 20 組が決まる。未決の「極限への一歩」の組 777 のうち 720 組を「<」と確かめた）は、[R2PLUS-ja.md](R2PLUS-ja.md) にある。状態と、未解決のことも書いてある。そこには、`(0,0,0)(1,1,1)(1,1,0)(2,2,1)(2,0,0)(2,0,0)` より小さいすべての標準形の行列（値は $`\upsilon_{\omega\cdot\omega}`$ より下）での順序の証明もある。さらに、査読では見取り図としてだけ認められた新しい補題 FRAG 1 つを仮定した、`(0,0,0)(1,1,1)(1,1,0)(2,2,1)(2,0,0)(2,0,0)(2,0,0)` より下への拡張、未決だった極限への一歩の組すべての証明書、そしてそれより上で `ι∘Φ₃` が基本列に沿って増えない 26 個の極限もある。
