# Trans/BMS/PoR

BMS → Carlson's patterns of resemblance. Two rows (`PSS/`): the map is order-preserving onto the core of R₁⁺ without 0, proved in Lean. Three rows (`Trio/`): the program `por/phi3def2.py` and the proofs on paper.

- [PSS/](PSS/README.md): two rows (pair sequences). The Lean proof and the proof on paper.
- [Trio/POR.md](Trio/POR.md): three rows (trio sequences). The converter, its rules and its tests.
- [Trio/R2PLUS.md](Trio/R2PLUS.md): the theorems about R₂⁺ used for the three-row proofs.
- [Trio/por/README.md](Trio/por/README.md): how to run the converter, and its algorithm.
