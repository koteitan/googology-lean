# 修正 E: 行 3552 に印字されたラベル

[TRIO-SHEET-41-ja.md](TRIO-SHEET-41-ja.md) は、シート
[`tools/omega_alpha_rows.tsv`](https://github.com/koteitan/trio/blob/main/tools/omega_alpha_rows.tsv)
の行 3552 をラベルの誤記と読んだ。シートの行列は `ψ_{Ω_{ω+1}}(Ω_β)` のものである。ここで
`β = ψ_{Ω_{ω+1}}(Ω_{ω+1})`。印字されたラベルは `ψ_{Ω_{Ω+1}}(Ω_β)` である。この印字どおりの順序数に対して、
規則（規則 1–10 も `TrioRules2.lean` も）は標準形でない行列を出す。

このノートでは次の 3 つを書く。

- なぜそうなるか。
- 印字どおりの項の行列。
- 修正を 1 つ（修正 E）。[`TrioRules3.lean`](TrioRules3.lean) に置いた。

[`TrioRules3Sheet.lean`](TrioRules3Sheet.lean) が、シートの全行でこの修正を確かめる。どれも
`#guard` による較正で、定理ではない。

## 記法

- `M(α)` は `ψ_0(Ω_α)` の行列。
- `ψ(w)` は `ψ_{Ω_{Ω+1}}(Ω_w)` の略。この範囲は行 4466（`w = Ω+1`）と行 4468（`Ω_{Ω+1}`）の間にある。
- `P` は `M(ψ(Ω+1))` から最後の列を除いたもの。`P` は規則 9 で下げた葉 `(6,2,0)` で終わる。
- `P₂ = M(ψ(Ω_2)) = P ++ (7,3,1)(8,3,1)(9,2,0)`。これが行 4467。
- `L(x,y,z) = (x+1, y+1, z)` は、列を 1 階持ち上げる写像。

印字されたラベルは `ψ(β)` である。`β = ε_{Ω_ω+1}` は `Ω_ω` と `Ω_{ω+1}` の間にある。よって
`Ω_2 < β < Ω_Ω`。

## 規則が標準形でない行列を出す理由

規則 9 は、引数のレベル `w` を `writeLevel` で書く。まず、`M(w)` と梯子（`M(2)`、`M(Ω+1)`、
作りかけの行列）とが共有する列のうち、いちばん深いレベル列を探す。`M(w)` のうち、その列より後ろを写す。
写した列のうち、持ち上げるのは z1 列とレベル列だけである。持ち上げる量は、文脈が使った深さの分。

`Ω_ω ≤ w` のとき、`M(w)` は `B ++ (1,1,1)` で始まる。どの梯子ともレベル列を共有しない。そのため
`M(w)[1:]` 全体が写され、2 だけ持ち上げられる。`Ω` の葉は持ち上がらない。

- `B` の葉 `(3,1,0)` は `y = 1` のまま残る。そのため `w ≥ Ω_ω` の `ψ(w)` はどれも
  `P ++ (7,3,1)(8,3,1)(9,1,0)` で始まる。これは、`w > Ω_2` なのに `P₂ = M(ψ(Ω_2))` より小さい。
  たとえば `M(ψ(Ω_ω)) = P ++ (7,3,1)(8,3,1)(9,1,0)(7,3,1)` は `M(ψ(Ω_2))` より下にある。
- `w = β` では、`M(β)` の下げた葉 `(5,1,0)` も `y = 1` のまま残る。一方で、その上のレベル列は
  `(8,3,0)` に上がる。できる行列は
  `P ++ (7,3,1)(8,3,1)(9,1,0)(7,3,1)(8,3,0)(9,4,1)(10,4,1)(11,1,0)(12,4,0)`。これは標準形でない
  （yaBMS `bms -s`）。そして `M(ψ(Ω_2))` より下にある。

TRIO-SHEET-41 の訂正: その「副次的な発見」は、この行列が「`M(ψ_{Ω_{Ω+1}}(Ω_{Ω_2}))` より上にある」と書く。
実際は下にある（`bms -c` の結果は `-1`）。上にあるのはラベルのほうである。

壊れているのはこの 1 行だけではない。`u = Ω+1` で、`(Ω_2, Ω_Ω]` の中から試した引数のレベル `w` は、
すべて標準形でないか、順序が合わない。試したのは `Ω_2+1`、`Ω_3`、`Ω_ω`、`Ω_ω+1`、`β`、`Ω_{ω+1}`、
`Ω_Ω`。シートには、4466 と 4467 のほかにこの範囲の行がない。

## 印字どおりの項の行列

```
M(ψ_{Ω_{Ω+1}}(Ω_β)) = P₂ ++ L(M(β)[4:])
  = (0,0,0)(1,1,1)(2,1,1)(3,1,0)(1,1,1)(2,1,1)(3,1,0)(1,1,0)(2,2,1)(3,2,1)(4,2,0)(2,2,1)(3,2,1)
    (4,1,0)(3,2,0)(4,3,1)(5,3,1)(6,2,0)(7,3,1)(8,3,1)(9,2,0)(2,2,1)(3,2,0)(4,3,1)(5,3,1)(6,2,0)(7,3,0)
```

`M(β)` はシートの行 3546。根拠は次の 5 つ。

1. **標準形。** yaBMS `bms -s` の結果は `1`。
2. **順序。** `TrioRules2Sheet.lean` の順序検査で使う 783 個の行列に、この 1 個を足す。
   784 個の行列、306,936 組になる。どの組でも、行列の順序はラベルの順序（`cmpOrd`）と一致する。
   特に、この行列は行 4467 と行 4468 の間にある。さらに L 行の印字ラベル 9 個を足すと 792 個になる。
   そのとき残る例外は、行 4369 の印字ラベルだけである。これは `ω^3·Ω` を正規化しない欠陥による。
   修正前は、行 3552 がもう 1 つの例外だった。
3. **展開。** `n = 0, …, 3` で、BM4 の展開はこの作り方と可換である:
   `(P₂ ++ L(M(β)[4:]))[n] = P₂ ++ L(M(β)[n][4:])`。検査には `expandRL 3 n` を使う。
   `EntriesR.lean` が、これは BM4 の展開だと証明している。つまりこの行列は、`β` の基本列
   （`Ω_ω` の塔）を 1 階上で持つ。
4. **土台 `Ω_ω`。** この作り方では、引数 `Ω_{Ω_ω}` は `P₂ ++ (2,2,1)` になる。形は次のとおり。
   - `Ω_2` を指す葉 `(9,2,0)` の後に、規則 5 の昇格の印 `(2,2,1)` が付く。
   - 印の位置は、土台 `M(Ω_{Ω+1})` にすでにその印がある位置である。
   - 一致する行 4457 も、最上位で同じ形をしている: `M(Ω_Ω+Ω_ω) = … (8,2,0)(2,2,1)`。

   `P₂ ++ (2,2,1)` の展開 `[1]` は、`P₂` の後に 1 階持ち上げた階を 1 つ置き、葉 `(10,3,0)` で終わる。
   これは、規則 6 が綴る引数 `Ω_{Ω_3}` である（レベル 1 つにつき 1 階）。レベル `ω` の引数は、どれもこの
   土台の上に積む。最上位で `M(Ω_ω + δ)` が `M(Ω_ω) = B ++ (1,1,1)` の上に積むのと同じである（規則 2）。
5. **葉の下に置けない理由。** `ψ_{Ω_{ω+1}}` の範囲（行 3550–3552）では、`Ω_ω` より上の引数は葉
   `(8,1,0)` の下に置かれる。ところが `ψ_{Ω_{Ω+1}}` の範囲では、葉 `(9,2,0)` の下はレベル `Ω` の引数が
   すでに使っている。
   - 行 4468 の展開 `[2]` は `P₂ ++ (10,3,1)(11,3,1)` で、入れ子の `ψ_{Ω_{Ω+1}}` である。
   - `M(ψ(ψ_{Ω_{Ω+1}}(Ω_{Ω+1}))) = P₂ ++ (10,3,0)` の展開は `P₂ ++ (10,2,0)(11,2,0)⋯` である。

   この葉の塔は `ε_{Ω_Ω+1}` に届く。したがって、子を持つこの葉は `Ω_Ω` を指す。レベル `ω` は別の場所に
   置くしかない。

これで決まらないこと: シートには、行 4467 と行 4468 の間に行がない。だからシートはこの行列を確かめていない。
根拠は、標準形・順序・展開の 3 つである。

## 修正 E

[`TrioRules3.lean`](TrioRules3.lean) では、`MpsiLevel2` の代わりに `MpsiLevel3` を使う。修正が効くのは、
規則 9 で `u = Ω+1` かつ引数のレベルが `Ω_ω ≤ w < Ω_{ω+1}` を満たすときである:

```
M(ψ_{Ω_{Ω+1}}(Ω_w)) = M(ψ_{Ω_{Ω+1}}(Ω_{Ω_2})) ++ L(M(w)[4:])
```

このような `w` ではいつも `M(w)[0:5] = B ++ (1,1,1)` が成り立ち、コードはこれを確かめる。それ以外は
`TrioRules2.lean` のまま。

**適用範囲。** `u = Ω+1` に限る。非可算の `u` のうち、最初の点 `ψ_{Ω_u}(Ω_u)` より上にシートの行が
あるのはこの `u` だけだから（行 4466 と 4467）。`u = Ω+2`、`Ω_2+1`、`Ω_ω+1`、`Ω_Ω+1` については、
シートにはその最初の点しかない（行 4492、4526、4619、4754）。レベルも `ω` に限る。持ち上げはその先へ延ばせないからである。

- `L(M(Ω_{ω^ω})[4:])` は `(4,1,0)` で終わる。これは、行 4458 と 4464 が `Ω_Ω` に付ける印
  `(2,2,1)(3,2,1)(4,1,0)` と同じになる。
- シートの `Ω_{ω^ω+1}` から `Ω_{ψ_0(Ω_Ω)}` までの行（4382–4391。行 4384 は訂正ラベル `Ω_{ω^ω·2}` で）
  では、持ち上げた行列は標準形でない。

その手前では、持ち上げは標準形を保つ。`Ω_ω ≤ a < Ω_{ω^ω+1}` を満たすシートのラベル `a` は、重複を除いて
286 個ある（そのうち 96 個がレベル `ω`）。どの `a` でも、`P₂ ++ L(M(a)[4:])` が標準形になるのは、規則自身の
`M(a)` が標準形のときに限る。標準形にならないのは行 3480–3482 のラベルだけで、そこでは `M(a)` も
標準形でない。

**結果**（`TrioRules3Sheet.lean`）:

- 重複を除いた 817 個のラベル（813 行のラベル 808 個と、L 行の訂正ラベル 9 個）で、修正 E は
  `TrioRules2.lean` と同じ行列を出す。違うのは行 3552 の印字ラベルだけである。
- 上の順序検査で、食い違いは 0。
- Python でも照合した（参照プログラムの写しに修正を当てたもの）。817 個のラベルで同じ比較をし、
  一致する 744 行はすべて一致し、783 個の行列で食い違いは 0。

## 副次的な発見: 行 3551

TRIO-SHEET-41 は、行 3551 `ψ_{Ω_{ω+1}}(Ω_{Ω_ω})` を R（弱い）とする。シートの `… (8,1,0)(1,1,1)` より、
規則の `… (8,1,0)(6,2,1)` を採った判定である。類推で読むと、展開は逆を示す。

- 規則の行列の `[1]` は、単位 `(6,2,0)(7,3,1)(8,3,1)(9,1,0)` を足す。葉 `(8,1,0)` の後ろに、`Ω` を指す
  2 つ目の葉が付く形である。これは、規則が最上位の `M(Ω_ω+Ω)` に置く単位 `(4,2,0)(5,3,1)(6,3,1)(7,1,0)`
  と同じ形をしている。そう読むと `[1]` は引数 `Ω_{Ω·2}` で、`[2]` は 3 つ目の葉を足す。すると基本列は
  `Ω·n` なので、この印は引数 `Ω_{Ω·ω}` であり、`Ω_{Ω_ω}` ではない。
- シートの行列の `[1]` は、1 階持ち上げた階で、葉 `(9,2,0)` で終わる。これは `P₂` の中の引数
  `Ω_{Ω_2}` の形である。そう読むと、これは `Ω_ω` の基本列 `Ω_n` である。

これは類推による読みであり、較正ではない:
- `x = Ω+1, Ω·2, Ω·ω, Ω_2` での規則自身の `ψ_{Ω_{ω+1}}(Ω_x)` の行列は標準形でない（yaBMS `bms -s`）。
  だから、どちらの読みも裏付けられない。
- シートには行 3550 と 3551 の間の行がない。
- 順序検査は、行 3551 にどちらの行列を使っても通る。

したがって行 3551 は「シートが正しい」寄りだが、どちらにしても根拠は弱い。修正 E は行 3551 を
変えない。検査は `TrioRules3.lean` にある。

## 残る問題

- `u = Ω+1` で `Ω_2 < w < Ω_ω`（たとえば `Ω_2+1`、`Ω_3`）の場合と、`Ω_{ω+1} ≤ w ≤ Ω_Ω` の場合。
  ここでの規則の行列は、まだ標準形でないか、順序が合わない。
- `u = ω+1` で `Ω < w < Ω_ω` の場合: `w = Ω+1, Ω·2, Ω·ω, Ω_2` での規則の `ψ_{Ω_{ω+1}}(Ω_w)` の行列は
  標準形でない（上の行 3551 を見よ）。
- 他の非可算の `u`（`Ω+2`、`Ω·2`、`Ω_2+1` など）でも同じ問題がある。そこでは、規則自身の
  `M(ψ_{Ω_u}(Ω_{Ω_2}))` がすでに怪しい。たとえば `u = Ω+ω` では標準形でない。
- 一般に、非可算の領域で `2 < ν < Ω` の `Ω_ν` を指す葉。最上位にも同じ弱点がある:
  `Ω_Ω+Ω_3` は標準形でなく、`Ω_Ω+Ω_{ω+1}` は `Ω_Ω+Ω_2` と同じ行列になる。
  [TRIO-ROW-3480-ja.md](TRIO-ROW-3480-ja.md) にある `β+Ω_2, β+Ω_3, β+Ω_ω, β·2` の衝突と比べよ。
