# トリオのシートの行 3480: `ψ_0(Ω_{Ω_ω·Ω+Ω_3})`

[koteitan/trio](https://github.com/koteitan/trio) のシート
[`tools/omega_alpha_rows.tsv`](https://github.com/koteitan/trio/blob/main/tools/omega_alpha_rows.tsv)

**どちらの側も正しくない。ラベルは正しく、行列は第 3 のもの。** `β = Ω_ω·Ω` と書く。すると

```

           (1,1,0)(2,2,1)(3,2,1)(4,2,0)(2,2,1)(3,2,0)(4,3,1)(5,3,1)(6,2,0)(5,3,1)(6,1,0)
           (5,3,0)(6,4,1)(7,4,1)(8,2,0)
           (2,2,0)(3,3,1)(4,3,1)(5,3,0)(3,3,1)(4,3,0)(5,4,1)(6,4,1)(7,3,0)(6,4,1)(7,1,0)
           (6,4,0)(7,5,1)(8,5,1)(9,3,0)
```

はじめの 3 行は規則の `M(β+Ω_2)`。あとの 2 行は 2 階目の階（storey）。この行列を
[`TrioRow3480.lean`](TrioRow3480.lean) では `c2` と呼ぶ。

|---|---|---|---|

| このノート | 上の `c2` | はい（Lean で証明） | `M(β+Ω_3)` |

ラベルの位置は正しい。行 3479 は `β+ω`、行 3483 は `β·ω` で、`β+ω < β+Ω_3 < β·ω`。だからラベルの誤記ではない。

## 記法

このノートでは、`M(α)` は `ψ_0(Ω_α)` の行列、`β = Ω_ω·Ω`。`A[n]` は悪い部分を `n+1` 個並べる BM4 展開で、yaBMS の `[n]` や `expandRL 3 n` と同じ。`A ++ B` は `A` の列のあとに `B` の列を並べたもの。使う行列は次のとおり。

| 名前 | 行列 | 読み |
|---|---|---|
| `w1` | `mβ S (5,3,0)(6,4,1)(7,4,1)(8,1,0)` | `M(β+Ω)`（規則） |
| `w2` | `mβ S (5,3,0)(6,4,1)(7,4,1)(8,2,0)` | `M(β+Ω_2)`（規則） |
| `c2` | `w2 ++ storey2`（`storey2` は表示の最後の 2 行） | `M(β+Ω_3)` |
| `lM` | `w2 ++ (2,2,1)` | `M(β+Ω_ω)` |
| `t2` | `w2 ++ (7,4,1)` | 規則: `M(β+Ω_2·ω)`、このノート: `M(β+Ω_ω·ω)` |
| `b1` | `w2 ++ (7,4,1)(8,1,0)` | `M(β·2)` |

ここで `mβ = M(β)`（行 3460、上の表示の 1 行目）、`S` は 1 階目の階（表示の 2 行目）。

## `c2` の作り方

`c2` は、シートと規則が一致する行で、1 段低いところでシートがしていることを繰り返したもの。

```
M(Ω_ω+Ω_3) = M(Ω_ω+Ω_2) ++ (2,2,0)(3,3,1)(4,3,1)(5,3,0)(3,3,1)(4,3,0)(5,4,1)(6,4,1)(7,3,0)(6,4,0)(7,5,1)(8,5,1)(9,3,0)    （行 3377）
```

足した列は、`M(Ω_ω+Ω_2)` の階（`M(Ω_ω+Ω)` のあとの列）の各列に `(1,1,0)` を足したもの。最後の葉 `(9,3,0)` の行 1 の親は、新しい階の根 `(2,2,0)`。シートは `Ω_3` をこう書く。

`c2` は `w2` に同じことをする。例外が 1 つある。階の列 `(6,1,0)` の行 1 の親は根 `(0,0,0)` なので、BM4 のコピーはその行 1 の値を上げない。だから `(7,2,0)` ではなく `(7,1,0)` になる。`(7,2,0)` にすると、行列は標準形でなくなる。

## 根拠

1. **`c2` は標準形。** yaBMS の `bms -s` は `1` を返す。[`TrioRow3480.lean`](TrioRow3480.lean)
   は `TrioStdL c2` を証明する。つまり `c2` はトリオの断片（`(0,0,0)(1,1,1)(2,2,1)⋯` を
   `expandRL 3 n` で閉じたもの）に入る。証明は `(0,0,0)(1,1,1)(2,2,1)` から `lM` までの 63 ステップ。
   各ステップでは展開してから接頭部分を残す。標準形の接頭部分は標準形（`trioStdL_prefix`）。
   もう 1 ステップで `c2 = lM[1]` になる。定理は `trioStdL_lM` と `trioStdL_c2`。
2. **展開。** `lM[0] = w2`、`lM[1] = c2`。一致する行では、最後の印（mark）はコピー 1 つごとに最後の
   `Ω` の段を 1 つ上げる。
   - `M(Ω_ω·2)[n] = M(Ω_ω+Ω_{n+1})`、`n = 0, 1, 2`（行 3338、3376、3377）
   - `M(Ω_ω^2)[n] = M(Ω_ω·Ω_{n+1})`、`n = 0, 1, 2`（行 3460、3491、3493）

   `lM` も同じことを 1 段上でする。`w2` の葉の行 1 の親が階の根 `(1,1,0)` だから。よって
   `lM[n] = M(β+Ω_{n+2})`。つまり `lM[0] = M(β+Ω_2)`、`lM[1] = M(β+Ω_3)`。
3. **順序。** `M(β+ω) < c2 < M(β·ω)`。この 2 つはラベルの隣の一致する行（3479 と 3483）。だから `c2`
   は一致する 744 行のすべてに対して正しい側にある。参照実装の `cmp_ord` で 1 行ずつ調べても違反は
   0。もっと大きな検査も通る。TRIO-SHEET-41-ja.md の 783 個の行列（一致する 744 行と、決めた 39 行）を
   使い、このノートの読みで 14 個の行列を足す。
   - `c2 = M(β+Ω_3)`、`lM = M(β+Ω_ω)`、`lM[2] = M(β+Ω_4)`
   - `t2 = M(β+Ω_ω·ω)`、`w2 ++ (7,4,0)(8,5,0) = M(β+Ω_ω+1)`、`b1 = M(β·2)`、`M(β·ω)[2] = M(β·3)`
   - 4 項目の 4 つの行列
   - 規則の `M(β+Ω)`、`M(β+Ω·ω)`、`M(β+Ω_2)`

   そして 317,206 組をすべて比べる。どの組でも行列の順序はラベルの順序と同じで、同じ行列を持つラベルの
   組もない。14 個の行列はすべて標準形（yaBMS）。
4. **`c2` の下に隙間がある。** 順序数 `β+Ω_2+1`、`β+Ω_2·ω`、`β+Ω_2·Ω`、`β+Ω_2^2` は `w2` と `c2`
   の間にないといけない。実際にある。2 階目の階の葉を `(9,2,0)` にして、そのあとに `(8,5,0)(9,6,0)`、
   `(8,5,1)`、`(8,5,1)(9,1,0)`、`(8,5,1)(9,2,0)` を続けたもの。4 つとも標準形で、この順に並ぶ。
   `M(Ω_ω+Ω_2)` の上に同じ形で作った 4 つも標準形で、`M(Ω_ω+Ω_3)` より小さい。ここでも 2 つの族は
   合う。

## もう一つの読みと、それが成り立たない理由

規則は `β+Ω_2·ω` に `t2 = w2 ++ (7,4,1)` を出す。`t2` は標準形で、行列として `lM < t2`。もし `t2` が
`M(β+Ω_2·ω)` なら、`lM` と `c2` は `β+Ω_2·ω` より下にあることになり、`M(β+Ω_ω)` や `M(β+Ω_3)` には
なれない。だから 2 つの読みのどちらかは捨てることになる。次の 3 点から、成り立たないのは規則の読みの方。

- **`(X·ω)[1] = X·2`。** `M(β·ω)` は一致する行（3483）で、`M(β·ω)[1] = b1 = t2 ++ (8,1,0)`。一致する
  行では、`X` の最後の因子が `Ω_v`（`v` は後続数）のとき、`X·ω` の最初の展開は `X·2` になる。

  | `X` | `M(X·ω)[1]` | 行 |
  |---|---|---|
  | `Ω_2·Ω` | `M(Ω_2·Ω·2)` | 2753 → 2752 |
  | `Ω^2` | `M(Ω^2·2)` | 2524 → 2523 |
  | `Ω_2^2` | `M(Ω_2^2·2)` | 2764 → 2763 |
  | `Ω_{ω+1}` | `M(Ω_{ω+1}·2)` | 3711 → 3707 |

  最後の因子が `Ω_ω` のときはそれが `Ω` になり（`Ω_ω·ω → Ω_ω+Ω`、3406 → 3338）、その前にある因子
  `Ω_ω` はそのまま残る（`Ω_ω^2·ω → Ω_ω^2+Ω_ω·Ω`、3531 → 3527）。`β = Ω_ω·Ω` の最後の因子は `Ω`
  なので、`M(β·ω)[1] = M(β·2)`、つまり `b1 = M(β·2)`。規則の読みでは `b1 = M(β+Ω_2·Ω)` になる。これは
  先頭の因子 `Ω_ω` を `Ω_2` に下げることで、一致する行でそうなるものは 1 つもない。
- **数字（digit）が続くと葉が上がる。** `X = M(Ω_ω·ω+Ω)`（規則）とする。`X` は葉 `(7,1,0)` で終わる。
  行 3454（`Ω_ω·ω·2`）は `X ++ (6,3,1)`、行 3451（`Ω_ω·ω+Ω_ω`）は `X ++ (1,1,1)` で、どちらも一致する
  行。つまり葉 `(7,1,0)` は、行列の最後にあるときは `Ω` を表すが、数字 `(6,3,1)` が続くと項は `Ω·ω`
  ではなく `Ω_ω·ω` になる。`w2` の葉も同じように階の印 `(2,2,1)` の下にある。階の根 `(1,1,0)` から
  測ると（各列から `(1,1,0)` を引くと）、`w2` の葉の祖先の列は
  `(0,0,0)(1,1,1)(2,1,0)(3,2,1)(4,2,0)(5,3,1)(6,3,1)(7,1,0)` で、これは `X` の葉の祖先の列とちょうど
  同じ。だから `t2 = w2 ++ (7,4,1)` は `β+Ω_ω·ω`、`b1 = t2 ++ (8,1,0)` は `β+Ω_ω·Ω = β·2`。1 点目と
  合う。
- **どの続きが標準形になるかを説明できる。** `Ω_ω` の族では、`M(Ω_ω+Ω_2)` の葉 `(8,2,0)` のあとの続き
  はどれも標準形でない（`+ (7,4,0)(8,5,0)`、`+ (7,4,1)`、`+ (2,2,1)`）。`β` の族では、`w2` のあとの
  同じ続きが標準形。葉が上がるならこれは当然。`Ω_ω` の族では、続きは `Ω_ω·2` 以上の順序数（例えば
  `Ω_ω+Ω_ω+1 = Ω_ω·2+1` や `Ω_ω+Ω_ω·ω`）を表すことになる。ところがその行列は
  `M(Ω_ω·2) = M(Ω_ω+Ω) ++ (1,1,1)` より小さくなってしまい、それはありえない。`β` の族では
  `β+Ω_ω·ω < β·2` を表すので、ありうる。規則の読みでは、この違いの理由がない。

| `β+Ω_3` | `(8,3,0)` で終わる（標準形でない） | `c2` |
| `β+Ω_ω` | `(8,3,0)(5,3,1)` で終わる（標準形でない） | `lM = w2 ++ (2,2,1)` |
| `β·2` | `(8,3,0)(7,4,1)(8,1,0)` で終わる（標準形でない） | `b1 = w2 ++ (7,4,1)(8,1,0)` |

- 行 3481（`β+Ω_ω`）は、`w2` の葉を `(8,3,0)` にして `(2,2,1)` を続けたもの。`(8,2,0)` にすると `lM` になる。

つまり、シートも規則も、BM4 では「`(8,2,0)` のあとに列が続く」形で書かれる段に、葉 `(8,3,0)` を使っている。
