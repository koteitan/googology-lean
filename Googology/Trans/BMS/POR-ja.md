# トリオ数列から加法的パターン（$`R_2^+`$）への写像 $`\Phi_3`$（途中）

**状態：部分的な規則と、実験の記録。** 証明も形式化も無い。

2 行の $`\Phi`$（[PSS/POR-ja.md](../PSS/POR-ja.md)）を、3 行の行列（トリオ数列）から Carlson の加法的パターン（階数 2）
$`R_2^+ = (\mathrm{Ord}; 0, +; \le, \le_1, \le_2)`$ への写像 $`\Phi_3`$ に広げる試みの記録である。

## 1. 結果の要約

- **働く範囲。** $`(0,0,0)(1,1,1) = \psi_0(\Omega_\omega)`$ から、$`(0,0,0)(1,1,1)(2,1,0)`$ の手前まで。$`\psi`$ で書くと $`\psi_0(\Omega_\omega \cdot k + \cdots)`$ と $`\psi_0(\Omega_\omega \cdot \omega + \cdots)`$ の辺りである。この範囲では、シートと合い、順序の食い違いは見つかっていない。
- **その先。** 2 つ目の潰す操作を足すと、シートとの一致は増えた。しかし $`[(0,0,0)(1,1,1)(2,1,0),\ (0,0,0)(1,1,1)(2,1,1))`$ で、順序の食い違いが出た。原因の形は、5 つに分類できている（§5）。
- **2 段の潰す操作の版**（§6）。場合ごとの規則を、2 つの潰す操作の再帰に置き換えた。シートとの一致は 444 行から 458 行に増え、新しい範囲の悪い組は 19 組から 11 組に減った。ただし、局所的に決まらない規則が 3 つ残った。
- **Carlson の定義から読んだ規則**（§7）。3 つの規則のうち 2 つを、$`\le_2`$ の定義から理由の付く局所的な規則に言い直した。また、入れ子の $`\omega`$ の列の潰し方を直した。一致は 468 行になり、2 つの順序の検証で食い違いは 0 になった。
- **1 つの反映の規則**（§8）。Carlson の下向きの 2 反映（Def 9.4）から 1 つの規則が出て、3 つ目の規則を置き換え、さらにシートの行を説明した。一致は 503 行になり、食い違いは 0 のままである。
- **Wilken の $`R_2`$ と未決の組**（§9）。Wilken の $`R_2`$ の解析は $`R_2^+`$ を記述しないので、組を決めるのには使えない。時間を延ばした計算器で、未決の 310 組のうち 23 組を確かめ、食い違いは見つからなかった。行 844 は $`\Phi_{3i}`$ が正しく、修正表を直すべきである。行 907 と 1009 はまだ決まらない。

## 2. 規則の形

2 行の $`\Phi`$ と同じく、行 0 の親の森を足し算の構造として読む。項は $`(y, z, \text{子})`$ である。$`\Phi_3(M)`$ は、$`\{0, 1, M\}`$ を次の操作で閉じたものである。

- 根の成分、途中までの和、anchor、$`\le_1`$ の届く先 $`\mathrm{lh}`$
- $`\le_2`$ の後者と、$`\le_2`$ の証人の節点

$`x \le_1 y`$ は $`x \le y \le \mathrm{lh}(x)`$ と読む。$`\le_2`$ の組は列挙してから閉じる。行 2 が全部 0 の行列では、$`\Phi_3`$ は 2 行の $`\Phi`$ と一致する。

2 行から増えた主な規則は次のとおりである。

- **根の最後の子が $`z = 1`$ の列の連なりのとき。** 2 行と同じ畳み込み $`\oplus`$ を、1 段上へのコピーで行う。コピーの中では、$`z = 1`$ の列は 1 段上がり、$`(y = 1, z = 0)`$ の列は $`N`$ に潰れ、$`y = 0`$ の列はそのまま残る。
- **$`\le_2`$ の組ができるとき。** 最後の子 $`W`$ の下に $`z = 1`$ の列があり、その後ろが葉だけのとき、$`\le_2`$ の後者の列が生まれる。例：シートの行 541 $`\lt_2`$ 行 551。
- **2 つ目の潰す操作。** 添字の列（子を持つ $`(y = 1, z = 0)`$ の列）の部分木を、$`\le_2`$ の点 $`c`$ に相対化して、2 行の $`\Phi`$ で読んだ節点を、$`\le_2`$ の区間の中に置く。潰し方は次のとおりである。

```math
\Omega_\omega \mapsto c,\qquad \Omega_{\omega + \nu} \mapsto \Omega_\nu
```

- **段の数え方。** 同じ段の $`z = 1`$ の子は、$`\le_2`$ の届く先を倍にする。この部分は、一部しか入っていない。

実装は `por/phi3.py` である。旗（flags）で版を選ぶ。

| `z,dbl,idx,lvl,lev`（既定） | 2 つ目の潰す操作と、段の数え方の一部を足した版 |

## 3. 比べ方

- **シート。** 表計算シート "Sheetified Patterns of Resemblance"（作者不明）の 3 行の行を使った。シートのパターンは、それ自体が $`\Phi`$ 型の閉包になっているので、構造を直接比べた。
  - iso：$`\Phi_3(M)`$ がシートのパターンと同じ構造である。
  - sub：シートのパターンが、$`\Phi_3(M)`$ の節点の一部（点を含む）の制限になっている。このとき、比較の計算器で $`\iota(\Phi_3(M)) \le \iota(\text{シート})`$ を確かめる。埋め込みから逆向きも出るので、両者は等しい。

## 5. 残った原因

1. コピーした $`z = 1`$ の列の中の、子を持つ $`(y = 1, z = 0)`$ の列（シートの行 787–809）。今は葉の倍数としか扱わず、部分木を捨てる。同じパターンになる組の大半は、これが原因である。
2. 添字の列の下の $`z = 1`$ の列（行 904–914）。$`\le_2`$ の区間の中に、さらに $`\le_2`$ の組を作れる点が要る。
3. 最後の $`D`$ が添字の葉で、その後ろに $`W`$ の子が続く形（行 826–844、884）。
4. 2 つ目の $`\le_2`$ の点の隣に、シートが置く $`\le_1`$ の入れ子の土台の節点（行 764、819、854）。
5. 行 915 より上の段の数え方。

## 6. 2 段の潰す操作（$`\Phi_{3g}`$）

2 行の $`\mathrm{Coll}`$ は、潰す先が 1 つ（$`\Omega_1 \mapsto N`$）だった。3 行では、潰す先を 2 つ持つ。場合ごとの規則をやめて、2 つの潰す操作の再帰で $`\Phi_3`$ を作り直した（`por/phi3g.py`）。

**列の段。** 潰す部分木の中で、各列は次のどれかである。

- **有限の段 $`y`$**：$`z = 0`$ で、$`z = 1`$ の先祖が無いか、その先祖の $`y`$ より下。有限の列の下も有限である。
- **$`\omega`$ の段**：$`z = 1`$。
- **添字の段 $`\omega + j`$**：$`z = 0`$ で、$`z = 1`$ の先祖 $`a`$ の下にあり、$`y = a.y + j`$。$`j = 0`$ のものを**印**と呼ぶ。

**$`C1_N`$：$`\Omega_1`$ の段の潰し**（$`\Omega_1 \mapsto N`$、$`\Omega_{1+\nu} \mapsto \Omega_\nu`$）

- $`y = 0`$ の列：そのまま。
- 有限の $`y = 1`$ の列：$`N`$ の子に $`C1_N`$（子）を足した、$`y = 0`$ の根の列になる。
- 有限の $`y \ge 2`$ の列：$`y - 1`$。
- 添字の列：不動点。$`\omega`$ の先祖が動けば、一緒に動く。
- $`y = 2`$ の $`\omega`$ の列：$`y = 2`$ のまま、段 1 の列 1 本で包む（$`\psi_1(\Omega_\omega \cdots)`$ に当たる）。
- $`y \ge 3`$ の $`\omega`$ の列：$`y - 1`$。

**$`C2_x`$：$`\Omega_\omega`$ の段の潰し**（$`\Omega_\omega \mapsto x`$、$`\Omega_{\omega+j} \mapsto \Omega_j`$）。コピーした $`\omega`$ の列 $`D`$ の子に使う。$`x`$ は $`\le_2`$ の組を作れる点である。

- $`y = 0`$ の列：そのまま。
- 印：$`x`$ の子に $`C2_x`$（子）を足した、$`y = 0`$ の根の列になる。
- 添字 $`\omega + j`$（$`j \ge 1`$）：有限の段 $`j`$ になる。
- $`D`$ の下の有限の列：$`x`$ の子に $`C1_x`$（子）を足した根の列になる。

**届く先。** $`\mathrm{lh}`$ は、2 行の畳み込み $`\oplus`$ にこの 2 つの潰しを入れたものである。$`\oplus`$ の 2 つ目の場合は、「$`Y`$ が $`\le_2`$ の組を作れるなら $`\mathrm{lh}(Y) + Y`$、そうでなければ $`\mathrm{lh}(Y)`$」になる。$`\le_2`$ の届く先 $`\mathrm{lh}_2`$ も、同じ形の畳み込みで作る。

**局所的に決まらない 3 つの規則。** 各列の $`(y, z)`$ と先祖だけで決める純粋な版は、シートの行 755–914 のうち 69 行にしか合わなかった。シートは、兄弟や最後の加数全体を見る、次の 3 つの判断を要る。

1. 最後の $`\omega`$ の加数の右端の道にある葉の印は、有限の列（$`\Omega_1`$ の倍数）として扱う。同じ局所的な形 $`(3,2,0)`$ が、行 759 と行 851 で別の役を持つ。
2. 極限の加数（右端の葉が印）の直後の単位の加数は、その後者で、同じ $`\le_2`$ の段をなす。
3. 倍にした段は、その $`\le_1`$ の入れ子の土台も節点として持ち込む。

## 7. Carlson の定義から読んだ規則（$`\Phi_{3h}`$）

§6 の 3 つの規則を、Carlson (2009) の $`\le_1`$ と $`\le_2`$ の定義、および Wilken, "Pure Σ₂-elementarity beyond the core"（APAL 172, 2021, [doi:10.1016/j.apal.2021.103001](https://doi.org/10.1016/j.apal.2021.103001)）の §1 にある $`R_2`$ の性質と照らし合わせた。3 つのうち 2 つは、局所的な規則に言い直せた。新しい版は `por/phi3h.py` である。

記法：$`N = \psi_0(\alpha)`$ は潰す点、$`W`$ は $`\alpha`$ の最後の加数である。

**規則 1（最後の列）。**
- **局所的な形。** 葉の印 $`m`$ が $`\Omega_1`$ の倍数になるのは、$`m`$ が今の潰す先の引数の最後の列で、かつ、その引数のいちばん外の $`\omega`$ の列の印であるとき、そのときだけである。
- **理由。** 1 行の再帰 $`\mathrm{lh}(\alpha) = \alpha + \mathrm{lh}(\rho_1) + \cdots + \mathrm{lh}(\rho_m)`$ と同じく、$`N`$ の届く先は $`W`$ だけで決まる。
  - $`\omega`$ の加数の中で、後ろにまだ項がある $`\Omega_1`$ は、段 $`\omega + 0`$ の係数である。$`\nu \ge \omega`$ なら $`1 + \nu = \nu`$ なので、$`C1`$ はこれを動かさない。
  - 引数全体の最後の $`\Omega_1`$ は、$`W`$ の有限の項である。$`C1`$ はこれを $`N`$ に送る。
- **確認。** この規則を外すと、$`\Phi(755)`$ と $`\Phi(810)`$ が、シートの次の行（756 と 811）以上になることを計算器が示した。

**規則 2（極限の直後の単位）。**
- **局所的な形。** コピーした $`\omega`$ の加数を $`\Omega_\omega \beta_1 + \cdots + \Omega_\omega \beta_k`$ と書く。$`\le_2`$ の段は、この倍数の後者の加数である。極限の加数の直後の単位の加数は、その極限の後者である。
- **理由。** $`a \lt_2 b`$ なら、$`a`$ は $`\lt_1`$ の無限の鎖の真の上限である（Wilken 2021 §1、Carlson 2009 Lemma 5.5）。極限の加数 $`\Omega_\omega \lambda`$ には、この鎖が無い。$`\Omega_1`$ の潰しが鎖を切るからである。だから、その段は $`\lambda + 1`$ で現れる。
- **確認。** この規則を外すと、$`\Phi(845)`$ と $`\Phi(863)`$ が、シートの次の行（846 と 864）以上になることを計算器が示した。

**規則 3（倍にした段の入れ子の土台）。**
- **局所的な形。** $`\mathrm{lh}_1(w) \gt \mathrm{lh}_2(w)`$ となる証人 $`w`$ は、$`C1`$ の入れ子の 1 つ前 $`e`$ を持ち込む。ここで $`e \le_1 \mathrm{lh}_1(w)`$ である。
- **理由（証明は無い）。** 同型最小の実現は、閉じた被覆のうち各点で最小のものである（Carlson 2009 Thm 14.10）。$`e`$ が無いと、組 $`(w, \mathrm{lh}_2(w))`$ が入れ子の届く先の中にあることが強制されない。
- **未確認。** この規則を外したとき、計算器は行 929 も行 944 も判定できなかった。

**入れ子の潰し（§6 の食い違い 10 組）。** 計算器によると、誤りは大きい方の行列にあった：$`\Phi_{3g}(905) \le \text{シート}(904)`$。行 905 の最後の列 $`(4,2,0)`$ は、内側の $`\omega`$ の列 $`(3,2,1)`$ の印で、その列は添字の列 $`(2,1,0)`$ の下にある。$`\Phi_{3g}`$ はこれを外側の点に潰していたが、シートは内側の段の証人に潰す。直し方：

- (a) $`z = 0`$ の列は、段が自分の $`y`$ 以下の $`\omega`$ の先祖のうち、**いちばん近いもの**の添字の列である。そういう先祖が無ければ有限の列である。つまり、各列は $`\omega`$ の先祖のスタックを持つ。
- (b) 印は、その印を持つ $`\omega`$ の列の潰す先に潰す。規則 1 は、いちばん外の $`\omega`$ の列の印にだけ使う。
- (c) $`C2_x`$ の中では、包まれた $`\omega`$ の列の最後の葉の印を、$`D`$ から見て読む（$`\Omega_{\omega+1} \mapsto \Omega_1`$）。これは段 1 の有限の列になり、そのあと証人に潰れる。
- (d) 同じ読み方を、$`W`$ の最後の低い子にも使う（行 827）。これで、同じパターンになる組が消えた。

## 9. Wilken の $`R_2`$ と未決の組

`por/tr3.py` は、トリオの行列 $`M`$ を、純粋な構造 $`R_2 = (\mathrm{Ord}; \le, \le_1, \le_2)`$ の Wilken の記法に訳す（Wilken, "Pure Σ₂-elementarity beyond the core", APAL 172, 2021, [doi:10.1016/j.apal.2021.103001](https://doi.org/10.1016/j.apal.2021.103001)）。訳した値を $`\mathcal{T}_3(M)`$ と書く。
- $`\upsilon_0 = 0`$、$`\upsilon_{i+1} = (\upsilon_i)^\infty`$、極限では上限をとる（Wilken の Def 1.5）。$`[\upsilon_i, \upsilon_{i+1})`$ の順序数は $`\tau = \upsilon_i`$ に相対的な $`\vartheta`$ の項で書け（Def 1.3）、その比較は Lemma 2.26 による。
- 読み方は $`\upsilon_{1+\xi} = \psi_0(\Omega_\omega + \psi_1(\Omega_\omega) \cdot \xi)`$ である。不動点 $`h = \upsilon_h`$ には有限の添字が無い。$`\mathcal{T}_3`$ はこれを行列で名付け、2 つの名前は行列の順序で比べる。
- 2 つの検証用の集合の上で、$`\mathcal{T}_3`$ は辞書式順序に沿って狭義に増える。
- **$`R_2`$ は $`R_2^+`$ ではない。** Wilken の $`\le_1`$、$`\le_2`$ は純粋な構造のものである。$`\Phi_3`$ が目指すのは、言語に $`+`$ を持つ $`R_2^+`$ である。2 つは違う。Wilken の Thm 1.8 では $`\upsilon_2 \lt_2 \upsilon_\omega`$ だが、シート（行 534）にも $`\Phi_{3i}`$ にも $`\upsilon_2`$ の $`\le_2`$ の後者は無い。だから Wilken の $`R_2`$ は $`\Phi_3`$ の判定には使えない。合うのは、$`R_2^+`$ の $`\upsilon_\iota`$ を $`R_2`$ の $`\varepsilon_0 \cdot \iota`$ と読むことである。これは Wilken §3 が $`R_1`$ と $`R_1^+`$ の間に与える対応と同じ形である。添字が有限の $`\upsilon`$ の点の上で、11758 の関係が一致し、食い違いは 0 である。

**310 組を $`\mathcal{T}_3`$ で見る。** どの組も $`A \lt_{\mathrm{lex}} B`$ で、どちらも根の項 1 つで $`z = 1`$ の列を持つ。

| $`\mathcal{T}_3(A) \lt \mathcal{T}_3(B)`$ の決まり方 | 組の数 |

| $`\upsilon`$ の添字が違う | 2 |

- 310 組すべてで $`\mathcal{T}_3(A) \lt \mathcal{T}_3(B)`$ である。上の 3 行の 58 組は Wilken の比較で決まる。残りの 252 組は $`\upsilon`$ の最小の不動点より上にあり、そこでは $`\mathcal{T}_3`$ は行列の順序に何も足さない。
- これは行列の順序数 $`o(A) \lt o(B)`$ の比較である。$`\iota(\Phi_{3i}(A)) \lt \iota(\Phi_{3i}(B))`$ が出るのは $`\iota \circ \Phi_{3i} = o`$ のときだけで、それこそが確かめたい主張である。だから $`\mathcal{T}_3`$ だけではどの組も決まらない。
