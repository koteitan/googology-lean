# Trans/BMS/ExBuchholz

BMS ↔ extended Buchholz ψ. The rank of a matrix as a ψ value: one row, ε-numbers, ζ, and pair sequences (rank = 1 + val, `PSS/`); and the rules that map ψ to trio sequences (`Trio/`).

- [PSS/](PSS/README.md): two rows (pair sequences).
- `Trio/`: three rows (trio sequences). Each fix of the rules has a note `TRIO-*.md` there.
