# Fix L: 1 列では名指せない最後の葉

[`TrioRulesAll.lean`](TrioRulesAll.lean)（[koteitan/trio](https://github.com/koteitan/trio)
の規則 1–10 に Fix A–E と N を入れたもの）の上に載せるパッチ。規則は
[`TrioFixLastLeaf.lean`](TrioFixLastLeaf.lean)、検査は
[`TrioFixLastLeafSheet.lean`](TrioFixLastLeafSheet.lean) にある。検査はすべて `#guard`
で、較正であって定理ではない。

`M(α)` は `ψ_0(Ω_α)` の行列。`M[n]` は悪い部分を `n + 1` 個写す BM4 展開（yaBMS の `[n]`、
Lean の `expandRL 3 n`）。`r` はレジーム、`r = Ω_w`, `w = Ω_{w'}`, … のとき
`tops(r) = [r, w, w', …]`（[TRIO-NONLAST-LEAF-ja.md](TRIO-NONLAST-LEAF-ja.md)）。

## 誤り

[TRIO-NONLAST-LEAF-ja.md](TRIO-NONLAST-LEAF-ja.md) の未解決 3。塔のレジームの下では、
ユニットの最後の葉は自分のレベル `Ω_p` を 1 列とアップグレードで名指す。次の `p` では、
葉が最後の列でもこれが誤る（`TrioRulesAll.lean`）:

| α | `TrioRulesAll.lean` |
|---|---|
| `Ω_{Ω_Ω}+Ω_3` | `Ω_{Ω_Ω}+Ω_{Ω+1}` と同じ行列 |
| `Ω_{Ω_Ω}+Ω_{Ω·2}` | `Ω_{Ω_Ω}+Ω_2` と同じ行列 |
| `Ω_{Ω_Ω}+Ω_{Ω+2}`, `Ω_{Ω_Ω}+Ω_{Ω_2+1}`, `Ω_{Ω_Ω}+Ω_{Ω_3}` | 葉 `(10,4,0)`: 標準形でない |
| `Ω_Ω+Ω_3` | 葉 `(8,3,0)`: 標準形でない |

## 変更

`MstepFix Mf α = MstepAll Mf α`。ただし `lastLeafFix Mf α = some cs` のときは `cs`。
`lastLeafFix` が働くのは次がすべて成り立つときだけ:

* `α` が `MstepAll` の和の枝に入る（可算でない、`ψ_{Ω_u}(X)` でない、`Ω_r` でない）;
* `r` が `1` の上の塔（`Ω`, `Ω_Ω`, `Ω_{Ω_Ω}`, …）;
* `α` の最後の項が `Ω_p·c`、または `β` が `Ω_p·k` で終わる `ω^β·c` で、その `Ω_p` が最後の
  葉の名指すレベル;
* `p ∉ tops(r)`。

`rb(q)` は `α` のその最後の `Ω_p` を `Ω_q` に替えたもの、`b` は `p` の `Ω` 鎖の底
（`p = Ω_{Ω_{…b}}`）、`p[b := b']` は底を替えた鎖。`L(B)` は `B[s₀:]` の持ち上げコピー
（Fix N の `blift` で、最後の葉も持ち上げる）。`s₀` は `B` の最後の列の行 1 の親で、
`B[s₀:f]` の持ち上げコピーか保持コピーが前にある間はその始まりへ動かす（`copyRoot`）。
4 つの場合:

| 場合 | 条件 | `M(α)` | 直すもの |
|---|---|---|---|
| L | `b = c + m`、`c = 0, m ≥ 3` か `c = Ω_w, m ≥ 2` | `B ++ L(B)`、`B = M(rb(p[b := c+(m−1)]))` | `Ω_3`, `Ω_4`, `Ω_{Ω+2}`, `Ω_{Ω_3}`, `Ω_{Ω_2+2}` |
| K | `p = Ω_w + 1`、`Ω_w ∉ tops(r)`、`M(chainBase Ω_w)` に接尾辞がない | `B`、その保持コピー（Fix N 2）、最後の根 `(x, y)` の上に `(x+1,y,0)(x+2,y+1,1)(x+3,y+1,1)(x+4,N(r)+1,0)`。`B = M(rb(Ω_w))` | `Ω_{Ω_2+1}` |
| K' | `p = Ω_w + ω^k` | K のあと `M(p)` の印（`appendSuffix`） | `Ω_{Ω_2+ω}` |
| D | `b = Ω_w·2`、`Ω_w ∈ tops(r)` | `B` の最後の葉を `N(w)` にしたもの、`B = M(rb(p[b := Ω_{w+1}]))` | `Ω_{Ω·2}` |

## なぜこの行列か

* **L は BMS 自身のもの。** 極限 `λ = γ + Ω_{c+ω}` について、Fix L の行列で
  `M(λ)[n] = M(γ + Ω_{c+n+1})`（`n = 0…3` か `0…2`）が 16 の文脈で成り立つ:
  `c = 1, Ω, Ω_Ω`、鎖（`Ω_{Ω_ω}`, `Ω_{Ω_{Ω_ω}}`, `Ω_{Ω_{Ω+ω}}`）、積（`Ω_{Ω_Ω}·Ω_ω`,
  `Ω_Ω·Ω_ω`, `Ω_{Ω_Ω}·Ω_{Ω_ω}`）、`Ω_{Ω_Ω}·2` のあと、Fix N のコピーのあと
  （`Ω_{Ω_Ω}+Ω_{Ω_2}+Ω_ω`。ここで `copyRoot` が要る）、`Ω_{Ω_Ω}+Ω_{Ω+1}` のあと、
  `Ω_{Ω_{Ω_Ω}}` の下。
* **K と K' は一緒に確かめられる。** 5 つの文脈で `n = 0, 1, 2` について
  `M(γ+Ω_{Ω_2+ω})[n] = M(γ+Ω_{Ω_2+n+1})`: `[0]` が K、`[1]`, `[2]` が K の上の L。
  `appendSuffix` の書く印 `(5,4,1)` は、K のあとの 1 列 `(x, y, 1)` でこの性質をもつ
  唯一のもの（Lean の外での探索）。葉 `N(r)+1` にすると `M(γ+Ω_{Ω_2+1})[1]` が
  `M(γ+Ω_{Ω+1})[1]` と同じ形になる: 上限 `Ω_2` の次は、頂点 `Ω` の次と同じにふるまう。
* **D は裏付けであって導出ではない。** `M(Ω_{Ω_Ω}+Ω_{Ω·2})` は `M(Ω_{Ω_Ω}+Ω_{Ω+1})` の
  あとに `(4,3,1)(5,3,1)(6,1,0)` を置いたもの。シートの行 4502 が `Ω_{Ω·2}` のために
  `M(Ω_{Ω+1})` のあとに置く尾と同じ。その `[0]` は `M(Ω_{Ω_Ω}+Ω_{Ω+ω²})` で、`[n]` は
  `(6,0,0)` の列（可算の `ψ_0`）に続く: `M(Ω·2)[n]` と同じ形で、`Ω + (可算)` の上限。
  記法の `ω` 極限でこれに展開されるものはない。

## 検査

| 検査 | `TrioRulesAll.lean` | Fix L |
|---|---|---|
| `TrioRulesAllSheet.lean` の全検査（932 個の `#guard`） | 成立 | 成立、数も同じ |
| そこで使うラベル（シート、族、probes、`probesEN`）の変化 | — | 0 |
| 6 つの行列が正しい | 0 / 6（衝突 2、非標準 4） | 6 |
| BMS 展開が規則の行列に落ちる（21 の極限） | — | すべて |
| 最後の葉の族 151 ラベル: 非標準 | 43 | 0 |
| … 不一致（11,325 組）; 衝突 | 555; 49 | 0; 0 |
| … 選ばれた 784 行列との不一致 | 51 | 0 |

族は `γ + Ω_p` と `Ω_{Ω_Ω}·Ω_p`, `Ω_{Ω_{Ω_Ω}}·Ω_p`。
`γ ∈ {Ω_{Ω_Ω}, Ω_{Ω_Ω}·2, Ω_{Ω_Ω}+Ω_{Ω_2}, Ω_{Ω_Ω}+Ω_{Ω+1}, Ω_{Ω_Ω}+Ω_2, Ω_Ω, Ω_Ω·2, Ω_Ω+Ω_2, Ω_{Ω_{Ω_Ω}}, Ω_{Ω_{Ω_Ω}}·2}`、
`p` は直したレベルのまわり。Fix L は 151 のうち 79 を変える。

## 未解決

1. **最後でない葉。** Fix L は最後の葉だけに働く。直したレベルのあとの `+1`
   （`Ω_{Ω_Ω}+Ω_3+1` など 69 ラベル）は元のまま: 不一致 340、衝突 26、非標準 21。
   最後でない葉の Fix N の手順が Fix L の葉を使う必要がある。
2. **鎖の中の K。** `Ω_{Ω_{Ω_Ω}}` のあとの `Ω_{Ω_{Ω_2+1}}` と `Ω_{Ω_{Ω_2+ω}}`: Fix L は
   働かず、`TrioRulesAll.lean` の行列は `Ω_{Ω_{Ω_3}}` より上で、標準形でない。
3. **同じ種類の他のレベル**は手つかず: `Ω_{Ω_Ω}` のあとの `Ω_{ω+1}`, `Ω_{Ω+ω+1}`,
   `Ω_{Ω+ω·2}`, `Ω_{Ω+ω^ω}`, `Ω_{Ω+ψ_0(Ω)}`, `Ω_{Ω·2+1}`, `Ω_{Ω·3}`, `Ω_{Ω²}`,
   `Ω_{Ω_2·2}` は誤った行列か非標準の行列のまま（基本規則はほとんどに `(10,2,0)` か
   `(10,4,0)` を書く）。L, K, K', D は BMS かシートが基準を与えるところでしか確かめていない。
4. **他のレジーム**（`Ω_ω`, `Ω_2`, …）: Fix N と同じく、Fix L は `1` の上の塔でないと働かない。
