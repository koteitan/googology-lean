# 修正 N: 非可算の領域で、後に続きがある葉

[`TrioRules2.lean`](TrioRules2.lean)（[koteitan/trio](https://github.com/koteitan/trio)
の規則 1〜10 に修正 A〜D を入れたもの）は、まだ `Ω_{Ω_Ω}+Ω_{Ω_2}+1` を
`Ω_{Ω_Ω}·2` より上に置く。このノートは原因を調べ、修正（修正 N）を与え、検査の結果を
書く。規則は [`TrioRulesNonLast.lean`](TrioRulesNonLast.lean)、検査は
[`TrioRulesNonLastSheet.lean`](TrioRulesNonLastSheet.lean) にある。検査はすべて
`#guard` で、較正であって定理ではない。

`M(α)` は `ψ_0(Ω_α)` の行列。`M[n]` は悪い部分を `n + 1` 個置く BM4 の展開
（yaBMS の `[n]`、Lean では `expandRL 3 n`）。

## 誤り

非可算の領域では、規則はユニットの葉の名前を行列の最後でしか付けない。最後の葉には
格上げ（修正 B 3。`Ω` 1 つにつき部分ユニット 1 つ）が付く。後に続きがある葉には何も
付かず、次のユニットは、葉の 1 行目の値が同じならどの階でも同じ形で書かれる。
`X = M(Ω_{Ω_Ω}+Ω_{Ω_2})`（末尾は `…(7,4,0)(8,5,1)(9,5,1)(10,3,0)(4,3,1)(5,3,1)(6,2,0)`）
とおくと:

| α | `TrioRules2.lean` |
|---|---|
| `Ω_{Ω_Ω}+Ω_{Ω_2}` | `X` |
| `Ω_{Ω_Ω}·2` | `X ++ (2,2,1)(3,2,1)(4,1,0)` |
| `Ω_{Ω_Ω}+Ω_{Ω_2}+1` | 部分ユニットを除いた `X` `++ (9,5,0)(10,6,0)` |
| `Ω_{Ω_Ω}+Ω_{Ω+1}+1` | 同じ行列 |
| `Ω_{Ω_Ω}·2+1` | 同じ行列 |

`(9,5,0) > (4,3,1)` なので、この共通の行列は `M(Ω_{Ω_Ω}·2)` より上にある。1 段下でも
同じことが起きる。`Ω_Ω+Ω_2+1` と `Ω_Ω·2+1` が同じ行列になる。

## そのまま続く書き方はどの階のものか

BMS が決める。シートの行 4460（`Ω_Ω·ω`）と行 4748（`Ω_{Ω_Ω}·ω`）は規則と一致する。
その展開は

- `M(Ω_Ω·ω)[2] = M(Ω_Ω+Ω_2) ++ (7,4,0)(8,5,1)(9,5,1)(10,2,0)`
- `M(Ω_{Ω_Ω}·ω)[2] = M(Ω_{Ω_Ω}+Ω_{Ω+1}) ++ (9,5,0)(10,6,1)(11,6,1)(12,3,0)`

である。`TrioRules2.lean` はこの 2 つを `Ω_Ω+Ω_2·2` と `Ω_{Ω_Ω}+Ω_{Ω+1}·2` に与える。
すると `M(·ω)[n]` は `Ω_Ω+Ω_2·n` になり、その極限 `Ω_Ω+Ω_2·ω` は `Ω_Ω·2` より下にある。
シートの行の基本列がその行に届かないことになる。したがって、葉の後にそのまま続く書き方
は、その 1 行目の値の**最上の階**（ここでは `Ω_Ω` と `Ω_{Ω_Ω}`）のものであり、
`M(·ω)[n] = M(·n + Ω_2)`、`M(·n + Ω_{Ω+1})` である。ほかの階には別の続け方が要る。

領域 `r = Ω_w` の最上の階を `tops(r) = [r, w, w', …]`（`w = Ω_{w'}` である間）とする。
`r = Ω_Ω` なら `[Ω_Ω, Ω, 1]`。1 行目の値 3 では `Ω_{Ω_Ω}`、2 では `Ω`、1 では `1`。

## もっと深い階について BMS が書くもの

別の続け方がどんな形かも BMS が示す。次の 2 つの印は、シートの行か規則の出力である。

- `M(Ω_{Ω_Ω}+Ω_ω)[1] = M(Ω_{Ω_Ω}+Ω_2) ++ C`（行 4743）
- `M(Ω_{Ω_Ω}+Ω_{Ω_ω})[1] = M(Ω_{Ω_Ω}+Ω_{Ω_2}) ++ C'`

`C` と `C'` は**持ち上げた写し**である。最後の葉の 1 行目の親（0 行目の祖先のうち、
1 行目の値がより小さい最も近いもの）を `s₀` とし、`s₀` から最後までの列を写す。各列は
`x + 1` し、1 行目の祖先をたどって `s₀` に届く列だけ `y + 1` する（BMS の上昇）。最後の
葉も持ち上がるので、`C` は `Ω_3` を、`C'` は `Ω_{Ω_3}` を表す。
`TrioRulesNonLast.lean` の関数 `blift` は、`C`、`C'`、および `M(Ω_Ω+Ω_ω)[1]` の同じ
写しを、そのまま再現する。

## 修正 N

領域 `r` が `1` の上の塔（`r ∈ {Ω, Ω_Ω, Ω_{Ω_Ω}, …}`）であるとする。最後の葉が
`tops(r)` にない階 `p` を表し、`p` の `Ω` の鎖の終わりが印のない階（`1`、`2`、…。`ω`
ではない）であり、その後に別の足し算ユニットか別の桁が続くとき:

1. 葉に今すぐ格上げを付ける。最後の葉のときと同じ（修正 B 3）。
2. 持ち上げた写しを置く。最後の葉は**据え置く**（持ち上げた値より 1 小さくする）。
   `s₀` が前の写しの根なら、前の写しそのものを持ち上げる（`s₀` をその写しの始まりに
   する）。
3. 写しの後では: 階 `p` を上限とする（後で `p` を表す葉は最上とみなす）。`r` を表す葉は
   写し 1 つにつき 1 大きくする。手順 1 が部分ユニットを書かなかったときは、`p` を表す
   葉は写しの最後の値をとる。格上げの最初の部分ユニットと印は、写しの中から取る。
4. 次の足し算ユニットは最後の根から続ける。次の桁も同じ。ただし手順 1 が部分ユニットを
   書いたときは、その部分ユニットの根の下にユニットを置き直し（錨、根、それまでの桁）、
   桁はその根から続ける。

新しい行列:

| α | 修正 N（`X` の後、または共通の前半の後） |
|---|---|
| `Ω_{Ω_Ω}+Ω_{Ω_2}+1` | `X ++ (2,2,0)(3,3,1)(4,3,1)(5,3,0)(3,3,1)(4,3,1)(5,3,0)(3,3,1)(4,3,1)(5,1,0)(4,3,0)(5,4,1)(6,4,1)(7,4,0)(5,4,1)(6,4,1)(7,3,0)(6,4,0)(7,5,1)(8,5,1)(9,4,0)(8,5,0)(9,6,1)(10,6,1)(11,4,0)(5,4,1)(6,4,1)(7,2,0)` `++ (6,4,0)(7,5,0)` |
| `Ω_{Ω_Ω}+Ω_{Ω+1}+1` | `M(Ω_{Ω_Ω}+Ω_{Ω+1}) ++ (4,3,0)(5,4,1)(6,4,1)(7,4,0)(5,4,1)(6,4,1)(7,2,0)(6,4,0)(7,5,1)(8,5,1)(9,4,0)(8,5,0)(9,6,1)(10,6,1)(11,3,0)` `++ (10,6,0)(11,7,0)` |
| `Ω_{Ω_Ω}·2+1` | `M(Ω_{Ω_Ω}+Ω_{Ω+1}) ++ (9,5,0)(10,6,0)`（前と同じ） |
| `Ω_Ω+Ω_2+1` | `M(Ω_Ω+Ω_2) ++ (2,2,0)(3,3,1)(4,3,1)(5,3,0)(3,3,1)(4,3,1)(5,1,0)(4,3,0)(5,4,1)(6,4,1)(7,3,0)(6,4,0)(7,5,1)(8,5,1)(9,2,0)` `++ (8,5,0)(9,6,0)` |

どの場合も、据え置いた写しは持ち上げた写し（`Ω_{Ω_3}`、`Ω_{Ω+2}`、`Ω_3`）より下にある。
よって順序は `Ω_{Ω_2} < Ω_{Ω_2}+1 < Ω_{Ω_2}·2 < Ω_{Ω_Ω}·2 < Ω_{Ω_Ω}·2+1` になる。
[TRIO-SHEET-41-ja.md](TRIO-SHEET-41-ja.md) が残りとして挙げる、`Ω_Ω+Ω_2+1` と行 4457
（`Ω_Ω+Ω_ω`）・行 4458（`Ω_Ω·2`）の順序もこれで決まる。今は両方より下にある。

## 検査

修正 N を入れた規則と `TrioRules2.lean` を比べる。標準形は yaBMS `bms -s` で調べる
（Lean の外）。「食い違い」は、ラベルの順序（`cmpOrd`）と行列の順序が違う組の数である。
ラベルが違うので、同じ行列になる組も数に入る。

| 検査 | `TrioRules2.lean` | 修正 N |
|---|---|---|
| シートの 813 個のラベルと、直した 9 個のラベル | — | 822 個すべてで同じ行列 |
| 選んだ 783 個の行列の食い違い（306,153 組） | 0 | 0 |
| シートのラベルでの標準形 | 3480 と 3552 の印刷ラベルで標準形でない（ほかに 3481、3482。ここはシートの行列も標準形でない） | 同じ |
| `TrioRules2` の報告の近くの順序数 71 個: 標準形でない数 | 15 | 15（同じ 15 個） |
| … 選んだ 783 個の行列との食い違い | 27 | 20 |
| … 71 個の中での食い違い（2,485 組） | 37 | 25 |
| `Ω_{Ω_Ω}` の後の和と積（179 個）: 標準形でない数 | 0 | 0 |
| … 食い違い（15,931 組）、同じ行列の組 | 1,961、220 | 1、1 |
| `Ω_Ω` の後の和と積（133 個）: 標準形でない数 | 0 | 0 |
| … 食い違い（8,778 組）、同じ行列の組 | 912、74 | 0、0 |

71 個の近くの順序数のうち、修正 N が変えるのは、`TrioRules2.lean` が順序を乱していた
5 個だけである: `Ω_{Ω_Ω}+Ω_{Ω+1}+1`、`Ω_{Ω_Ω}+Ω_{Ω_2}+1`、`Ω_{Ω_Ω}+Ω_{Ω_2}·2`、
`Ω_{Ω_Ω}·Ω_{Ω_2}·ω`、`Ω_{Ω_Ω}·Ω_{Ω+1}·ω`。5 個とも前から標準形で、今は順序どおりになった。
選んだ行列との残る 20 個の食い違いはほかの領域（`Ω_{Ω+1}^ω`、`Ω_ω·Ω_2·…`、
`Ω_{ψ_{Ω_{ω+1}}(Ω_{ω+1})·2}`）から来る。71 個の中の 25 組は、同じ領域と
`Ω_{Ω_{ω+1}}+Ω_Ω`、`Ω_{Ω_{ω+1}}+Ω_{ω+1}` から来る。

**展開.** 27 個の `#guard` で、`n = 1, 2`（`Ω_{Ω_Ω}·Ω_{Ω_2}·ω` は `n = 1` だけ）について
`M(γ·ω)[n]` を修正 N の行列と比べる。`γ·ω` は: `Ω_Ω·ω`、`Ω_{Ω_Ω}·ω`、`Ω_{Ω_Ω}^2·ω`、`Ω_{Ω_Ω}+Ω_2·ω`、
`Ω_{Ω_Ω}+Ω_{Ω+1}·ω`、`Ω_{Ω_Ω}+Ω_{Ω_2}·ω`、`Ω_{Ω_Ω}·Ω_2·ω`、`Ω_{Ω_Ω}·Ω_{Ω+1}·ω`、
`Ω_{Ω_Ω}·Ω_{Ω_2}·ω`、`Ω_{Ω_Ω}+Ω_{Ω_2}+Ω_2·ω`、`Ω_{Ω_Ω}+Ω_{Ω+1}+Ω_2·ω`、
`Ω_{Ω_Ω}+Ω_{Ω_2}+Ω_{Ω+1}·ω`、`Ω_Ω+Ω_2·ω`、`Ω_Ω+Ω_2+Ω·ω`。どの展開も、修正 N での
あるラベルの行列になる。最後の `·ω` が `·n` か `·(n+1)` になり、`Ω_{u+1}` を含む項が
後に付くこともある（シートの行の型 `(Ω_{Ω_u}·ω)[1] = Ω_{Ω_u}+Ω_{u+1}`）。たとえば
`M(Ω_{Ω_Ω}+Ω_{Ω_2}·ω)[n] = M(Ω_{Ω_Ω}+Ω_{Ω_2}·(n+1)+Ω_{Ω+1})`（`n = 1, 2`。yaBMS では
`n = 0` も）。

## どこまで確かか

- そのまま続く書き方が最上の階のものであることは、行 4460 と 4748 の展開から決まる。
- 持ち上げた写しは BMS 自身が書くもの（上の印の展開）。
- 手順 4（部分ユニットの後でユニットを置き直す）があるから、`Ω_{Ω_Ω}+Ω_{Ω_2}·ω` の
  展開が `Ω_{Ω_2}·(n+1)+Ω_{Ω+1}` に落ちる。これがないと展開はどのラベルにも落ちない。
- `M(Ω_{Ω_Ω}+Ω_{Ω_2}+1)` そのものは、シートの行の展開としては得られていない。これを
  決めているのは、据え置いた写し（BMS が `Ω_{Ω_3}` に書く写しで、葉を 1 小さくしたもの）、
  上の順序と標準形、そして隣の項の展開である。最も裏付けのある候補であって、導いた
  行列ではない。（修正 N では、yaBMS で `M(γ+ω)[1] = M(γ+1)`、`M(γ+ω)[2] = M(γ+2)`
  になる。`γ = Ω_{Ω_Ω}+Ω_{Ω_2}`、`Ω_Ω+Ω_2`、`Ω_{Ω_Ω}+Ω_{Ω+1}`。これは合っているが、
  行列を決めはしない。`TrioRules2.lean` でも `M(γ+ω)[1] = M(γ+1)` だから。）

## まだ残るもの

1. **ほかの領域.** 修正 N は、領域が `1` の上の塔のときだけ働く。`r = Ω_ω`、`Ω_2`、
   `Ω+1` などでは、元の規則が最後の葉ですでに衝突する（たとえば `Ω_{Ω_2}+Ω_{Ω+1}` と
   `Ω_{Ω_2}+Ω_3`、`Ω_{Ω_ω}+Ω_{ω+1}` と `Ω_{Ω_ω}+Ω_2`）。そこでの最上の階はまだ分かって
   いない。`tops` のまま `r = Ω_ω` に修正 N を当てると、`Ω_{Ω_ω}` の後の 170 個の和で
   食い違いは減る（3,263 → 814、Python での計算）が、衝突が増える（38 → 44 組）ので、
   当てていない。
2. **印のある階**（`Ω_ω`、`Ω_{Ω_ω}`）が最後でないとき: 変えていない。
3. **部分ユニット付きの葉で表せない階**: `Ω_{Ω_Ω}` の後の `Ω_3`、`Ω_{Ω+2}`、`Ω_{Ω·2}`、
   `Ω_{Ω_2+1}`、`Ω_{Ω_3}`、`Ω_Ω` の後の `Ω_3`。最後の葉のときでも規則は誤っている:
   `Ω_{Ω_Ω}+Ω_3` は `Ω_{Ω_Ω}+Ω_{Ω+1}` の行列に、`Ω_{Ω_Ω}+Ω_{Ω·2}` は `Ω_{Ω_Ω}+Ω_2` の
   行列になり、ほかは標準形でない。上の展開から、これらには葉を持ち上げた写しが要る
   （`M(Ω_{Ω_Ω}+Ω_ω)[1]` が `Ω_{Ω_Ω}+Ω_3`）。実装していない。
4. **衝突が 1 つ残る.** `Ω_{Ω_Ω}` の後の和で、`Ω_{Ω_Ω}+Ω_{Ω_2}+Ω_2+Ω_2` と
   `Ω_{Ω_Ω}+Ω_{Ω_2}+Ω_2+Ω` が同じ行列になる（写しを 2 回置いた後、`Ω_2` と `Ω` の葉が
   どちらも値 1 になる）。
5. **修正 E と修正 N は別々.** 修正 E（[`TrioRules3.lean`](TrioRules3.lean)）は規則 9
   （`MpsiLevel`）を変え、修正 N は `placeUnits` と最後の格上げを変える。触る関数が違う
   ので、両方を入れた構成は、`MstepN` の `MpsiLevel2` を `TrioRules3` の `MpsiLevel3` に
   替えればよい。
