# ペア数列から加法的パターン（$`R_1^+`$）への写像 $`\Phi`$

**状態：紙の上で証明済み（§8、[proof/](proof/README-ja.md)）。Lean でも `sorry` なしで形式化した（`Main.lean` の `mainTheorem_mat`）。文献から引用した事実は、点検済みの公理として置いた。数値の証拠もある。**

標準形のペア数列 $`M`$ から、Carlson の加法的パターン（階数 1）$`\Phi(M)`$ を作る写像を定める。
$`\Phi(M)`$ は、行列の木を組み替えるだけで作る。$`\psi`$ の項は書かない。

**定理（紙の上で証明済み、§8）。** 標準形のペア数列 $`M, M'`$ について、次が成り立つ。

```math
M \lt_{\mathrm{lex}} M' \iff \iota(\Phi(M)) \lt \iota(\Phi(M'))
```

ここで $`\iota(P)`$ は、パターン $`P`$ の点の、最小の実現（isominimal な実現）での値である。

これは、次の強い形から出る。強い形も紙の上で証明済みである。

```math
\iota(\Phi(M)) = 1 + \mathrm{val}(\mathrm{pairTerm}(M))
```

`pairTerm` は、`Rank.lean` にある、ペア数列から Buchholz の $`\psi`$ の項への写像である。$`1 +`$ が要るのは、`pairTerm` が $`(0,0)`$ を 0 に送る一方で $`\iota(\Phi((0,0))) = 1`$ だからである。無限の値では $`1 + \alpha = \alpha`$ である。`pairTerm` は $`\psi_0(\Omega_\omega)`$ より下の項への順序同型なので、この形から定理が出る。さらに、$`\Phi`$ の点が核の 0 でない値を全部とることも出る。

## 1. 背景

- ペア数列の順序型は $`\psi_0(\Omega_\omega)`$ である（このライブラリの `Rank.lean`）。
- Carlson の構造 $`R_1^+ = (\mathrm{Ord}; 0, +; \le, \le_1)`$ の核（有限パターンの最小の実現の和集合）も、
  $`\psi_0(\Omega_\omega) = \lvert \Pi^1_1\text{-}\mathrm{CA}_0 \rvert`$ である（Wilken, "Σ₁-Elementarity and Skolem Hull Operators", APAL 145, 2007）。
- なので、ペア数列から $`R_1^+`$ のパターンへの順序同型が期待できる。問題は、それを行列から直接読めるかである。
- $`\Phi`$ は読める形の候補である。ただし、中で使う操作 $`\mathrm{Coll}`$（§3.4）は、Buchholz の $`\psi`$ の潰し方を行列の上に書いたものである。なので、$`\psi`$ の記法は使わないが、$`\psi`$ の仕組みは使っている。

## 2. 行列を木として読む

- 行列は列 $`(x_i, y_i)`$ の列である。
- 列 $`i`$ の**行 0 の親**は、$`x_j \lt x_i`$ となる最大の $`j \lt i`$ である。親の無い列を**根**と呼ぶ。
- 列 $`i`$ の**項**は $`T(i) = (y_i, (T(c_1), \ldots, T(c_k)))`$ である。$`c_1 \lt \cdots \lt c_k`$ は、$`i`$ を親に持つ列（子）である。
- 行列は、根の項の列 $`(T(r_1), \ldots, T(r_m))`$ と 1 対 1 に対応する。$`x`$ は木の深さで決まる。
- 順序は、列の並びの辞書式順序である。
- **和**は、Cantor 標準形の足し算である。$`(a_1, \ldots, a_m) + (b_1, \ldots, b_n)`$ は、$`a`$ の末尾から $`b_1`$ より小さい項を落としてから、$`b`$ を並べたものである。
- $`1 = (0, ())`$ は行列 $`(0,0)`$ である。

**例。** $`(0,0)(1,0)(2,0)(1,0)`$ は、根が 1 つの木である。根の子は $`(1,0)`$（その子が $`(2,0)`$）と $`(1,0)`$ である。子の無い列を $`1 = \omega^0`$、子を持つ列を $`\omega^{(\text{子の和})}`$ と読むと、$`\omega^{\omega + 1}`$ になる。$`y`$ が全部 0 の行列は、原始数列と同じ読み方になる。

## 3. 定義

以下、$`N = (0, (C_1, \ldots, C_k))`$ は根の項である。$`A = (C_1, \ldots, C_k)`$ とおく。

### 3.1 $`\varepsilon`$ 性と anchor

- $`N`$ が **$`\varepsilon`$ 的**であるとは、$`k \ge 1`$ かつ最後の子 $`C_k`$ の $`y`$ が 1 以上であることをいう。
- $`\mathrm{anchor}(N) = (0, (C_1, \ldots, C_{k-1}))`$（$`k \ge 2`$ のとき）。最後の子を除いたものである。

### 3.2 指数 $`\log`$ と $`\lambda`$

$`\varepsilon`$ 的でない根の項 $`u = (0, B)`$ について、$`B^{\mathrm{hi}}`$ を $`y \ge 1`$ の子の列、$`B^{\mathrm{lo}}`$ を $`y = 0`$ の子の列とする（どちらも元の順）。

```math
\log(u) = (0, B^{\mathrm{hi}}) + B^{\mathrm{lo}}_1 + \cdots + B^{\mathrm{lo}}_r
```

$`B^{\mathrm{hi}}`$ が空なら、最初の項を省く。$`N`$ が $`\varepsilon`$ 的でないとき（$`k \ge 1`$）、最後の子 $`C_k`$ を根の項 $`u`$ として読み、次のようにおく。

```math
\lambda(N) = \begin{cases} (u) & (u \text{ が } \varepsilon \text{ 的}) \cr \log(u) & (\text{それ以外}) \end{cases}
```

### 3.3 届く先 $`\mathrm{lh}`$（$`\le_1`$ で届く最大の点）

- $`N = 1`$ のとき：$`\mathrm{lh}(N) = (N)`$。
- $`N`$ が $`\varepsilon`$ 的でないとき：$`\mathrm{lh}(N) = (N) + \lambda(N)`$。
- $`N`$ が $`\varepsilon`$ 的なとき：$`W = C_k`$ とおく。$`W`$ の子のうち $`y \ge 2`$ のものを $`D_1, \ldots, D_p`$、$`y \le 1`$ のものを $`E_1, \ldots, E_q`$ とする（どちらも元の順）。次の手順で $`S`$ を作り、$`\mathrm{lh}(N) = S`$ とする。

```math
\begin{aligned}
S &:= (N, N) \cr
S &:= S \oplus \bigl(0,\ A + \mathrm{Coll}_A(D_1) + \cdots + \mathrm{Coll}_A(D_i)\bigr) && (i = 1, \ldots, p) \cr
S &:= S \oplus \mathrm{Coll}_A(E_j) && (j = 1, \ldots, q)
\end{aligned}
```

畳み込み $`\oplus`$ は、次の式で定める。$`S_1`$ は $`S`$ の最初の項である。

```math
S \oplus Y = \begin{cases} S + (Y) & (Y \le S_1) \cr \mathrm{lh}(Y) & (Y \gt S_1) \end{cases}
```

$`\oplus`$ は、$`\le_1`$ の推移律に当たる。新しい点が今までの届く先の中にあれば、届く先は足し算で伸びる。そうでなければ、その点の届く先へ移る。

### 3.4 潰す操作 $`\mathrm{Coll}_A`$

項 $`s = (y, (B_1, \ldots, B_m))`$ について、次のようにおく。$`\mathrm{Coll}_A(B) = \mathrm{Coll}_A(B_1) + \cdots + \mathrm{Coll}_A(B_m)`$ である。

```math
\mathrm{Coll}_A(s) = \begin{cases}
s & (y = 0) \cr
(0,\ A + \mathrm{Coll}_A(B)) & (y = 1) \cr
(y - 1,\ \mathrm{Coll}_A(B)) & (y \ge 2)
\end{cases}
```

- $`y = 1`$ の列は、$`N`$ そのものに $`\mathrm{Coll}_A(B)`$ を子として足したものになる。例えば、$`N = (0,0)(1,1)(2,2)`$ では、列 $`(1,1)(2,2)`$ が $`(0,0)(1,1)(2,2)(1,1)`$ になる。
- $`y \ge 2`$ の列は、$`y`$ を 1 減らす。
- これは Buchholz の潰し方 $`\Omega_1 \mapsto N`$、$`\Omega_{k+1} \mapsto \Omega_k`$ に当たる。

### 3.5 パターン $`\Phi(M)`$

$`M`$ は標準形の行列で、根の項を $`T_1, \ldots, T_m`$ とし、$`\hat{M} = (T_1, \ldots, T_m)`$ とおく。根が複数ある行列は、根の項の和である。

- 節点の集合 $`V`$ は、$`\{(),\ (1),\ \hat{M}\}`$ を含み、次の操作で閉じた最小の集合である。
  - 途中までの和：$`(a_1, \ldots, a_m) \in V`$ なら $`(a_1, \ldots, a_j) \in V`$。
  - 根の成分：$`(a_1, \ldots, a_m) \in V`$ なら $`(a_i) \in V`$。
  - 項が 1 つの節点 $`(N) \in V`$ について、$`(\mathrm{anchor}(N)) \in V`$ と $`\mathrm{lh}(N) \in V`$。
- 節点の順序は辞書式順序である。足し算は、§2 の和による関係 $`\{(x, y, z) \in V^3 : x + y = z\}`$ である。
- $`\le_1`$ は、次で定める。

```math
x \le_1 z \iff x = z \lor (x \text{ は項が 1 つ} \land x \le z \le \mathrm{lh}(x))
```

- 点は $`\hat{M}`$ である。

## 4. 例

パターンは poral の例と同じ書き方で書く。節点を小さい順に左から並べる。$`0`$ は 0、`a` は 1、`n0, n1, …` は項が 1 つの節点、`x+y` は和、`(x … z)` は $`x \le_1 z`$（$`z`$ は $`x`$ の届く先の端）、`*` は点である。例は `por/phi.py` で計算した。

| 行列 $`M`$ | $`\Phi(M)`$ | 節点 |
|---|---|---|
| $`(0,0)(1,0)(2,0)(1,0)`$ | `0 a (n0 n0+a) *n1` | n0 = $`(0,0)(1,0)(2,0)`$、n1 = $`M`$ |
| $`(0,0)(1,1)`$ | `0 a (*n0 n0+n0)` | n0 = $`M = \varepsilon_0`$ |
| $`(0,0)(1,1)(1,0)`$ | `0 a (n0 n0+n0) *n1` | n0 = $`(0,0)(1,1)`$、n1 = $`M`$ |
| $`(0,0)(1,1)(1,0)(2,0)`$ | `0 a (n0 n0+n0) (*n1 n1+a)` | n1 = $`M`$、届く先は n1 + 1 |
| $`(0,0)(1,1)(1,1)`$ | `0 a (n0 n0+n0) (*n1 n1+n1)` | n0 = $`(0,0)(1,1)`$、n1 = $`M`$ |
| $`(0,0)(1,1)(2,1)(3,0)`$ | `0 a (*n0 n1)` | n1 = $`(0,0)(1,1)(2,1)(3,0)(1,0)`$ |
| $`(0,0)(1,1)(2,2)`$ | `0 a (*n0 (n1 n1+n1))` | n1 = $`(0,0)(1,1)(2,2)(1,1)`$ |
| $`(0,0)(1,1)(2,2)(3,3)(2,2)`$ | `0 a (*n0 (n1 (n2 n2+n2)) n2+n2+n2)` | n1 = $`M(1,1)(2,2)`$、n2 = $`M(1,1)(2,2)(1,1)`$ |

- $`(0,0)(1,1)(1,0)(2,0)`$ は $`\omega^{\varepsilon_0 + \omega}`$ である。届く先 n1 + 1 の「+1」は、指数の最後の項 $`\omega = \omega^1`$ の指数 1 である。$`\varepsilon_0`$ より下で Carlson が示した規則「届く先は、指数の最後の項の指数だけ先」と同じ形である。
- $`(0,0)(1,1)(2,2)`$（Bachmann–Howard 順序数）では、$`\mathrm{Coll}`$ が列 $`(1,1)(2,2)`$ を $`(0,0)(1,1)(2,2)(1,1)`$ に写す。
- $`y = k`$ の列は、$`\le_1`$ の $`k - 1`$ 段の入れ子になる。

## 5. 数値の証拠

比べる相手には、Samuel Alexander の $`R_1^+`$ の計算器 [poral](https://github.com/semitrivial/poral) を使った。poral にはライセンスが無いので、このリポジトリには入れていない。

**手書きの対応表との一致。** 表計算シート "Sheetified Patterns of Resemblance"（作者不明）は、ペア数列と $`R_1^+`$ のパターンを手で対応させている。その 2 行の行 469 行のうち、451 行で $`\Phi(M)`$ が同じ順序数になった（poral で比較）。

- 外れた 18 行は、どれもシートの誤りである。14 行は、シートのパターンが別の行列の $`\Phi`$ に等しかった。4 行は、前の行と同じ順序数の重複だった。
- シートの点は、「最後の直既約元のうち、どの小さい節点からも $`\le_1`$ で届かないもの」と読む。こう読むと一致した。

**順序の一致。** 展開と接頭辞で標準形の行列を作り、辞書式順序と poral の順序を比べた。

| 行列の集め方 | 隣り合う組 | ランダムな組 | 食い違い |
|---|---|---|---|
| $`(0,0)\ldots(3,3)`$ から、8 列以下 | 3,013 | 1,008,223 | 0 |
| $`(0,0)\ldots(4,4)`$ から、9 列以下 | 5,291 | 823,565 | 0 |
| $`(0,0)\ldots(5,5)`$ から、9 列以下 | 5,328 | 823,337 | 0 |
| $`(0,0)\ldots(4,4)`$ から、11 列以下 | 95,515 | 3,880,540 | 0 |
| シートの行 460–467 の辺り、13 列以下 | 35,626 | 936,327 | 0 |
| 合計 | 144,773 | 7,471,992 | 0 |

- **全射性。** 数値の試験では、$`\Phi`$ の像にすき間は見つからなかった。像が核の 0 以外の全体であることは、紙の上で証明済みである（§8）。

## 6. 捨てた版

- **畳み込みの無い $`\mathrm{Coll}`$。** $`\psi(\Omega_3)`$ より下では順序を保つ。深さ 3 で崩れる。最小の反例は次である。

```math
\Phi\bigl((0,0)(1,1)(2,2)(3,3)(2,1)(3,2)(4,3)\bigr) \gt \Phi\bigl((0,0)(1,1)(2,2)(3,3)(2,2)\bigr)
```

- **届く先を飛び越える版。** 順序は保つが、証明できるすき間が残った。
- **畳み込み $`\oplus`$**（採用）。順序を保ち、すき間は見つからなかった。

## 8. 証明（紙の上）

強い形 $`\iota(\Phi(M)) = 1 + \mathrm{val}(\mathrm{pairTerm}(M))`$ を、紙の上で証明した。証明の全体は [proof/README-ja.md](proof/README-ja.md) にある。これから定理の両方の半分が出る：$`\Phi`$ は順序を保ち、$`\Phi`$ の点は核の 0 でない値を全部とる。3 つの部分それぞれを独立した査読者が確かめた。偽の命題は見つからず、見つかった穴と細かい点は直した。Lean でも `sorry` なしで形式化した（[proof/README-ja.md](proof/README-ja.md) の「状態」）。文献から引用した事実はそこで公理として置き、それぞれを論文と照らし合わせた。外からの仮定は、Lean の `Ord.psi` が Buchholz の $`\psi`$ であることの 1 つだけで、像を核と呼ぶところだけに使う。

証明は 3 つの部分からなる。
1. **ペア数列**（[proof/COMB.md](proof/COMB.md)）。行列が標準形であることは、行 0 の木の局所的な条件と同値である（定理 SC。最後の条件は Buchholz の $`G_\nu(a) \lt a`$ のペア数列版）。ここから：$`\mathrm{anchor}`$、$`\log`$、$`\mathrm{lh}`$ は標準形の行列を作り、$`\mathrm{lh}`$ は止まり、$`\varepsilon`$ 的でない $`N`$ では $`o(N) = \omega^{o(\log N)}`$ である。
2. **Wilken の $`\vartheta`$ への翻訳**（[proof/TR.md](proof/TR.md)）。行列から $`\vartheta`$ の項への具体的な写像 $`\mathcal{T}`$ を、$`\psi`$ を通さずに木の上で定め、$`\mathrm{val} \circ \mathcal{T} = o`$ を示した。Buchholz の $`\psi`$ と $`\vartheta`$ の間の翻訳は、これまで知られていなかった（Weiermann と Wilken は今後の課題としている）。
3. **主な鎖**（[proof/PROOF.md](proof/PROOF.md)）。畳み込み $`\oplus`$ は Wilken の $`\le_1`$ の届く先の計算なので、$`o(\mathrm{lh}(N))`$ は $`o(N)`$ の $`\le_1`$ の最大の届く先である。節点の集合 $`V`$ は有限で、その値は Wilken の bar 操作で閉じている。だから Carlson と Wilken の標準形により、$`\Phi(M)`$ の最小の実現は点を $`o(M)`$ に置く。

**定義についての注意。** $`\log`$ の和は、小さい項を捨てる §2 の和でなければならない。例えば $`M = (0,0)(1,1)(1,1)(1,0)(2,1)(2,1)(2,0)(3,0)`$ では、項 $`\varepsilon_1`$ が捨てられる。anchor は、一般には Wilken の bar 操作と違う。$`\varepsilon_{\varepsilon_0} = (0,0)(1,1)(2,0)(3,1)`$ には anchor が無く、bar の値は 1 である。
