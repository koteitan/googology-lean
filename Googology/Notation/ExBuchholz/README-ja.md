# ExBuchholz

拡張ブーフホルツ psi。Maksudov による Buchholz の崩壊関数の拡張で、`ψ` の添字が
`ω` 以下の数ではなく、この系自身が名前を付けられる任意の順序数になる。

```
C_v^0(a)     = {b | b < Ω_v}
C_v^(n+1)(a) = {b + c, ψ_u(e) | u, b, c, e ∈ C_v^n(a) ∧ e < a}
C_v(a)       = ⋃_{n<ω} C_v^n(a)
ψ_v(a)       = min {g | g ∉ C_v(a)}
```

`Ω_0 = 1`、`v > 0` では `Ω_v` は濃度 `ℵ_v` の最小の順序数。可算な極限は `p0(Λ)`
で、`Λ` は最初の omega 不動点である。

## 項の型

再帰引数 3 つの単一の帰納型。相互帰納も入れ子帰納も使わないので、以下の再帰は
全部構造帰納である。

```lean
inductive Term where
  | nil  : Term                       -- 0
  | cons : Term → Term → Term → Term  -- ψ_a(b) + t
```

項は主項 `ψ_a(b)` の有限和である。添字が項であることが、この拡張の中身そのものである。

## 順序

`cmp` は主項のリストの辞書式順序で、真の前半が小さい方になる。主項どうしは
`(添字, 引数)` の辞書式で比べる。Buchholz の `(<1)`–`(<3)` で、添字を数から項に
一般化したものである。

`Order.lean` はこれが狭義の線形順序であることを証明する。この 3 つは
`Googology.Core.Morphism` の `OrdHom.injective` が要求するものそのものなので、
この系への翻訳は順序を保つだけで単射になる。

## 標準形

`ψ_a(b)` が標準形であるとは、`ψ_a` がまだ届く `b` の部分項が全部 `b` より真に
小さいことをいう。和が標準形であるとは、主項が広義単調減少であることをいう。
集める関数 `G` は Buchholz のものだが、内側の `ψ_c(d)` の添字 `c` 自身が項なので、
`d` と一緒に `c` も集める点が違う。

`isOT` は `Bool` を返す決定手続きなので、小さい場合は `#guard` が計算で確かめる。
`Std.lean` に入れたものには、`ε₀ = ψ_0(Ω)` が標準形であること、`1 + ω` は主項が
増えるので標準形でないこと、`ψ_0(ψ_0(Ω))` は `Ω` が引数より下にないので標準形で
ないことが含まれる。

## なぜ標準形が要るか

`WF.lean` は、**全部の項の上の順序が整礎でない**ことを証明している。

```
Ω > ψ_0(Ω) > ψ_0(ψ_0(Ω)) > ψ_0(ψ_0(ψ_0(Ω))) > ⋯
```

`cmp` が添字を先に比べ、`0 < ψ_0(0)` なので、これが無限に下がる。この列は 3 項目で
`OT` の外に出る。だから `not_wellFounded_lt` は欠陥ではなく、標準形の条件が存在する
理由そのものである。

## 証明済みの `p` の値

`Ord/Opow.lean` が、引数が小さくて閉じた形を持つ範囲で collapse を計算する。表の
中身は全部定理で、仮定は書いてあるものだけである。

| | 値 | 場所 |
|---|---|---|
| `p_v(0)` | `W_v`。よって `p0(0) = 1`、`p1(0) = W` | `psi_zero_arg` |
| `p0(a)`、任意の `a` | `<= w^a` | `psi_zero_le_opow` |
| `p0(a)`、`a < e0` | `w^a` | `psi_zero_eq_opow` |
| `p0(W)` | `e0` | `psi_Omega_one` |
| `p0(W + a)`、任意の `a` | `<= e0·w^a` | `psi_Omega_add_le` |
| `p0(W + a)`、`a < e1` | `e0·w^a`。よって `p0(W + 1) = e0·w` | `psi_Omega_add_eq` |
| `p0(W·2)` | `e1` | `psi_Omega_two` |
| `p0(e0)` | また `e0`。引数は値から決まらない | `psi_eps0` |
| `p0(W·(n+1))`、任意の `n` | `e_n` | `psi_OmegaMul` |
| `p0(W·(n+1) + a)`、`a < e_{n+1}` | `e_n·w^a` | `psi_OmegaMul_add` |
| `p1(1)` | `W·w` | `psi_one_one` |
| `p0(W·w)` | `e_w` | `psi_Omega_omega` |
| `p_v(a)`、任意の `v` と `a` | `<= W_v·w^a` | `psi_le_Omega_mul_opow` |
| `p_v(a)`、`a < fpOmega v`、`v < W_v` | `W_v·w^a` | `psi_eq_Omega_mul_opow` |
| `p1(a)`、`a < fpOmega 1` | `W·w^a` | `psi_one_eq` |
| `p_v(W_{v+1})`、`v < W_v` | `fpOmega v`。`x ↦ W_v·w^x` の最小不動点 | `psi_Omega_succ` |

最後の 4 行が `Ord/Level.lean` である。`Ord/Opow.lean` の最初の節を、添字を自由に
したものである。`p0(a) <= w^a` の論法は `0` について何も使っていない。添字 `v` でも
同じ証明が `p_v(a) <= W_v·w^a` を与える。`W_0 = 1` なので、`v = 0` では元の主張に
なる。等号の方は `v` 自身が `C_v(a)` に入っている必要があり、それには `v < W_v` で
足りる。これは自明な条件ではない。aleph 関数の不動点では `p_v(1) = W_v` であって
`W_v·w` ではない。

`e0` は `nfp (w ^ ·) 0`、`e1` は `nfp (e0 * w ^ ·) 0` で、それぞれその関数の最小
不動点である。`Ord/Eps.lean` は同じ二つを有限の全段で一度に持つ。`epsN n` が
`e_n` で、一段ずつ上に積むタワーである。証明は `n` についての強い帰納法一本で、
梯子を一段ずつ登るのではない。それが通る理由が `decomp` である。`C_0(W·(n+1))` の
元でその上界より下のものは `W·k + c` の形で、`k <= n`、`c < e_n` である。最後の二つを名指す項が `Trans.BMS.te1` と `Trans.BMS.tew` で、
`Trans.BMS.OT_psi_Omega_add` によって標準形である。

### 訂正の中身

`G` は当初、内側の `ψ_c(d)` について引数 `d` と一緒に添字 `c` も集めており、
`isOT` が出典より狭義に強くなっていた。出典は `d` だけを集め、`c` には再帰で
しか届かない。`G` をそれに合わせた。

訂正後、このディレクトリの定理は**全部そのまま通った**。証明が余分な条件に
寄りかかっていなかった、ということである。

### まだ開いていること

出典は、`o` の `OT` への制限が `C_0(Λ)` への順序**同型**だと述べている。単調で
単射という半分はここの定理である（`val_lt_val`、`val_inj_of_OT`）。全射性は
**`e1` 未満では**証明した。`e0` 未満は `Trans.BMS.exists_OT_of_lt_eps0` が Cantor
標準形で、その上は `Trans.BMS.exists_OT_of_lt_eps1` が先頭項 `p0(W + B)` で組む。
`e1` 以上は証明していない。

## 整礎性：どう閉じたか

`Sum.lean` が次を証明した。

```lean
theorem wellFounded_OTLt (HP : ∀ a b, OT (ψ_a(b)) → Acc OTLt (ψ_a(b))) :
    WellFounded OTLt
```

したがって問題は**主項についての仮定 1 つ**に落ちた。和の側に内容はもう無い。

その半分の筋道。標準形は主項が広義単調減少である（`OT_tail_head_le`）ので、頭が
`p` 以下の標準形は「`p` の連続する塊」＋「頭が `p` より真に小さい項」の形になる。
`lead_lex` は、比較がこの表示を辞書式に読むことを言う。塊が長い方が大きく、塊が
同じ長さのときだけ残りが効く。だから帰納は `Nat` の塊の長さで回り、長さを固定した
中では塊のあとの部分の可到達性で回る。`OT` の外の項は自動的に可到達である。
`OTLt y t` が `OT t` を要求するからである。

`acc_of_headLe` は全体仮定をまったく必要としない。境界の項の可到達性そのものが
帰納の軸になっている。

そこで残ったのが `HP` 自身である。

```
∀ a b, OT (ψ_a(b)) → Acc OTLt (ψ_a(b))
```

これが崩壊の議論で、**証明済み**である。取った道は順序数の側である。`Ord.lean` が
Maksudov の条項から順序数の上の `ψ` を定義し、`Eval.lean` が項をそこへ評価し、
`Mono.lean` がその評価が `OT` の上で狭義単調であること（`val_lt_val`）を示す。
そこから `OrdHom.wf` で整礎性を引き戻したものが `OTLt_wf` である。

`Ord.lean` には濃度評価が入った。閉包を有限段の合併として表し、各段が濃度
`max #(Iio Ω_v) ℵ₀` 以下であることを濃度の計算で示し、その最大値がどの `v` でも
`ℵ_v` であることを示した——`Ω_0 = 1` の `v = 0` でも閉包は可算である。
`ℵ_v < ℵ_{v+1}` だから、閉包は `Ω_{v+1}` 未満の順序数を覆いきれない。したがって
`ψ_v(a) < Ω_{v+1}` である。

`Eval.lean` が `Term.val` を定義し、`Mono.lean` が `OT` 上での単調性を示す。
すぐに出なかった理由は記録しておく価値がある。`ψ_v` の引数についての弱い単調性では
足りない。`ψ_v(a) = ψ_v(a+1)` は実際に起きる——`a` が `C_v(a)` の中に届かないとき
ちょうどそうなる。狭義にするのが標準形の条件の役目である。4 段階は `Eval.lean` の
冒頭に書いてある。

構文的な道（Buchholz の集合 `W_u` と Bachmann 性質）を整礎性のために取らなかった
のは、当時は拡張版の基本列を出典と突き合わせられていなかったからである。その後
突き合わせは済み、Bachmann 性もここでは定理になったが、それは整礎性のためではなく
補題 3.3 と展開系の停止性のためである。

### 最後の補題への道筋

Buchholz は補題 3.3 を `b ⊲_z a` という関係を経由して証明する。`b` が `a` より
下で、`G` が `b` に見るものが、その間のどの `c` に見るものと `z` とで抑えられる、
という関係である。

| | 主張 | 状態 |
|---|---|---|
| 3.4 | `b ⊲_z a`、`G_u a < a`、`G_u z < b` ⟹ `G_u b < b` | **済** |
| 3.5 | `b₀ ⊲_z b` ⟹ `a + b₀ ⊲_z a + b`、`ψ_u(b₀) ⊲_z ψ_u(b)`、`ψ_{b₀}(0) ⊲_z ψ_b(0)` | **済** |
| 3.2(b) | 項で添字づけられた定義域で `z₁ < z₂` ⟹ `a[z₁] < a[z₂]` | **済**（`fs_mono`） |
| 3.6 | `z ∈ dom a` ⟹ `a[z] ⊲_z a` | **済** |
| 3.3 | `a, z ∈ OT`、`z ∈ dom a` ⟹ `a[z] ∈ OT` | **済** |
| Bachmann | 場合 4 の配置で `G_A(B) < B[ψ_{Z[0]}(0)]` | **済** |

仕事をするのは 3.4 である。「`z` に相対して抑えられる」を、標準形の条件そのものに
変える。`Closure.lean` には 3.4 と、3.5 の 3 つの形と、3.6（`Trian_fs`）がある。
3.5 の各形は「2 つの項の狭義の間にある項の形」を決める分解補題に乗っている。

`Trian_fs` が 3.6 である。仮定は 3.3（ここでは `OTFS`）だけである。証明は
`size` についての帰納法で、`fs` の枝ごとに場合を分ける。7 つの枝のうち 6 つは
3.5 と、小さな補題 `Trian_nil`、`Trian_self`、`Trian.of_nil`、
`Trian.repeatPrin` で閉じる。残る 1 つが Buchholz の場合 4 で、
`dom X₂ = ψ_Z(0)` が `ψ_{X₁}(X₂)` より下になく、指標を `Z` から組み直す枝で
ある。数字 `n` で展開すると、次の塔を回ることになる。

```
W₀ = ψ_{Z[0]}(0)        W_{i+1} = ψ_{Z[0]}(X₂[W_i])
(ψ_{X₁}(X₂))[n̲] = ψ_{X₁}(X₂[W_n])
```

この塔は `FS.lean` に `tower` として定義してある。枝との一致が `fs_numeral`、
登ることが `tower_lt` と `tower_val_lt`、各段が `X₂` の指標として使えることが
`tower_lt_dom` である。登るところに 3.2(b)、すなわち同じファイルの `fs_mono`
が要る。

`Trian_case4` は、塔についての評価から場合 4 を出す。その評価を
`tower_G_le` が `Z[0]` についての評価に、`sub_G_le` がさらに `Z` 自身について
の評価に落とし、`subBound_of_OTFS` がそれを 3.3 から出す。

```
X[ψ_{Z[0]}(0)] ≤ c ≤ X  ⟹  G_u(Z) ≼ G_u(c) ∪ {0}     （Z = subOf (dom X)）
```

最後の段は `X` についての帰納法で、`dom` の枝ごとに場合を分ける。3.3 が要るの
はそのうち 1 つだけで、`dom X = X = ψ_A(0)` かつ `A` が後続の枝である。ここでは
`u` が大きいときに `G_u(A) = G_u(A[0]) ++ G_u(1)` を空リストで抑えることに
なり、`G_eq_nil_of_le` がそれを出すのは `A[0]` が標準形のときだけである。

形を外してはいけない箇所が 2 つあり、それぞれの項を
`test/ExBuchholzCheck.lean` に置いてある。1 つは、評価が `c` に相対でなければ
ならないこと。Buchholz 自身の不変量は絶対形 `G_u(W_i) < X₂[W_i]` で、彼の体系
では添字が数なので `G` が添字の中に入らず成り立つが、添字が項になると偽になる。
もう 1 つは、指標が `ψ_{Z[0]}(0)` でなければならず、`dom X` より下の任意の `W`
では駄目なことである。

つまり 3.6 は 3.3 だけに乗っている。

3.3 自体は `OTFS_aux` で、`size` についての帰納法で 3.6 を一緒に回す。`fs` の
各枝は `OT_cons_fs`、`OT_psi_nil`、`OT_psi_fs`（3.3 が要る形にした 3.4）、
`OT_repeatPrin` で片付く。指標の中に `G` が崩壊の水準で何も見ないことは
`G_eq_nil_of_lt_psi` と `G_numeral_eq_nil` が与える。残る枝は 1 つ、Buchholz の
場合 4 で、指標が塔の段になるところである。この枝が要求するのは彼の第二の塔
不変量である。場合 4 の配置にある `ψ_A(B)` について

```
OT W_i   かつ   ∀ x ∈ G_A(W_i), x < B[W_i]
```

が崩壊の水準で成り立つこと。水準は効いていて、水準 `0` では同じ主張は偽に
なる。それを示す項は `test/ExBuchholzCheck.lean` にある。

`towerOT_of_Bachmann` が、この不変量を段についての帰納法で、`B` だけについて
の 1 つの主張から出す。それが `Bachmann` である。

```
∀ x ∈ G_A(B), x < B[ψ_{Z[0]}(0)]
```

`B` の基本列が、塔の最初の指標のところで、崩壊の水準に `G` が `B` に見るもの
を全部追い越す、という主張である。これが Bachmann 性であり、下で証明する。

`System.lean` がそこから先を繋いでいる。`exbOT` は可算標準形に制限した展開系で、
`exbOT_wf` と `exbOT_terminates` は `Bachmann` から出る。それが定理なので、
無条件に成り立つ。

`Bachmann` 自体への道筋は `B` についての帰納法で、`dom` の枝ごとに場合を分ける。
枝によって要るものが違う。`P(V)` を `ψ_V(0)` と書くと次のようになる。

| `dom B` の枝 | その場合に要るもの |
|---|---|
| `B = p + t` | 頭はサイズの議論、尾は `t` での同じ主張。ただし `p` を前に置いたまま |
| `B = ψ_a(0)`、`dom a = 1` | `a` が後続なので `le_pred_of_lt` とサイズの議論 |
| `B = ψ_a(0)`、`dom a ∉ {0,1}` | `a` での同じ主張。ただし `P` の形で。仮定が `G_u(a) < P(a)`、結論が `G_u(a) < P(a[W])` |
| `B = ψ_a(b)`、`dom b < B` | `b` での同じ主張と、`G` が自分の要素について閉じていること |

つまり帰納法は、前置きを付けた 2 つの形、素の形と `P` の形を一緒に回す必要が
ある。素の形の和の枝が `bach_sum` で、これは証明済みである。頭は
`lt_of_size_lt_addT` によるサイズの議論で片付き、尾は頭を前置きに足した上で
`t` での同じ主張に落ちる。

Bachmann 性は証明済みである。結局、文脈は要らなかった。効いているのは次の
3 つである。

* `size_fs_W0` — 塔の最初の指標での基本列はちょうど 1 節点だけ減る。
  `size (V[W₀]) + 1 = size V`。
* `G_size_succ_lt` — 項で添字づけられた定義域では、`G` は 2 節点以上小さいもの
  しか見ない。`size x + 1 < size V`。
* `no_small_between` — それだけ小さい項は `V[W₀]` と `V` の狭義の間には無い。

この 3 つがあれば、`bach_pre` は `x` と `p + V[W₀]` の三分法で終わる。下なら
そのまま、等しいならサイズで矛盾、上なら `addT_between` が
`V[W₀] < y < V` かつ `size y + 1 < size V` の `y` を出し、`no_small_between`
がそれを潰す。`bachmann` は `bach_pre` を前置き無しで使ったもので、その仮定は
`OT (ψ_A(B))` に対する `OT_G_lt` である。

したがって 3.3、3.6、`SubBound`、場合 4 の塔不変量、そして `System.lean` の
展開系の停止性は、どれも無条件に成り立つ。

前置きは外せない。`V = ψ_Ω(0) + ψ_1(ψ_Ω(0))` は標準形で定義域も項で添字づけ
られるが、`G_1` は尾の中に `ψ_Ω(0)`、つまり `V` 自身の頭を見る。だから「頭より
下」も「尾より下」も成り立たないのに、結論は成り立つ。この項も
`test/ExBuchholzCheck.lean` に置いてあり、3 つの形を全部確認してある。

残っているものは無い。鎖は閉じた。

## 名前について

`EBuchholz` でも `EBP` でもなく `ExBuchholz` とする。mathlib は「拡張した X」を
`E` の接頭辞で綴る——`ENat`、`EReal`、`ENNReal`、`EMetricSpace`——が、その読み方は
人名の前では壊れる。`EBuchholz` はイニシャル「E. Buchholz」と見分けがつかない。
`Ex` なら「拡張」以外には読めない。
