# InaccPsi: 最初の ω 個の弱到達不能基数の上の Buchholz の ψ

このディレクトリは、ω 個の弱到達不能基数 `I_0 < I_1 < ⋯` とその上限 `I_ω` の上の
順序数崩壊関数を定義する。その表記系も定義する。

- **土台。** 弱到達不能基数 1 つ `I` の上の崩壊関数は、W. Buchholz,
  *A simplified version of local predicativity*
  (in P. Aczel, H. Simmons, S. S. Wainer (eds.), *Proof Theory*, Cambridge University
  Press 1992, 115–147) の定義 4.2 である。W. Pohlers, *Subsystems of set theory and second order number
  theory* (Handbook of Proof Theory, Elsevier 1998, Chapter IV) の §3.4.4 も、
  同じ定義を載せている。そこには事実 (155)–(179) と項の体系の概略もある。
- **拡張。** `ω` 個の弱到達不能基数への拡張は、ここで新しく作ったものである（koteitan
  と Claude）。G. Wilken, *A glimpse of Σ₃-elementarity* (2020) の p. 421 は、
  「最初の ω 個の弱到達不能基数から得られる Skolem 包の表記系」が `R₂⁺` の核を覆う、と
  主張している。ただし定義は書いていない。ここの体系は、その言い方を正確にする
  1 つの方法である。これが Wilken の考えていた体系と同じだという根拠は無い。

## 1. 仮定と記法

- `Ω_0 = 0` とする。`ξ ≥ 1` では `Ω_ξ = ω_ξ`（`ℵ_ξ` に当たる順序数）とする。よって `ξ ↦ Ω_ξ` は
  `{0}` と非可算基数を順に並べる。これは狭義単調増加で、連続である。
- `φ(ξ, η)` は 2 変数の Veblen 関数で、`φ(0, η) = ω^η` である。`1 = φ(0, 0)` である。
- `SC` は強臨界順序数のクラスである。つまり `γ > 0` で、全ての `ξ, η < γ` について
  `φ(ξ, η) < γ` となるものである。非可算基数はどれも `SC` に入る。
- **仮定。** `I : ℕ → Ord` は狭義単調増加である。どの `I_n` も非可算正則基数で、
  `Ω_{I_n} = I_n` を満たす（弱到達不能基数である）。
  `I_ω = sup_n I_n` とおく。このとき `Ω_{I_ω} = I_ω` も成り立つ。`I_n` が
  最初の `ω` 個の弱到達不能基数であることは仮定**しない**。以下ではそれを使わないからである。
- `R = {I_n | n < ω} ∪ {Ω_{s+1} | s ∈ Ord}` とおく。`R` の元はどれも非可算正則基数である。
  これが ψ が崩壊する添字である。

## 2. 定義

`α` についての再帰で、集合 `Cl(α, β)` と順序数 `ψ_κ(α)`（`κ ∈ R`）を定義する。

- `Cl(α, β)` は次を満たす最小の集合 `X` である。
  - `β ⊆ X`、`0 ∈ X`、全ての `n < ω` について `I_n ∈ X`、`I_ω ∈ X`。
  - `ξ, η ∈ X` ⇒ `ξ + η ∈ X`、`φ(ξ, η) ∈ X`、`Ω_ξ ∈ X`。
  - `ξ, π ∈ X`、`ξ < α`、`π ∈ R` ⇒ `ψ_π(ξ) ∈ X`。
- `ψ_κ(α) = min {β | κ ∈ Cl(α, β) ∧ Cl(α, β) ∩ κ ⊆ β}`。

到達不能基数が 1 つ `I` のとき（`I_n` が全部 `I` に等しく、`I_ω` が無いとき）、これは Buchholz の
定義そのものである。変えたのは、定数 `I_n`、`I_ω` と、添字のクラス `R` だけである。

## 3. ψ についての事実

`κ` は `R` の元を動く。角括弧の中の番号は Pohlers のものである。

**F1（単調）。** `α ≤ α'` かつ `β ≤ β'` ⇒ `Cl(α, β) ⊆ Cl(α', β')`。[155]

**F2（大きさ）。** `|Cl(α, β)| ≤ max(|β|, ℵ_0)`。[157] — この集合は `ω` 個の段の
合併である。各段は、前の段に有限個の有限項演算を施し、
`ω + 1` 個の定数を加えたものである。

**F3。** ある `β < κ` について `κ ∈ Cl(α, β)`。— `κ = I_n` なら定数である。
`κ = Ω_{s+1}` なら `β = s + 1 < κ` をとる。すると `s ∈ Cl`、`s + 1 = s + φ(0,0) ∈ Cl`、
`Ω_{s+1} ∈ Cl` となる。

**F4（崩壊）。** `ψ_κ(α) < κ`、`κ ∈ Cl(α, ψ_κ(α))`、`Cl(α, ψ_κ(α)) ∩ κ ⊆ ψ_κ(α)`、
`ψ_κ(α) ∉ Cl(α, ψ_κ(α))`。[160] — F3 の `β₀ < κ` から始め、
`β_{n+1} = sup(Cl(α, β_n) ∩ κ)` とおく。F2 と `κ` の正則性から `β_{n+1} < κ` である。
`cf κ > ω` なので `β = sup_n β_n < κ` である。`Cl(α, β)` は `Cl(α, β_n)` の
合併なので、この `β` は条件を満たす。最後の主張: `ψ_κ(α) ∈ Cl ∩ κ ⊆ ψ_κ(α)` は起こりえない。

**F5。** `α₀ < α` かつ `α₀ ∈ Cl(α, ψ_κ(α))` ⇒ `ψ_κ(α₀) < ψ_κ(α)`。[161] — `ψ_κ(α₀)` は
`Cl(α, ψ_κ(α)) ∩ κ ⊆ ψ_κ(α)` に入る。F4 より、それは `ψ_κ(α)` ではない。

**F6。** `ψ_κ(α) ∈ SC`。[163] — `0 ∈ Cl ∩ κ` から `ψ_κ(α) > 0` である。`ξ, η < ψ_κ(α)` なら、
`κ ∈ SC` なので `φ(ξ, η) ∈ Cl ∩ κ` である。

**F7（基数）。** `Ω_σ ∈ Cl(α, β)` ⇒ `σ ∈ Cl(α, β)`。[164] — `x ∈ Cl(α, β)` の
生成についての帰納法で示す。示すこと: `x = Ω_σ` なら `σ ∈ Cl(α, β)`。
- `x < β` のとき: `σ ≤ Ω_σ < β`。
- `x ∈ {0, I_n, I_ω}` のとき: `Ω` は単射で、これらは `Ω` の不動点である。よって `σ = x`。
- `x = ξ + η` のとき: `Ω_σ` は `0` か加法的主要である。よって `η = Ω_σ` か `η = 0 ∧ ξ = Ω_σ`。
- `x = φ(ξ, η)` のとき: `Ω_σ ∈ SC`（または `σ = 0`）である。よって `ξ = Ω_σ` か `η = Ω_σ`。
- `x = Ω_ξ` のとき: `ξ = σ`。
- `x = ψ_π(ξ)` のとき: `σ = Ω_σ` なら `σ = x ∈ Cl`。そうでなければ `σ < Ω_σ = ψ_π(ξ) =: γ` である。よって
  `σ ∈ γ ⊆ Cl(ξ, γ)` で、`Ω_σ ∈ Cl(ξ, γ) ∩ π ⊆ γ`、つまり `γ < γ` となる。これは起こりえない。

**F8（後続）。** `s + 1 ∈ Cl(α, β)` ⇒ `s ∈ Cl(α, β)`。— 同じ帰納法で示す。
`η ≠ 0` で `ξ + η = s + 1` なら、`η = t + 1`、`s = ξ + t` となる。`φ` の値で
後続のものは `1` に等しい。`Ω` の値と `ψ` の値は `0` か極限である（F6）。

**F9（後続の添字）。** `κ = Ω_{s+1}` について: `Ω_s < ψ_κ(α) < Ω_{s+1}`。よって `ψ_κ(α)`
は基数ではない（`s = 0` のとき: `ψ_κ(α)` は可算）。[167] — `κ ∈ Cl(α, ψ_κ(α))`
（F4）なので、`s + 1` と `s` もそこに入る（F7、F8）。`s < κ` なので `s ∈ Cl ∩ κ` で、`Ω_s ∈ Cl ∩ κ
⊆ ψ_κ(α)` となる。

**F10（到達不能基数の添字）。** `κ = I_n` について: `Ω_{ψ_κ(α)} = ψ_κ(α)` である。また
`n ≥ 1` のとき `I_{n-1} < ψ_κ(α) < I_n` である（`n = 0` のときは `Ω_1 < ψ_κ(α)`）。[170] — `I_{n-1}`
（`n = 0` のときは `Ω_1`）は `Cl ∩ κ` に入る。不動点であることの証明: `γ = ψ_κ(α)` とおき、
`Ω_σ ≤ γ < Ω_{σ+1}` とする。`I_n` は極限基数なので `Ω_{σ+1} < I_n` である。よって
`Ω_{σ+1} ∉ Cl(α, γ)` である（入っていれば `Ω_{σ+1} < γ` となる）。よって `σ ∉ Cl(α, γ)` で、`σ ≥ γ` である。よって
`Ω_σ ≥ σ ≥ γ ≥ Ω_σ` で、`γ = σ = Ω_σ` となる。

**F11（引数について単調）。** `ξ ≤ α` ⇒ `ψ_κ(ξ) ≤ ψ_κ(α)` かつ
`Cl(ξ, ψ_κ(ξ)) ⊆ Cl(α, ψ_κ(α))`。[168] — `κ ∈ Cl(ξ, ψ_κ(α))` を示す。`κ = I_n` なら
定数である。`κ = Ω_{s+1}` なら `s < Ω_s < ψ_κ(α)`（F9）である。さらに
`Cl(ξ, ψ_κ(α)) ∩ κ ⊆ Cl(α, ψ_κ(α)) ∩ κ ⊆ ψ_κ(α)` である。

**F12（標準的な引数で狭義単調）。** `α₀ < α` かつ
`α₀ ∈ Cl(α₀, ψ_κ(α₀))` なら、`ψ_κ(α₀) < ψ_κ(α)`。— F11 より `α₀ ∈ Cl(α, ψ_κ(α))` である。F5 を使う。

## 4. 項の体系

### 項

```
t ::= 0 | I_n | I_ω | t + t | φ(t, t) | Ω_t | ψ^S_s(t) | ψ^I_n(t)       (n ∈ ℕ)
```

`ψ^S_s(a)` は `ψ_{Ω_{s+1}}(a)` を表す。`ψ^I_n(a)` は `ψ_{I_n}(a)` を表す。項の
値 `|t|` は、そのまま読んだ順序数である。添字は一般の項ではない。`R` の添字は、
後続基数（`s` で与える）か `I_n`（`n` で与える）のどちらかである。

### 項の種類

- **SC 項**: `I_n`、`I_ω`、`Ω_a`、`ψ^S_s(a)`、`ψ^I_n(a)`。
- **主項**: SC 項と `φ(a, b)`。
- **不動点項** `F`: `I_n`、`I_ω`、`ψ^I_n(a)`（`Ω_x = x` となる値 `x`）。
- **基数項** `K`: `F` と `Ω_a`。

### 標準形 `NF`

- `0`、`I_n`、`I_ω` は `NF` に入る。
- `a + b` が `NF` に入るのは、`a` が主項で `NF` に入り、`b ≠ 0` が `NF` に入り、`b` の最初の
  加数が `≤ a` のときである。
- `φ(a, b)` が `NF` に入るのは、`a, b ∈ NF`、`a < φ(a, b)`、`b < φ(a, b)` のときである。
- `Ω_a` が `NF` に入るのは、`a ∈ NF`、`a ≠ 0`、`a ∉ F` のときである。
- `ψ^S_s(a)` が `NF` に入るのは、`s, a ∈ NF` かつ `K_{c}(a) < a` のときである。ここで `c = card(Ω_s)`（下を参照）。
- `ψ^I_n(a)` が `NF` に入るのは、`a ∈ NF` かつ `K_{ψ^I_n(a)}(a) < a` のときである。

ここで `<` は下の比較である。`K_μ(a) < a` は、有限集合 `K_μ(a)` の全ての元が
`< a` であることをいう。

### 集合 `K_μ(a)`

項 `μ` について、`K_μ(a)` は、`a` の中の崩壊のうち `μ` より下にないものの引数を
集めた有限集合である（Pohlers の定義 3.4.4.2）。

- `K_μ(0) = K_μ(I_n) = K_μ(I_ω) = ∅`。
- `K_μ(a + b) = K_μ(a) ∪ K_μ(b)`、`K_μ(φ(a, b)) = K_μ(a) ∪ K_μ(b)`。
- SC 項 `a < μ` について: `K_μ(a) = ∅`。
- `a ≥ μ` について: `K_μ(Ω_b) = K_μ(b)`、`K_μ(ψ^S_s(b)) = {b} ∪ K_μ(s) ∪ K_μ(b)`、
  `K_μ(ψ^I_n(b)) = {b} ∪ K_μ(b)`。

**健全性（Pohlers の (178) のやさしい方の半分）。** `a ∈ NF` で、
`K_μ(a)` の全ての元が `< α` なら、`|a| ∈ Cl(α, |μ|)` である。— `a` についての帰納法で示す。`K` の各条項は
`Cl` の条項に 1 つずつ対応する。もう半分は整列性には要らない。

これから、`ψ^S_s(a) ∈ NF` なら `|a| ∈ Cl(|a|, Ω_{|s|}) ⊆ Cl(|a|, ψ_{Ω_{|s|+1}}(|a|))`
（F9）となる。`ψ^I_n(a) ∈ NF` なら `|a| ∈ Cl(|a|, ψ_{I_n}(|a|))` となる。よって F12 は、
標準形の崩壊の引数に使える。

### 基数部分 `card(t)`

`card(t)` は基数項か `0` である。`|card(t)|` は `|t|` の基数の水準
（`Ω_σ ≤ |t|` となる最大の `Ω_σ`、無ければ `0`）である。

- `card(0) = 0`。`card(a + b) = card(a)`。`card(φ(a, b)) = max(card(a), card(b))`。
- `t ∈ K` について `card(t) = t`。
- `card(ψ^S_s(a)) = card(Ω_s)`。ここで `card(Ω_s)` は、`s = 0` なら `0`、`s ∈ F` なら `s`、
  それ以外なら `Ω_s` を表す。

### 比較

項の上の `a < b` は、`size(a) + size(b)` についての再帰で定義する。

1. `0 < b` となるのは `b ≠ 0` のときである。`a < 0` にはならない。
2. 和（主項は加数 1 つの和とみなす）: 加数のリストを辞書式に比べる。
   真の前半の方が小さい。
3. `φ(a, b)` と `φ(c, d)`: `a < c ∧ b < φ(c, d)`、または `a = c ∧ b < d`、または
   `c < a ∧ φ(a, b) < d`。
4. `φ(a, b)` と SC 項 `s`: `φ(a, b) < s` となるのは `a < s ∧ b < s` のときである。`s < φ(a, b)` となるのは
   `s ≤ a ∨ s ≤ b` のときである。
5. SC 項どうし:
   - `Ω_a < Ω_c` となるのは `a < c` のとき。`f ∈ F` について: `Ω_a < f` となるのは `a < f` のとき、`f < Ω_a` となるのは
     `f < a` のとき。
   - `I_n < I_m` となるのは `n < m` のとき。`I_n < I_ω`。`ψ^I_n(a) < I_m` となるのは `n ≤ m` のとき。
     `I_m < ψ^I_n(a)` となるのは `m < n` のとき。`ψ^I_n(a) < I_ω`。
     `ψ^I_n(a) < ψ^I_m(b)` となるのは `n < m ∨ (n = m ∧ a < b)` のとき。
   - `ψ^S_s(a) < ψ^S_t(b)` となるのは `s < t ∨ (s = t ∧ a < b)` のとき。
   - 基数項 `k` について: `ψ^S_s(a) < k` となるのは `card(Ω_s) < k` のとき、`k < ψ^S_s(a)` となるのは
     `k ≤ card(Ω_s)` のとき。

### 主定理（目標）

`NF` の項の上で、`a < b ⟺ |a| < |b|`。よって `|·|` は `NF` の上で単射で、`(NF, <)` は
狭義の整列順序である。これは順序数の集合と順序同型である。

条項ごとに使う事実:
- 3、4: Veblen 関数（Mathlib）と F6。
- 5 の 1 行目: `Ω` が狭義単調増加であること、不動点。
- 5 の 2 行目: F10。
- 5 の 3 行目と 4 行目: F9 と F12（`K` の健全性を通して）。

## 5. ここでしていないこと

- **完全性。** `Cl(ε_{I_ω+1}, 0)` のどの順序数も、ある `NF` 項の値であること
  （Pohlers の (174)–(177) と (178) のもう半分）。整列順序には要らない。
- **再帰的正則順序数。** Buchholz や Pohlers と同じく、基数は本当の
  基数である。それを再帰的正則順序数に置き換えることは試みていない。
- **Wilken の主張。** この体系の可算な部分が `Core(R₂⁺)` を覆うかどうかは
  未解決である。
